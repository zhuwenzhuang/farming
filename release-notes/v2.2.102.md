# Farming v2.2.102

[简体中文](./v2.2.102.zh_cn.md)

- Choose Standard, Fast, or Ultrafast directly in the Codex model picker when the selected model advertises those tiers. The picker stays open after a speed change, and the Composer shows Fast or Ultrafast next to the model.
- Recognize the current Codex Terminal prompt and footer so an idle session can change its model and speed after startup.
- Keep Agent state consistent during runtime replacement and confirm Codex steering when a concurrent prompt hands over.
- Update the managed Codex runtime to 0.172.0, Codex ACP to 2.10.0, Claude ACP to 0.110.1, Claude Agent SDK to 0.3.330, Pi ACP to 0.0.35, and the ACP SDK to 2.9.1.

## Installation

npm install -g farming-code@2.2.102 --registry=https://registry.npmjs.org
