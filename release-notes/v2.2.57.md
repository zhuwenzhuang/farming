# Farming v2.2.57

[简体中文](./v2.2.57.zh_cn.md)

This patch release removes a scroll-linked Project Files effect and tightens several recovery and activity-state boundaries.

## Stable Project Files navigation

- Project Files no longer renders a sticky ancestor row while scrolling. This removes the feedback path that could make a directory such as `workflow` flash while the sidebar divider was dragged.
- Deep trees keep the actual file name visible by capping visual indentation and reserving a minimum name width. Repeated two-way divider drags, scrolling, search, and reload are covered by focused browser tests.

## Truthful Agent activity

- ACP turns that end without a final reply are now represented explicitly instead of appearing complete, including after history replay and recovery.
- Long-running command activity uses the latest authoritative event time, so the visible activity age does not drift from the runtime transcript.
- ACP restart and executable fixtures are isolated from inherited test environments, preventing unrelated recovery settings from changing their behavior.

## Bounded recovery and reminders

- Stale Browser Resources now use bounded, owner-checked recovery and expose reconnecting or failed state instead of remaining indefinitely ambiguous.
- Rest reminders enter the resting state only after an explicit valid start, so timer and recovery events cannot cover a running Agent with a break overlay.
- Managed Agent dependencies are refreshed to ACP SDK 1.4.0 and Codex Runtime 0.149.1, with every supported platform artifact pinned by the generated runtime manifest.

## Upgrade

```bash
npm install --global farming-code@2.2.57 && farming daemon
```
