# Farming v2.2.48

[English](./v2.2.48.md)

里程碑代号：**ANCHORAGE**

本次发布增强代码导航能力，为 Runtime Recovery 建立有界路径，并新增事务化的私有 Linux 部署流程。

## 更深入的代码导航

- Language Server 结果现在集中在可调整尺寸的 Dock 中，更清晰地呈现 Definition、Reference、Hierarchy、Diagnostic、Semantic Highlight 与 Inlay Hint 刷新。
- File Navigation 能更紧凑地处理深层目录树与 Sticky Context，Editor Blame Detail 和 Transcript File Link 也会保留更有用的源码上下文。
- Rest Reminder 设置现在会明确反馈待定、关闭、预览与自定义间隔状态。

## 有界的 Runtime Continuity

- Chat Session 会把 Managed 或显式 Custom ACP Runtime 绑定到所选 Agent Home，同时不再把隐藏的运行上下文加入用户 Prompt。
- Terminal Checkpoint 现在通过版本化 WebSocket Protocol 传输，Farming Code 与 CRT 共享有界的重连和恢复行为。
- Managed Computer Action 会在执行前刷新其拥有的 Driver Session，遵守统一 Request Deadline，并区分从未开始的 Action 与结果不确定的 Mutation。

## 事务化私有部署

- 私有 Linux 部署现在从一个已提交 Revision 构建，进行不可变激活和 Readiness 验证，并在失败时回滚到上一个健康版本。
- Deployment Smoke Agent 不再出现在交互式 Agent List 中；Lifecycle Failure 会传递给 CLI，机器可读的 Artifact Output 也不再暴露服务器凭据。

## 升级

```bash
npm install --global farming-code@2.2.48 && farming daemon
```
