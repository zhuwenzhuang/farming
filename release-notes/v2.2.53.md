# Farming v2.2.53

[简体中文](./v2.2.53.zh_cn.md)

Milestone codename: **FLOW**

This release makes Project Files substantially faster and more predictable, adds dynamic Agent pinning, improves Browser recovery and CRT session state, and tightens the visual and read-only sharing experience across Farming Code.

## Faster, stable Project Files

- Workspace file control now travels over the main authenticated WebSocket, with request ownership, cancellation, timeouts, reconnect behavior, and file watches sharing one authoritative transport.
- File-open races are fenced by exact intent, stale reads and Language Server responses are cancelled, and retained editor models make repeated tab and file switches immediate without issuing another read.
- Large expanded trees keep selection feedback off the expensive whole-tree render path. Restored directories hydrate only when Files is visible, use bounded concurrency, and abort obsolete work when the workspace changes.
- Oversized Markdown previews virtualize offscreen sections, while file-row pointer, keyboard, range-selection, compact-folder, header, and diff interactions remain stable under production-shaped stress coverage.
- Progressive **Show More** controls preserve their batch size and keyboard behavior while Agents or sessions are selected, revealed, and reordered.

## Better Agent supervision

- Dynamic pinning can keep active Agents near the top of a Project while preserving explicit persistent order and recovery state.
- Farming CRT now synchronizes Pi session state through the shared Agent protocol, and generated bridge types stay aligned with backend state.
- ACP review actions no longer offer a commit operation after the relevant changes are already committed.

## Browser, appearance, and sharing polish

- The Browser Connector can automatically reconnect to Farming after a transient backend interruption, with an explicit user control for the behavior.
- Light, dark, and paper appearances restore their semantic colors across tabs, file icons, transcripts, diffs, and action surfaces.
- Read-only sharing notices now distinguish copy, link, and access failures more clearly, while anchored copy feedback stays attached to the action that produced it.

## Upgrade

```bash
npm install --global farming-code@2.2.53 && farming daemon
```
