# Farming v2.2.71

[简体中文](./v2.2.71.zh_cn.md)

## Chat and related Sessions

- Keep unfinished Composer submissions attached to their Agent across file navigation, and collapse accepted mobile submissions without overlapping controls.
- Open native subagent details with shared Chat rendering and safe, paginated related-session reads. Close archived panes and preserve fork boundaries after inherited conversations.
- Show persistent turn failures, fade new progress messages without replay, and keep keyboard-selected commands visible.
- Keep completed turns idle when submission acceptance arrives late, and restore disclosure arrows on hover and keyboard focus.
- Restore large Codex conversations without truncating their history, and reconcile failed resume attempts before reopening a Session.
- Keep native child Agents discoverable after the parent turn finishes, preserve their details while navigating back to the parent, and provide a shared visibility toggle.

## Connections and lifecycle

- Keep file browsing responsive when restoring oversized directories: bound directory enumeration and metadata work, honor cancellation, and report an explicit size limit without returning a partial listing.
- Queue restored directory reads before sending them, preserving navigation capacity while background file decorations load.
- Keep tracked-file Reviews independent of unrelated untracked files, and show Blame availability checks and retryable check failures in the editor menu.
- Keep Review source selection available with large untracked inventories, and render submodule commit changes without requiring their objects in the parent repository.
- Preserve a mobile sidebar opened by the user while an Agent or file finishes restoring in the background.
- Recover stalled connections, make Project path actions connection-aware, and configure read-only sharing link expiry with readable guidance.
- Hard-stop only verified Farming-owned process snapshots, retain verified runtime caches, and prepare the patched Browser runtime for source installations.
- Improve private release toolchain compatibility and validate lifecycle recovery before deployment smoke acceptance.
- Update the shared ACP SDK to 1.5.0 while retaining adapter-owned runtime pins.
- Refresh managed Codex to 0.156.1, Codex ACP to 1.13.0, and Claude ACP to 0.81.0 with its SDK 0.3.280, retaining Farming's reviewed history and lifecycle integrations.
- Support isolated directory installations with explicitly prepared private runtimes, and avoid duplicating browser-only dependencies in installation images while retaining their license notices.

npm install -g farming-code@2.2.71
