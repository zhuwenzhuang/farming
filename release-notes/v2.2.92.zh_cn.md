# Farming v2.2.92

[English](./v2.2.92.md)

## Chat 与移动端导航

- 返回正在向上阅读的 Terminal 时，会保留未读状态，直到跳转至最新输出。
- 打开空白 Chat 后，会在历史记录成功加载时清除未读提示。
- 浏览器页签可靠显示未读图标；标题保留实例名在前，并用当前界面语言说明未读数量。

- 通过 HTTP 地址打开 Farming 时，Chat 内嵌可视化能够正常展示。
- 移动端支持左滑进入下一个未读 Agent，并保留草稿。每次导航都会刷新返回窗口，分享复制错误显示在对应链接旁。
- Light、Dark、Paper 下，Project 操作按钮与焦点行使用一致的背景。产品文档更新了这些外观的截图。
- Chat 文件链接在访问检查期间保持稳定，符号链接项目在 Agent 和历史记录中使用统一身份。
- 被拒绝的 Fork 和只读语言服务请求会明确结束，不再停留在等待状态。

## 运行时与恢复

- Terminal 恢复会释放已被放弃的轮换准备；代次分配使用精确进程所有权，防止旧写入覆盖新状态。
- Desktop 停止或删除时，会拒绝尚未获得租约的 Browser 获取请求。
- 失去所有权的升级操作不能回滚或启动旧安装。
- Agent 更新拒绝不支持的协议字段。agy 在中断后保留准确的响应、工具完成和配置状态。
- Claude 交互式恢复保留原生会话选择语义，不再注入新 Session 身份。

## 托管 Agent 维护

- 托管 Codex 更新至 0.164.0，Claude ACP 更新至 0.94.0，ACP SDK 更新至 2.0.1。Claude 运行时跟随其适配器指定的 SDK 版本 0.3.303。

npm install -g farming-code@2.2.92 --registry=https://registry.npmjs.org
