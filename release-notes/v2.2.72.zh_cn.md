# Farming v2.2.72

[English](./v2.2.72.md)

## Chat 状态与恢复

- 修复后台切换和历史分页后的完成状态同步，无需刷新浏览器才能看到回合完成。
- 请求结算期间保留 Runtime 的等待审批和失败状态；冷恢复后正确标记被中断的工作。
- Provider 未提供错误文案时，自主回合失败仍可见。保留子会话的未知、失败、取消状态，避免将历史回合标为运行中。
- 长回合的正文窗口保持连续且有界。完成通知和重连保留历史阅读位置，返回最新时重新读取权威 Checkpoint。
- 拒绝过期响应与版本倒退。为排队读取、超时和恢复重试设置明确边界；无法完成同步时提供“重试”操作。
