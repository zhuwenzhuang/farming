# Farming v2.2.28

[English](./v2.2.28.md)

里程碑代号：**POMODORO**

本版本增加两种留在 Farming Workspace 内完成工作的方式：Farming Pet 提供显式启用的番茄钟式休息体验；Browser Resources 则让人和 Agent 通过系统 Chromium 浏览器查看并操作同一个网页。

## 核心改进

- Farming Pet 只根据真实的 Farming 点击或输入开始工作周期，连续五分钟无操作后重置，在当前标签页刷新后恢复，并且永远不会把 Agent Output 当成人的操作。工作时长包含常见番茄钟档位与自定义时长；到时先进入安静倒计时，支持延后一次、关闭本轮提醒，以及五分钟休息。
- 用户尚未明确选择时，Pet 样式跟随当前主题；手动选择后始终以用户选择为准。柔光提供安静的模态休息界面。黑洞提供 WebGL 休息场景、局部页面折射、不受折射影响的可读控制、连续透镜效果、后台安全计时，以及完整的霍金辐射蒸发过程。
- 每个 Project 可以拥有多个持久、可命名的 Browser Resource。Farming 会发现 macOS、Linux 或 Windows 上已经安装的兼容 Chromium 系浏览器，用隔离 Profile 以 Headless 方式启动，并把准确页面流式展示在 Workspace 内。Farming 不下载 Chromium，也不把 Playwright 加入产品运行时。
- 人和 Agent 共享同一个 Browser Resource 与 CDP Session。Viewer 支持导航、指针、文本输入、键盘、滚动、生命周期状态、重连，以及有边界的递归查看反馈。
- Browser 能力默认关闭。启用后，ACP Agent 可以获得 Project Scoped 的 `farming-browser` MCP Server；Terminal 和其他 Agent 可以通过 `farming browser` 或 `farming-browser` 别名发现并操作同一组 Resource。工具会先列出 Resource，后续操作必须显式指定 Browser id。
- HTML 文件现在可以在沙箱预览中打开，支持源码/预览切换、未保存内容、相对资源、有边界导航、过期恢复，以及桌面和手机覆盖。它仍然是静态 HTML Surface，不是通用 JavaScript 浏览器。

## Browser 边界

Browser Resources 面向网页查看和直接的 Agent 操作，不替代完整浏览器窗口、DevTools、下载界面、扩展、任意桌面操作或未来的 Computer Use。本版本只支持兼容的 Chromium 系系统浏览器。

## 可靠性与交互

- Browser Process、Row、隔离 Profile、Screencast Frame、CDP Request 与 Viewer Connection 都有明确生命周期 Owner 和有界失败状态。
- 递归 Browser 查看有明确边界，因此 Browser 可以查看包含 Farming 的页面，而不会形成无界视频反馈。
- Composer Draft 会跟随正确的 Restart Lineage；Browser 的发布与 E2E 状态也不再跨用例泄漏。
