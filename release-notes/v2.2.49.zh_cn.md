# Farming v2.2.49

[English](./v2.2.49.md)

里程碑代号：**CURRENT**

本次发布升级了托管 ACP Runtime，接入协商后的标准 Steering，并让安装不再依赖 npm 生命周期脚本。

## 标准 Steering

- Farming 现在会为所有声明标准 Steering 能力的 Agent 协商并启用该能力，包括 Codex 与 Claude。
- 现有 Queue 与 Steer 控件在支持该能力的 Provider 上保持一致行为，同时为旧 Codex Adapter 保留兼容路径。
- Goal 文本仍是普通 Prompt Content，不会成为跨 Turn 持久协议状态。

## 无脚本安装

- npm 包不再依赖 `preinstall`、`install` 或 `postinstall`；所需平台 Runtime 在发布制品中提前准备。
- 包验证会在禁用生命周期脚本的情况下安装，并确认 ACP、Server、Capability 与 Native PTY 路径仍可工作。

## 托管 Runtime 更新检查

- 托管 Codex ACP、Claude ACP、ACP SDK 与 Codex Runtime Pin 已一起升级并验证。
- 发布预检现在会在发布所管理的 Agent 依赖出现待评审新版本时失败关闭。

## 升级

```bash
npm install --global farming-code@2.2.49 && farming daemon
```
