# Farming v2.2.37

[English](./v2.2.37.md)

这个补丁版本加固了 Farming 的发布流程：只要精确发布提交对应的 CI 缺失、运行中、取消或失败，版本就不能继续发布。

## 发布安全

- 发布提交对应的完整 `CI` workflow 全部成功，现在被明确记录为第一条、不可绕过的发布门禁。任何失败都必须先修复并形成新的候选 Revision，再重新开始发布验收。
- Release workflow 会等待与候选 SHA 精确绑定、由 push 触发的 CI Run，只有该 Run 成功才允许继续，否则严格阻断发布。
- npm 来源校验现在会对 Registry 短暂的元数据传播窗口做有界重试，同时一旦发现该版本属于另一个 Git Revision 就立即失败。

## 升级

```bash
npm install --global farming-code@2.2.37 && farming daemon
```
