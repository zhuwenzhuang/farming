# Farming v2.2.49

[简体中文](./v2.2.49.zh_cn.md)

Milestone codename: **CURRENT**

This release upgrades the managed ACP runtimes, adopts negotiated standard Steering, and makes installation independent of npm lifecycle scripts.

## Standard Steering

- Farming now negotiates and uses standard ACP Steering for every Agent that advertises it, including Codex and Claude.
- The existing queue and steer controls keep the same behavior across supporting providers, while older Codex adapters retain a compatibility path.
- Goal text remains ordinary prompt content instead of becoming persistent cross-turn protocol state.

## Script-free installation

- The npm package no longer depends on `preinstall`, `install`, or `postinstall`; required platform runtimes are prepared in release artifacts.
- Package verification installs with lifecycle scripts disabled and confirms the ACP, server, capability, and native PTY paths still work.

## Managed runtime currency

- Managed Codex ACP, Claude ACP, ACP SDK, and Codex runtime pins are upgraded and verified together.
- Release preflight now fails closed when release-owned Agent dependencies have newer versions that require review.

## Upgrade

```bash
npm install --global farming-code@2.2.49 && farming daemon
```
