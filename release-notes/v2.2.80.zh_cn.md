# Farming v2.2.80

[English](./v2.2.80.md)

## 工作区与 Review

- 大目录按有界分页加载，可继续展开更多条目，避免阻塞文件树；不再使用的目录索引会释放内存。
- 并发读写时保持 Changes 和 Git 状态一致；重叠 Project 串行保存文件，提交或分支变化后 Git 历史仍沿固定快照分页。
- 从历史打开已提交变更进行 Review，保留审阅进度与偏好，切换比较时避免旧选择和结果混入。
- 编辑 Worktree 分支名称时即时更新目标目录，创建前校验可用性；窄侧栏中的历史控件和操作保持可访问。

## Agent 监督

- 保留已停止 Provider Terminal 的检查入口，可选择 Resume 或 Archive，并保留所属 Project 和会话上下文。
- 自主 Goal 在多轮执行、取消和完成时保持一致；已完成 Goal 记录在 Chat 历史中，用量读取保持新鲜。
- Composer 模型与推理强度标签完整显示，避免裁掉 `g` 等字母的下沿。
- 更新托管 Codex、Claude ACP 运行时及 ACP SDK，发布前验证 Provider 兼容性。

## 维护

- 停止所选 Config 的进程时，不再误杀共享同一父进程组的其他前台实例。
- 通过有界的所有者认证确认服务器就绪，避免重复运行时准备与归档扫描，并在等待 npm 公开可见期间保留已接受的发布状态。

## 升级

```bash
npm install -g farming-code@2.2.80
```
