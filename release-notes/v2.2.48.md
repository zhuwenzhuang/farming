# Farming v2.2.48

[简体中文](./v2.2.48.zh_cn.md)

Milestone codename: **ANCHORAGE**

This release makes code navigation more useful, keeps runtime recovery bounded, and adds a transactional path for private Linux deployments.

## Deeper code navigation

- Language Server results now live in a resizable dock with clearer definitions, references, hierarchy, diagnostics, semantic highlighting, and inlay-hint refreshes.
- File navigation handles deep trees and sticky context more compactly, while editor blame details and transcript file links preserve more useful source context.
- Rest reminder setup now provides clearer pending, disabled, preview, and custom-interval feedback.

## Bounded runtime continuity

- Chat Sessions bind their managed or explicitly custom ACP runtime to the selected Agent Home without adding hidden operational context to user prompts.
- Terminal checkpoints now travel over the versioned WebSocket protocol, with bounded reconnect and recovery behavior shared by Farming Code and CRT.
- Managed Computer actions refresh their owned Driver Session before use, enforce one request deadline, and distinguish actions that never started from uncertain mutations.

## Transactional private deployment

- Private Linux deployment now builds one committed revision, activates it immutably, verifies readiness, and rolls back to the prior healthy release on failure.
- Deployment smoke Agents stay out of the interactive Agent list, lifecycle failures propagate to the CLI, and machine-readable artifact output no longer exposes server credentials.

## Upgrade

```bash
npm install --global farming-code@2.2.48 && farming daemon
```
