# Farming v2.2.52

[English](./v2.2.52.md)

里程碑代号：**REACH**

本次发布让 Farming Browser Connector 在普通网站上保持一致可用，在 Agent 附加前恢复被 Chrome Memory Saver 休眠的页面，更新托管的 Codex 与 Claude ACP Adapter，理清文件编辑时的 Agent 选中语义，并正式发布 Language Server 指南与更新后的产品截图。

## 让 Agent 介入普通 Chrome 页面

- Farming Browser Connector 现在申请 Chrome 的所有网站 Host Permission，因此会显示在 **Full access** 分组；完成配对后，Agent 无需按网站逐个授权即可读取和操作任意普通 HTTP 或 HTTPS 页面。
- 配对入口仍只接受 localhost 或 `127.0.0.1` 上已登录的 Farming 页面；`chrome://`、无痕页、Chrome Web Store 及其他浏览器受限页面仍不可用。
- Farming Backend 暂时不可达时，Connector 启动流程会进入有界重连状态，不再留下扩展错误；配对始终使用明确的 Farming 标签页，而不是碰巧处于激活状态的页面。
- Chrome Memory Saver 已休眠目标页面时，Farming 会恢复该精确标签页，重新校验 URL 与访问权限，再建立 Debugger 会话；恢复期间 Chrome 短暂返回空标题时，可通过唯一 URL 正确匹配。

## 更清晰的工作区选中语义

- 打开文件后，由编辑器接管主区域并清除 Agent Row 的选中状态，避免同时出现两个 Active Surface。
- 离开编辑器进入 Farming 其他视图时会保留所选 Agent；从外部文件链接返回时，也会可靠恢复来源 Agent。

## 当前托管 Provider Adapter

- 托管的 Codex ACP Adapter 已更新到 1.4.0，Claude ACP Adapter 已更新到 0.69.0，同时保留 Farming 经过审查的 Codex 集成补丁与精确的 Bundle Runtime 哈希。
- 两个上游版本均为 AIR Extension 新增变更文件报告能力，并保持现有 ACP SDK 与托管 Claude SDK 的兼容边界。

## 文档

- Language Server 指南已进入正式的中英文 Code 文档，包含设置、导航、故障排查，以及 Settings 和 Call Hierarchy 的验证截图。
- Farming Code、CRT、Browser、分享、移动端、Appearance、Pet 与 Usage 等产品截图已用更高分辨率重新生成，并由更严格的资源校验覆盖。

## 升级

```bash
npm install --global farming-code@2.2.52 && farming daemon
```
