# Farming v2.2.73

[English](./v2.2.73.md)

里程碑代号：**FRESH BRANCH**

## Chat 与输入区

- 长文本粘贴自动折叠为可恢复的引用卡片；统一文件粘贴、选择和拖放，支持文档正文提取、图文混合粘贴、图片大图预览、HEIC 转换、可选图片优化，以及带附件的草稿和历史恢复。

- 在对话正文内显示待回答的 Agent 问题，提供“稍后”和“跳过”操作，并让取消状态更清晰。
- 输入区新增上下文建议和斜杠命令；切换 Runtime 时保留选择与草稿。
- 小幅上滚后保留阅读位置，并准确显示“跳转到最新”；实时操作进度保持连贯。
- 可见的子会话持续更新；点击父行可收起子会话，再点击子行可重新打开，并保留草稿和历史记录。
- `/side` 从父会话当前上下文新建旁聊；已归档会话保持归档，已有子行保留各自的对话与草稿。
- 将托管 Codex Runtime 更新至 0.158.0、Codex ACP 更新至 2.0.0、Claude ACP 更新至 0.82.0，ACP SDK 更新至 1.5.1。

## Files 与 Review

- Files 标题显示当前目录，支持显示和跳转变更文件，并分页加载大量变更。
- 文件差异视图支持按修订版本查看 blame。
- 导航时保留 Review 的比较对象、草稿和审阅进度。

## 升级

```bash
npm install -g farming-code@2.2.73
```
