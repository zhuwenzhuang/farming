# Farming v2.2.13

[简体中文](https://github.com/zhuwenzhuang/farming/blob/main/release-notes/v2.2.13.zh_cn.md)

Milestone codename: **PHOSPHOR**

This release changes Farming CRT structured Chat typography, syntax highlighting, and phosphor effects. It also fixes Main Agent recovery, initial focus, and delayed terminal-link handling, and updates the README lead image.

## Highlights

- **Markdown rendering and content restrictions in CRT Chat**: Agent replies now render GitHub Flavored Markdown, syntax-highlighted code, KaTeX formulas, and lazily loaded Mermaid diagrams. Raw HTML stays disabled, unsafe links are stripped, and invalid diagrams retain their source in a bounded error state.
- **CRT typography and phosphor-effect changes**: structured Chat, controls, metadata, and Agent previews use one type scale. Code keeps syntax highlighting, while preview text drops the phosphor blur.
- **Main Agent process reclaim and focus recovery**: starting Main Agent reclaims an already-running Main process if its authoritative id was temporarily lost. Opening Main Agent after another session now keeps terminal input focused after the initial authoritative screen checkpoint settles, without stealing focus from a control the user already selected.
- **Terminal links bound to their source session**: delayed terminal-link activations are fenced to the session that created them, and browser checks use semantic or test-id contracts for files, navigation, display flows, and focus recovery.
- **README lead image**: the README now leads with the current CRT Billing view.

## Verification

- Backend and source-contract test suite
- TypeScript typecheck and ESLint
- Focused Chromium coverage for CRT Markdown, KaTeX, Mermaid, and Main Agent focus recovery
- `/farming` production build

## Upgrade

```bash
npm install --global farming-code@2.2.13 && farming daemon
```
