# Farming v2.2.64

[English](./v2.2.64.md)

里程碑代号：**PASSAGE**

Passage（通途）将受监督工作区扩展到原生 Desktop 浏览、统一协调的 Agent 入口、
可持续恢复的 Terminal 历史、由所有者控制的分享流程，以及始终保持在可见视口内
的移动端布局。

## 原生 Browser 与 Desktop

- Desktop 应用可在原生 Browser 界面中承载 Browser Resource，同时保持 Farming
  统一的 Browser 生命周期、客户端能力语义和后端鉴权边界。
- 原生导航、下载、窗口焦点、单实例行为及外部链接遵循明确的 Desktop 归属与安全
  协议。结构化原生下载被允许进入，页面框架内的原生文件选择器保持禁用。
- Web 客户端与 Desktop 适配器之间的 Browser 状态和控件保持一致，包括滚动条
  行为及客户端特定能力。

## 工作区连续性

- 打开或恢复 Agent 统一进入一个协调流程，提供有界加载、搜索、历史、取消和明确
  的终态失败反馈。
- Terminal 重连时渐进恢复 scrollback，无需等待全部保留历史即可看到可用输出。
- 宽版 Markdown 预览充分利用工作区宽度，同时保持长内容和公式可读。
- 窄屏 Terminal 中仍可浏览 Codex 快捷模型菜单与分页模型列表，选择器无法稳定
  时提供有界恢复。
- Codex 模型选择器保持预期的深色主题配色。
- 协作摘要可区分同前缀的 Subagent、展示其实际任务，并且不再把历史创建快照显示
  为当前“准备中”状态。

## 分享与访问

- 实例所有者可直接在 Share 弹层中轮转分享鉴权 Token。轮转一次性更新持久化的
  所有者凭据，刷新可见的浏览器 URL 与完整控制复制入口，并使旧所有者 Token 及
  携带它的 QR 票据失效。
- 轮转前已获准入的连接保留其准入状态；HTTP 与 WebSocket 客户端继续执行明确的
  鉴权边界。

## 移动端布局

- 键盘打开或收起时，紧凑 Composer 始终保持在视觉视口内，不会漂移到可见区域
  之外。
- 安装为独立 Web App 后，静息 Composer 停在原生绘制边界上，消除其下方多余的
  空白间隙，且不再重复扣除安全区。

## 运行时与依赖

- Codex ACP 适配器更新至 1.8.0，Claude Agent ACP 适配器更新至 0.73.0，内置
  Codex CLI 更新至 0.153.0。
- HTTP 服务升级至 Express 5.2，引入 body-parser 2.3 与 qs 6.16.0，生产
  依赖审计保持干净。

## 升级

```bash
npm install -g farming-code@2.2.64
```
