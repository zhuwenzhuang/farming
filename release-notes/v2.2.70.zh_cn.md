# Farming v2.2.70

[English](./v2.2.70.md)

里程碑代号：**WORKSHEET**

Worksheet 为统一的 Project、Agent 工作区加入表格预览、子 Agent、引用提问与内联可视化。

## 子 Agent 与引用提问

- 点击 Agent 行上的加号即可创建或重新打开持久化子 Agent。父 Agent 与子 Agent 初始各占一半宽度，并分别保留草稿与对话。
- 在父 Chat 输入 `/side` 可打开同一个子 Agent，命令文本不会发送给 Agent。
- 选中 Agent 回复中的文字后，可引用到当前 Chat，或交给子 Agent 继续提问。Agent 在任务中自行创建的子会话仍在同一个右侧详情区域打开。

## 表格预览

- 在 File Viewer 中直接打开 XLSX、CSV、TSV，支持切换 Sheet、单元格地址跳转、查找、选区复制和下载原文件。
- 展示合并单元格、列宽、隐藏内容标记与公式缓存提示。CSV/TSV 保留标识符前导零和日期形式的文本，不静默转换数值。
- 在可取消的 Worker 中解析工作簿，加载和解析均有时间限制。预览前拒绝损坏或超限 XLSX，切换或关闭文件时释放预览资源。
- 支持 Light、Dark、Paper 三种外观，按需加载完全开源的 SheetJS CE 与 VTable。预览只读，不重新计算公式、不修改原始工作簿。

## 内联可视化与浏览器生命周期

- 在 Chat 中直接展示 Agent 创建的 HTML 可视化，支持隔离的本地资源、自适应尺寸、全屏查看以及 Light、Dark、Paper 外观。
- 按需获取浏览器画面，并在会话关闭时清理由 Farming 启动的 Chrome 进程。

## 升级

```bash
npm install -g farming-code@2.2.70
```
