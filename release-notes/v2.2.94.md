# Farming v2.2.94

[简体中文](./v2.2.94.zh_cn.md)

## Access, Chat, and runtime startup

- Unauthenticated browser visits and expired sessions open a tap-to-compose passphrase challenge instead of raw JSON errors. Poetic and word-based passphrases pre-fill the opening clue of each line and offer a shuffled tile bank in Light, Dark, and Paper, with direct passphrase input available when needed.
- Parallel runtime dependency preparation downloads missing managed runtimes concurrently and reports multiline per-component progress on interactive terminals.
- Chat preserves streamed Markdown structure across steering updates and reconciles historical Antigravity error steps without overlapping composer feedback.
- Rich Chat composition preserves native IME input and focus across quoted side-chat flows, and adds a wide transcript layout toggle that maintains the current reading anchor.
- CRT usage metering scans large local Codex session histories without starving forked-session baseline indexing, reports explicit syncing or incomplete history states, and keeps the CRT dashboard focused on live Agents while settling stopped or dead terminals into read-only inspection without checkpoint retry errors.

## Managed Agent maintenance

- Update Codex ACP to 2.3.0 and Claude ACP to 0.97.0. The Claude runtime follows its adapter-owned SDK version, 0.3.310.
