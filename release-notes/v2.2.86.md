# Farming v2.2.86

[简体中文](./v2.2.86.zh_cn.md)

## Native text editing

- Use native plain-text editing in Chat, Terminal and side conversations, including compact and expanded input. Markdown stays literal without changing input typography.
- Paste rendered answers as their plain text, retaining indentation, line breaks and native undo. Long pasted text keeps its context card and restores its exact source to the input.
- Select and copy file source with native touch controls on mobile, while retaining the desktop editor.
- Keep file-link and search navigation focused on the visible mobile source, including after changing the layout.

## Conversation continuity

- Keep long Chat history complete and restore the reading position across reloads and background updates.
- Preserve file-reference shorthand such as paired source and header extensions.
- Submit Terminal handoff context automatically and remember the selected launch mode when opening the next Agent.
- Confirm Codex Terminal Fast mode changes from the rendered terminal state, preventing false timeouts after successful changes.

## Upgrade

```bash
npm install -g farming-code@2.2.86
```
