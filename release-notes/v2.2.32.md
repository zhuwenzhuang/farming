# Farming v2.2.32

[简体中文](./v2.2.32.zh_cn.md)

Milestone codename: **TYPESCRIPT**

This release completes Farming's TypeScript migration and turns the stronger typed boundaries into a broad reliability and product-quality pass across Agents, Browser, Computer, Chat, Terminal, Files, and mobile use.

## TypeScript milestone

- Farming's maintained backend runtime, browser protocol, classic browser, shared, script, usage-scanner, and test sources now pass the repository-wide TypeScript gates. Release packages continue to ship generated and bundled JavaScript rather than executable TypeScript.
- Runtime bindings, provider capabilities, terminal state, lifecycle journals, workspace roots, ACP checkpoints, usage parsing, update management, and release tooling now have explicit typed boundaries instead of relying on loosely shared runtime shapes.
- Backend tests are TypeScript-checked as a first-class release surface, and source-contract tests were updated to verify the current authoritative refresh, menu, and compact process-display behavior.
- App bundles explicitly copy the generated Backend, Browser, and Computer CommonJS runtime modules after the tracked-source archive is created, so clean release runners ship the same TypeScript-generated runtime verified in source and dogfood deployments.

## Agent workflows and extensions

- **Plugins → Extensions** provides a read-only catalog grouped by Agent Home and extension type. It understands Agent Plugins v1 plus native Codex, Claude, Qoder, Skill, MCP, Hook, Plugin, and Command layouts; displays provider-owned configured/enabled/disabled state; opens the exact source file; and never creates a second Farming-owned enablement database.
- Registered Agent Homes remain visible when their CLI is unavailable. Extension discovery rejects paths that escape a Plugin root, distinguishes standard manifests from provider-private formats, and reads Qoder's native plugin status correctly.
- Agent runtime dependencies are versioned and isolated more explicitly. Plugin settings inherit the selected Home, current capability reads are authoritative, and Agent, Project, History, queued-follow-up, and runtime-switch interactions have been tightened without adding parallel lifecycle implementations.

## Browser and Computer

- Isolated Browser is an explicit Browser source backed by the Agent's visible Computer. Browser tabs share that Agent-owned desktop while keeping lifecycle, storage, Viewer generation, and cleanup ownership precise.
- Startup recovery retries every Browser resource that still owns an exact process identity, including previously failed cleanup. It resolves the pinned `agent-browser` runtime independently of the currently selected browser source and clears the exact stale identity before admitting a new start.
- Managed Chromium preparation now grants the container's real desktop user read-only traversal of the cache and validates readiness as that user. CDP probing waits for its relay connection to close before starting `agent-browser`, preventing the first WebSocket from being blocked behind the readiness check.
- Browser and Computer settings, source selection, unavailable-state reporting, Viewer behavior, and mobile controls have been simplified while preserving the single supported runtime path.

## Chat, Terminal, and Files

- ACP Chat keeps accepted steers, queued follow-ups, permissions, forms, tool evidence, file changes, media, collaboration activity, and runtime switching in one ordered transcript. While work is active, the collapsed process area shows only the current running command; completed intermediate activity remains available on demand without leaving a stacked residue.
- Terminal reattachment hides a parked xterm buffer until a current authoritative checkpoint commits. Fast recovery no longer flashes a transient loading card, while slower recovery still exposes bounded progress and retry state.
- Project Files uses one explicit reveal owner when Chat or another surface opens a file, preventing the tree and Project list from fighting over scroll position. Deep trees remain stable through expand, scroll, collapse, refresh, and reload.
- Mobile coverage now includes an iPhone WebKit project with production-shaped long Chat, terminal, file, permission, authentication, Fork, background continuity, and runtime-switch scenarios. Desktop-equivalent Chromium paths remain covered alongside the mobile flows.

## Product polish

- Project and Agent rows, hover previews, menus, settings, status presentation, file diffs, content sizing, dark mode, and narrow layouts received a coordinated interaction and visual pass.
- Farming Pet rest reminders now use an explicit delayed interaction model with regression coverage.
- Current-state pages refresh authoritatively instead of presenting a previous visit's snapshot as the answer to a new request.

## Upgrade

```bash
npm install --global farming-code@2.2.32 && farming daemon
```
