# Farming v2.2.103

[简体中文](./v2.2.103.zh_cn.md)

- Accelerate Project file and directory search with a persistent in-memory workspace index supporting arbitrary-length fuzzy matching, multi-token queries, Smart Case ranking, and recent-access boost.
- Add SQLite FTS5 full-text search across historical Agent session transcripts (including CJK and multi-token cross-turn matching) with highlighted contextual snippets.
- Add a dedicated Project code content search dialog (`Shift+Cmd+F` / `Ctrl+Shift+F`) with match case, whole word, and regular expression toggles, collapsible file groups, and exact line jump.
- Record automatic hidden Git ref checkpoints around Agent turns so you can inspect the exact per-turn diff and safely restore a turn's working tree with an automatic pre-restore backup.
- Keep mobile Composer menus, carets, and transcript content visible without clipping across mobile viewports.
- Update the managed Codex ACP adapter to 2.12.1, Claude ACP to 0.113.0, Claude Agent SDK to 0.3.331, and the ACP SDK to 2.12.0.

## Installation

```bash
npm install -g farming-code@2.2.103 --registry=https://registry.npmjs.org
```
