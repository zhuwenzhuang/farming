# Farming v2.2.73

[简体中文](./v2.2.73.zh_cn.md)

Milestone codename: **FRESH BRANCH**

## Chat and composer

- Show pending Agent questions inline in the conversation, with Later and Skip actions and clearer cancellation state.
- Add context suggestions and slash commands to the composer while preserving selections and drafts across runtime changes.
- Preserve the reading position after small upward scrolls and keep the jump-to-latest control accurate. Maintain coherent progress for live actions.
- Create a fresh side chat from the current parent context with `/side`; archived chats stay archived, and existing child rows preserve their own conversation and draft.
- Update the managed Codex runtime to 0.158.0 and the ACP SDK to 1.5.1.

## Files and Review

- Show the current directory in the Files header, reveal and navigate changed files, and load large change lists in pages.
- Add revision-aware blame to file diffs.
- Preserve Review comparison identity, drafts, and progress while navigating.

## Upgrade

```bash
npm install -g farming-code@2.2.73
```
