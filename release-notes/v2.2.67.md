# Farming v2.2.67

[简体中文](./v2.2.67.zh_cn.md)

## Chat and recovery

- Return to the newest message after an accepted Chat message while preserving
  your reading position during ordinary updates.
- Preserve your selected model when discovery fails, and show a recovery action
  before another message can use an unintended model.
- Preserve an explicit jump to the latest Terminal output when a reconnect
  checkpoint arrives after switching Agents.
- Retire unrecoverable Shells after a hard restart so replaced Main terminals
  do not accumulate as extra bash rows.
- Fix macOS Terminal-to-Chat switches that could fail while an old process
  was finishing its exit.

## Files and rich content

- Keep streaming Markdown, formulas, and diagrams stable, with fitted diagram
  previews and shared fullscreen inspection controls.
- Keep blame annotations below asynchronously rendered sticky headers and inside
  the editor viewport, and dismiss stale menus
  when changing files or views.
- Preserve selected text when a clipboard write fails during Cut, with visible
  failure feedback.
- Keep desktop navigation and editing controls in intermediate-width windows.

## Browser and runtimes

- Improve remote Browser keyboard, pointer, focus, and clipboard handling.
- Keep isolated Browser input responsive while its automation connection is open.
- Release the isolated Desktop lease when the last Browser tab disappears, so its Computer can be deleted.
- Update managed Codex to 0.154.0, Codex ACP to 1.11.0, and Claude ACP to 0.76.0.

## Upgrade

```bash
npm install -g farming-code@2.2.67
```
