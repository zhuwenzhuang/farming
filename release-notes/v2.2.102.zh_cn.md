# Farming v2.2.102

[English](./v2.2.102.md)

- 当 Codex 模型提供极速档位时，可直接在模型面板选择「标准」「快」或「极速」。切换速度后面板保持打开，Composer 在模型旁显示当前启用的「快」或「极速」。
- 识别新版 Codex Terminal 的提示符和状态栏，启动完成后即可在空闲会话中切换模型和速度。
- 保持 Agent 切换运行时期间的状态一致，并在 Codex 并发提示词交接时确认引导请求。
- 更新托管 Codex 至 0.172.0、Codex ACP 至 2.10.0、Claude ACP 至 0.110.1、Claude Agent SDK 至 0.3.330、Pi ACP 至 0.0.35、ACP SDK 至 2.9.1。

## 安装

```bash
npm install -g farming-code@2.2.102 --registry=https://registry.npmjs.org
```
