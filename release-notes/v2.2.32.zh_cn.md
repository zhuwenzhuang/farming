# Farming v2.2.32

[English](./v2.2.32.md)

里程碑代号：**TYPESCRIPT**

这个版本完成了 Farming 的 TypeScript 全量迁移，并以更严格的类型边界为基础，对 Agent、Browser、Computer、Chat、Terminal、Files 与移动端体验做了一轮覆盖面较大的可靠性和产品质量收敛。

## TypeScript 里程碑

- Farming 维护的 Backend Runtime、Browser Protocol、Classic Browser、Shared、Script、Usage Scanner 与测试源码现在统一通过仓库级 TypeScript 门禁。发行包仍然只携带生成或 Bundle 后的 JavaScript，不要求用户运行 TypeScript。
- Runtime Binding、Provider Capability、Terminal State、Lifecycle Journal、Workspace Root、ACP Checkpoint、Usage Parser、Update Management 与 Release Tooling 都拥有显式类型边界，不再依赖松散共享的 Runtime Shape。
- Backend 测试成为正式的 TypeScript 检查面；源码契约测试也更新为验证当前权威刷新、菜单与紧凑过程展示行为。
- App Bundle 会在 tracked source archive 创建后显式复制 TypeScript 生成的 Backend、Browser 与 Computer CommonJS Runtime，确保干净 Release Runner 携带的运行时代码与源码门禁和 Dogfood 部署验证的是同一份生成结果。

## Agent 工作流与扩展

- **插件 → 扩展**新增只读目录，按 Agent Home 与扩展类型分组。它支持 Agent Plugins v1，以及 Codex、Claude、Qoder 原生格式和 Skill、MCP、Hook、Plugin、Command 布局；展示 Provider 自己维护的已配置、已启用或已停用状态；可打开精确来源文件；不会再维护一套 Farming 私有 Enablement。
- 即使 Agent CLI 当前不可执行，已注册 Home 仍然可见。扩展发现会拒绝逃出 Plugin Root 的路径，区分标准 Manifest 与 Provider 私有格式，并正确读取 Qoder 的原生插件状态。
- Agent Runtime Dependency 的版本与隔离边界更明确。插件设置继承选中的 Home，当前 Capability 读取保持权威；Agent、Project、History、排队 Follow-up 与 Runtime Switch 交互得到收紧，同时没有引入第二套生命周期实现。

## Browser 与 Computer

- Isolated Browser 成为显式 Browser Source，由 Agent 可见的 Computer 承载。同一 Agent 的 Browser Tab 共享这台桌面，同时保持 Lifecycle、Storage、Viewer Generation 与 Cleanup Ownership 精确。
- 启动恢复会重试所有仍持有精确 Process Identity 的 Browser Resource，包括上次 Cleanup 失败的资源。Cleanup 会独立解析锁定版本的 `agent-browser`，不依赖当前选中的 Browser Source，并在允许新启动前清除精确遗留身份。
- Managed Chromium 准备流程现在为容器内真实桌面用户提供只读遍历权限，并以该用户校验就绪状态。CDP Probe 必须等 Relay 连接真正关闭后才启动 `agent-browser`，避免第一次 WebSocket 被就绪探测堵住。
- Browser 与 Computer 的设置、来源选择、不可用状态、Viewer 行为和移动端控件进一步简化，同时保留唯一受支持的 Runtime 主路径。

## Chat、Terminal 与 Files

- ACP Chat 会在同一条有序 Transcript 中保留已接受 Steer、排队 Follow-up、Permission、Form、Tool Evidence、文件变更、Media、协作活动与 Runtime Switch。工作进行时，收起的过程区只显示当前正在运行的一条命令；完成后的中间过程默认不留下层叠残影，但仍可按需展开查看。
- Terminal 重新挂载时会隐藏停放 xterm 的旧 Buffer，直到当前权威 Checkpoint 提交。快速恢复不再闪出短暂 Loading Card；恢复较慢时仍会展示有界进度与重试状态。
- 当 Chat 或其他 Surface 打开文件时，Project Files 只保留一个显式 Reveal Owner，避免目录树与 Project List 争抢滚动位置。深层目录在展开、滚动、折叠、刷新与重载后保持稳定。
- 移动端新增正式 iPhone WebKit 项目，覆盖 Production-shaped 的长 Chat、Terminal、文件、Permission、Authentication、Fork、后台连续性与 Runtime Switch 场景；对应桌面 Chromium 路径也继续覆盖。

## 产品打磨

- Project 与 Agent Row、Hover Preview、Menu、Settings、状态展示、文件 Diff、内容字号、Dark Mode 与窄屏布局完成一轮协同的交互和视觉打磨。
- Farming Pet 休息提醒改为显式的延迟交互模型，并补充回归覆盖。
- 展示当前能力、配置或状态的页面会重新取得权威结果，不再把上次访问的快照作为新请求的答案。

## 升级

```bash
npm install --global farming-code@2.2.32 && farming daemon
```
