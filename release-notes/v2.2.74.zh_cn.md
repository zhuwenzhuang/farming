# Farming v2.2.74

[English](./v2.2.74.md)

## Projects 与文件

- 创建永久 Worktree 前可编辑名称，提供冲突检查、可见创建进度和可最小化的状态控件；重新加载后继续跟踪原操作。
- 编辑器变更等待安全时机再刷新；改进引用上下文，同时保留当前草稿。

## Chat 与用量

- 统一文档粘贴、图文混合粘贴、图片预览、HEIC 转换、可选图片优化，以及带附件的草稿与历史恢复；长文本粘贴折叠为可恢复的引用卡片。
- 在实时内容底部隐藏“返回最新”控件；Mermaid 组件加载失败时可重新加载页面恢复。
- 独立于推理 Provider 读取 Codex 账号额度，隔离账号身份，并协调 Code 与 CRT 的 Token 用量快照。
- 模型矩阵保留版本号，便于区分不同代际。

## 安装与 Runtime

- 改进公开安装脚本的兼容性，简化网站安装命令。
