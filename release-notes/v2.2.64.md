# Farming v2.2.64

[简体中文](./v2.2.64.zh_cn.md)

Milestone codename: **PASSAGE**

Passage expands the supervised workspace with native Desktop browsing, one
coordinated Agent entry, durable Terminal history, owner-controlled sharing,
and a mobile layout that stays inside the visible viewport.

## Native Browser and Desktop

- The Desktop app can host Browser Resources in a native Browser surface while
  preserving Farming's shared Browser lifecycle, client capability semantics,
  and authenticated backend boundary.
- Native navigation, downloads, window focus, singleton behavior, and external
  links follow explicit Desktop ownership and safety contracts. Structured
  native downloads are admitted, and frame-level file pickers stay blocked.
- Browser state and controls remain coherent between web clients and the
  Desktop adapter, including scrollbar behavior and client-specific
  capabilities.

## Workspace continuity

- Opening or resuming an Agent uses one coordinated flow with bounded loading,
  search, history, cancellation, and visible terminal failures.
- Terminal reconnect restores scrollback progressively, so useful output
  appears before the complete retained history arrives.
- Wide Markdown preview uses the available workspace width while keeping long
  content and equations readable.
- Codex quick model menus and paged model lists stay navigable in narrow
  Terminals, with bounded recovery when the picker cannot settle.
- The Codex model picker keeps its intended dark-theme palette.
- Collaboration summaries keep same-prefix subagents distinguishable, show
  their actual task, and avoid presenting an old creation snapshot as a live
  pending state.

## Sharing and access

- Instance owners can rotate the sharing authentication token directly from
  the Share popover. Rotation updates the persisted owner credential once,
  refreshes the visible browser URL and the full-control copy surface, and
  invalidates the previous owner token and any QR tickets that carried it.
- Connections admitted before a rotation keep their admission. HTTP and
  WebSocket clients continue to enforce explicit authentication boundaries.

## Mobile layout

- Long Chat prose, identifiers, URLs, inline paths, and command blocks wrap
  within the transcript instead of being clipped outside the narrow viewport.
- The compact Composer stays inside the visual viewport while the keyboard
  opens or closes, instead of drifting below the visible area.
- An installed standalone Web App settles its resting Composer at the native
  paint boundary, removing the extra blank gap below it instead of
  subtracting the safe area a second time.

## Runtime and dependencies

- The Codex ACP adapter is updated to 1.8.0 and the Claude Agent ACP adapter
  to 0.73.0, with the bundled Codex CLI refreshed to 0.153.0.
- The HTTP server is upgraded to Express 5.2, bringing body-parser 2.3 and
  qs 6.16.0, keeping the production dependency audit clean.

## Upgrade

```bash
npm install -g farming-code@2.2.64
```
