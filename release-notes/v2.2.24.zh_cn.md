# Farming v2.2.24

[English](./v2.2.24.md)

本补丁完整收口 Farming Server Generation 重叠时的 Native Terminal 恢复，并让 Terminal 输出中的可读绝对文件路径可以直接在 Project Files 中打开。

## 修复

- 即使旧 Farming Generation 删除了 Config 绑定的公开 Socket 链接，每个 Native PTY Host 仍可通过 Private Listener 访问。Server 重启时只有在恰好找到一个匹配的 Live Private Host 时才恢复公开链接；多个匹配项会显式失败，不会任意选择 Runtime。
- Controlled Runtime Rotation 会等待精确 Private Listener 真正退出，不能把公开链接消失误判为旧 Host 已停止。
- 保留 `v2.2.23` 的 Socket Ownership 保证：已修复的过时 Host 退出时不能删除 Replacement Host 的公开链接。

## 调整

- Terminal 渲染出的可读绝对文件路径现在可以直接在只读 Project Files 界面中打开，并支持行列定位。后端只接受该精确可读文件；目录、缺失文件与不可读路径仍会拒绝，所有写操作继续限制在 Workspace 范围内。

## 验证

- Native Private Socket 发现、Ambiguous Host 拒绝、Replacement Ownership、重启恢复、Controller Fencing 与事务式 Rotation 测试
- Project Files Terminal Link 与精确 External File Router 测试
- TypeScript Typecheck、ESLint、Backend Checks、Packaged CLI Smoke 与 Linux/macOS Release Artifact Smoke

## 升级

```bash
npm install --global farming-code@2.2.24 && farming daemon
```
