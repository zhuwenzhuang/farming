# Farming v2.2.91

[English](./v2.2.91.md)

## 未读提示与分享

- 浏览器页签显示蓝色未读圆点和未读会话数量，与 Agent 列表共用未读状态。深色浏览器外观使用 CRT 图标，浅色使用透明农夫图标。
- 浏览器通知设置说明权限要求，并提供明确的权限申请操作。
- 剪贴板访问失败或超时后，只读分享链接仍然可见，支持重试和手动复制。

## Chat 与 Agent 默认设置

- 发往其他 Agent 的消息保留紧凑、默认收起的预览，展示目标 Agent 分配的图标、名称和消息摘要。
- Chat 文件链接在验证工作区访问权限后启用，并更清楚地处理不可用目标。
- 新 Agent 继承当前全局权限默认值；明确的启动选择优先，已有 Session 的权限保持不变。
- Agent 指引减少对空闲或已完成任务的无必要协调。
- 启动验证共用一个有界的就绪等待期限。
- 并发启动 Terminal 时，操作会等待 PTY 控制权注册完成，避免连接建立期间误报控制权冲突。

## 安装

```bash
npm install -g farming-code@2.2.91 --registry=https://registry.npmjs.org
```
