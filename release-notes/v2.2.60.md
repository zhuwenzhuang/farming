# Farming v2.2.60

[简体中文](./v2.2.60.zh_cn.md)

This release makes long-running Chat sessions and mobile supervision reliable, with stricter read-only sharing boundaries.

## Reliable Chat history

- Large ACP transcripts are projected and paged inside the Host boundary before they cross the bounded IPC channel, so long-running sessions no longer fail merely because their raw provider history exceeds the transport limit.
- Transcript pages, tool-review details, media, cache checkpoints, reconnects, and abrupt Server or Host recovery preserve one authoritative session without replaying prompts.
- Farming CRT now reads lightweight session metadata instead of requesting an unbounded raw transcript.

## Production-ready mobile supervision

- Chat composing, sending, cancelling, model selection, permission actions, image preview, and long transcript navigation now remain usable across iPhone- and Android-sized layouts.
- Project Files uses touch-sized rows and responsive two-line editor actions, while large trees, long names, horizontal scrolling, previews, dirty drafts, and conflict recovery stay bounded on narrow screens.
- Share controls, drawers, menus, tabs, and status surfaces keep stable geometry across Light, Dark, and Paper appearances.

## Read-only sharing and recovery

- Read-only links now fail closed for Chat, Terminal, file mutation, and Language Server activity while retaining bounded transcript, file, and HTML preview access.
- Preview sessions are isolated by access authority and credential scope with independent quotas, so one viewer cannot evict or open another viewer's or the Owner's preview.
- Read-only Browser and update checks are observe-only: they do not persist a default Browser, force registry refreshes, create installation directories, or advance recovery state.
- Browser capability refreshes preserve a newer Owner selection across concurrent probes and retry transient source verification failures instead of caching them indefinitely.

## API compatibility

- `GET /api/agents/:id/acp-session` now returns session metadata without transcript entries by default. Clients that explicitly need the legacy raw entry array must request `?includeEntries=1`; interactive clients should use bounded transcript pages.

## Upgrade

```bash
npm install --global farming-code@2.2.60 && farming daemon
```
