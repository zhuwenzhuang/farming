# Farming v2.2.90

[English](./v2.2.90.md)

## 侧栏导航

- Agent 列表立即随侧栏滚动，包括“显示更多”展开后的长列表。切换到其他 Agent 不再需要先滚完整个文件树。
- Farming 头像上方新增固定按钮，桌面窗口缩窄时仍保留 Agent 窄栏，并记住选择；触屏设备继续使用抽屉导航。
- 文件摘要标题保持吸顶，同时不再遮挡最后一个 Agent 的拖放区域。

## 桌面与 Chat

- 桌面窄窗口保留键盘和鼠标编辑，触屏设备保持原生输入控件。
- 流式回复、轮次完成以及输入框增高或缩小时，Chat 阅读位置更准确地跟随用户的阅读意图。
- Codex Terminal 通过提供方模型目录支持按显示名切换模型，并继续核实确切的模型标识符。
- 黑洞休息效果完整遮住中心后方的文字。
- 兼容 ACP SDK 2.0，保留现有 Agent 适配器的协议版本与会话行为。

## 安装

安装命令使用 npm 公共仓库，发布后的镜像同步只处理当前版本。

```bash
npm install -g farming-code@2.2.90 --registry=https://registry.npmjs.org
```
