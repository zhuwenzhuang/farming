# Farming v2.2.46

[简体中文](./v2.2.46.zh_cn.md)

Milestone codename: **WEIGHTED**

This release removes the last avoidable release tail and balances browser verification by measured duration rather than test count.

## Faster verified delivery

- Nine isolated Chromium jobs now assign atomic test locations by measured duration, spreading known slow scenarios without adding workers or ordinary CI work.
- GitHub publication, public asset verification, and npm publication run in one continuous job, removing repeated runner scheduling and setup.
- npm remains the final public mutation and publishes only after the matching GitHub Release, tag, manifest, checksums, and required assets are publicly verified.
- Release snapshot and workflow watcher scripts replace repeated manual status polling and produce bounded failure evidence.

## Upgrade

```bash
npm install --global farming-code@2.2.46 && farming daemon
```
