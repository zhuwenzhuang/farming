# Farming v2.2.13

[English](https://github.com/zhuwenzhuang/farming/blob/main/release-notes/v2.2.13.md)

里程碑代号：**PHOSPHOR**

这个版本调整 Farming CRT 结构化 Chat 的字号、语法高亮和磷光效果，并修复 Main Agent 恢复、首次聚焦和异步 Terminal Link 问题，同时更新 README 主图。

## Highlights

- **CRT Chat Markdown 与内容限制**：Agent Reply 现在支持 GitHub Flavored Markdown、代码语法高亮、KaTeX 公式和按需加载的 Mermaid 图。Raw HTML 继续禁用，危险链接会被移除；非法图表保留源码并进入有界错误状态。
- **CRT 字号与磷光效果调整**：结构化 Chat、操作控件、元信息和 Agent Preview 使用一套字号规则。代码保留语法高亮，Preview 文字移除磷光扩散。
- **Main Agent 进程认领与焦点恢复**：启动 Main Agent 时，如果权威 ID 临时丢失，会重新认领已经运行的 Main 进程。从其他 Session 打开 Main Agent 后，会在首次权威屏幕快照就绪时保持 Terminal Input Focus，同时不会抢走用户已经主动选择的控件。
- **Terminal Link 绑定来源 Session**：延迟完成的 Terminal Link 只允许作用于创建它的 Session；Files、Navigation、Display Flow 和 Focus Recovery 改用语义或 Test ID 契约测试。
- **README 主图更新**：README 首张产品图更新为当前 CRT Billing 视图。

## Verification

- Backend 与源码契约测试套件
- TypeScript Typecheck 与 ESLint
- CRT Markdown、KaTeX、Mermaid 和 Main Agent Focus Recovery 的定向 Chromium 覆盖
- `/farming` Production Build

## Upgrade

```bash
npm install --global farming-code@2.2.13 && farming daemon
```
