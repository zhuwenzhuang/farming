# Farming v2.2.23

[简体中文](https://github.com/zhuwenzhuang/farming/blob/main/release-notes/v2.2.23.zh_cn.md)

This patch keeps live Terminal sessions reconnectable when two Farming server generations overlap during an upgrade or restart.

## Fixed

- Prevents an obsolete native PTY host from deleting the replacement host's public socket path during shutdown. Each host now listens on a private socket inode and publishes the stable config-bound path as an owned hard link, so closing the obsolete listener cannot make the replacement host unreachable.
- Preserves the existing controller-generation and transactional runtime-rotation protocol. Normal restarts still reconnect to the same PTY and reducer state; overlapping same-config startup no longer leaves a live Terminal process stranded behind an unlinked socket.

## Verification

- Native session recovery, replacement-socket ownership, controller fencing, runtime rotation, and terminal-runtime cleanup tests
- TypeScript typecheck, ESLint, backend checks, packaged CLI smoke, and Linux/macOS release artifact smoke

## Upgrade

```bash
npm install --global farming-code@2.2.23 && farming daemon
```
