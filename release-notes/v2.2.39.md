# Farming v2.2.39

[简体中文](./v2.2.39.zh_cn.md)

Milestone codename: **SIGNAL**

This release makes structured Chat feel live sooner and communicate ongoing work more clearly. It also adds Codex inline visualizations and preserves terminal mouse input across authoritative replay.

## Faster Chat startup

- A newly started ACP Chat opens while the Agent is still connecting instead of keeping the launch dialog in front of the workspace.
- Workspace selection and recent-workspace persistence no longer delay Agent startup. Failed persistence is reconciled from authoritative settings without replaying the launch.
- The transcript distinguishes initial Agent startup from history synchronization, so the visible status matches the owning runtime state.

## Live ACP activity

- In-progress turns show one compact live activity row across supported ACP providers, including thinking, reading, searching, editing, planning, fetching, terminal, and tool work.
- Typed activity icons appear only while work is live; completed transcript entries keep their existing compact presentation.
- Thought headings and plan labels are retained when they are the best available description of current work.

## Codex inline visualizations

- Codex host-directed HTML visualization resources can render inline in the Chat transcript.
- Visualization documents run in a sandboxed iframe with bounded workspace-resource access. Forms, object embedding, parent navigation, and arbitrary network connections remain blocked.
- Preview resources are created and removed with the transcript component lifecycle, including cancellation and failure paths.

## Terminal replay

- Authoritative terminal checkpoints now preserve the active xterm mouse encoding in addition to the mouse tracking protocol.
- Full-screen TUIs that use SGR mouse reporting, including Qwen Code, keep wheel and pointer input after reconnect or native PTY host rotation.
- Codex Terminal recognizes the current bordered `/status` panel, so a fresh session can materialize its resumable identity and switch to ACP Chat without losing continuity.

## Workspace layout

- The Project Files workspace pane no longer exposes a resize cursor or drag affordance. Its width remains stable while supervising Agents and files.

## Upgrade

```bash
npm install --global farming-code@2.2.39 && farming daemon
```
