# Farming v2.2.81

[简体中文](./v2.2.81.zh_cn.md)

Milestone codename: **SHRINK**

## Smaller installation

- Deliver agent-browser, ripgrep and native PTY through exact platform-selected npm packages. Only Linux x64 downloads the legacy glibc compatibility libraries.
- Remove duplicate frontend dependency trees, unused dependencies, design masters, historical artwork, debugger symbols and development-only SDK files from runtime packages. Preserve application features and license notices.
- Install prepared runtimes with npm lifecycle scripts disabled; installation does not depend on postinstall downloads.
- Show compact installation stages and download progress. Download independent runtime archives in parallel, and support `--mirror cn` with official version resolution, integrity verification and same-version fallback.

## First use

- Keep optional browser discovery quiet and the access token easy to find at startup. Hide temporary installation paths from normal progress output.
- Select Chinese by default for a fresh Config in a Chinese time zone, while preserving an explicit language preference.
- Present a missing Docker browser image as an installable capability, and show a concise refresh action when Agent Home configuration changes during loading.

## Agent supervision

- Preserve formatted pasted text and highlight editable Composer drafts.
- Stage Chat sends immediately while retaining ordered admission and safe recovery.
- Support native ACP child updates and provide clearer quota-failure diagnosis.

## Upgrade

```bash
npm install -g farming-code@2.2.81
```
