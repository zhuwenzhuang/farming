# Farming v2.2.47

[简体中文](./v2.2.47.zh_cn.md)

Milestone codename: **WATCHTOWER**

This release makes workspace sharing safer and makes release readiness visible before any public package is published.

## Safer workspace sharing

- Owners can create short-lived signed read-only links that keep HTTP and WebSocket access read-only across reconnects while the link is valid.
- Read-only guests can observe shared Browser output while input, resize, Computer control, and other mutations are rejected by the authoritative backend.
- Full-control link copying remains available from the share menu, with clearer state and responsive dark-theme presentation.

## Verified publication

- Release preparation now gates publication on focused automated, real-provider, and Computer Use acceptance for the exact candidate revision.
- Every workflow triggered by the candidate push is monitored, including Documentation and GitHub Pages when that domain changed.
- GitHub Release assets are published and publicly verified before the exact pre-smoked npm tarball becomes available.

## Upgrade

```bash
npm install --global farming-code@2.2.47 && farming daemon
```
