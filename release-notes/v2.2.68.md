# Farming v2.2.68

[简体中文](./v2.2.68.zh_cn.md)

## Workspace and navigation

- Unify Project and Agent information cards, including long titles, keyboard access,
  pointer interaction and viewport placement across Light, Dark and Paper.
- Preserve the full Agent title when renaming, and align sidebar reordering,
  selection and shared interaction behavior.
- Discover Agent Homes automatically, group them by provider, and remember model
  and Fast defaults per Home.
- Keep file auto-refresh working when another watched file is missing or invalid;
  preserve drafts and require a fresh read before reusing failed watch content.
- Reconcile stale file entries and keep directory collapse local without redundant
  filesystem requests.
- Balance Agent pane width with its available workspace.
- Preserve file rename selections when recovering focus.

## Runtime and recovery

- Recover blocked history archives and scope resumed sessions to their owning Home.
- Keep startup reads pending until the ACP runtime binding is ready.
- Preserve Agent selection and drafts through consecutive permission restarts.
- Update managed Codex ACP to 1.12.0 and Claude ACP to 0.78.0.

## Upgrade

```bash
npm install -g farming-code@2.2.68
```
