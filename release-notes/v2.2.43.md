# Farming v2.2.43

[简体中文](./v2.2.43.zh_cn.md)

Milestone codename: **TEN MINUTES**

This release removes measured CI and packaging waste while preserving the full exact-SHA, platform, runtime, artifact, and publication gates.

## Faster verified delivery

- Source CI no longer runs the installed-package postinstall that downloaded a large runtime seed into every throwaway job.
- Chromium coverage uses twelve bounded file-level shards, and failed browser jobs retain Playwright traces, screenshots, and reports.
- Linux CLI, standard app, and legacy app artifacts build in parallel; macOS CLI and app artifacts also build independently for each architecture.
- App-bundle smoke tests run against the exact retained assembly directory instead of immediately extracting the large archive that was just created.
- GitHub Release manifest generation reuses artifact checksums and avoids reinstalling the repository dependency tree.
- npm publication uses the exact pre-smoked tarball through an explicit relative path, while remaining the final public mutation after GitHub assets are verified.

## Upgrade

```bash
npm install --global farming-code@2.2.43 && farming daemon
```
