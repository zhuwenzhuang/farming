# Farming v2.2.23

[English](./v2.2.23.md)

本补丁保证升级或重启期间两个 Farming Server Generation 发生重叠时，仍存活的 Terminal Session 可以继续重连。

## 修复

- 防止过时 Native PTY Host 在退出时删除 Replacement Host 的公开 Socket 路径。每个 Host 现在监听私有 Socket Inode，并把 Config 绑定的稳定路径发布为自己持有的 Hard Link，因此关闭旧 Listener 不会再让 Replacement Host 失联。
- 保留现有 Controller Generation 与事务式 Runtime Rotation 协议。正常重启仍会重连同一 PTY 和 Reducer 状态；同一 Config 的重叠启动不再把仍存活的 Terminal Process 困在已取消链接的 Socket 后面。

## 验证

- Native Session 恢复、Replacement Socket 所有权、Controller Fencing、Runtime Rotation 与 Terminal Runtime Cleanup 测试
- TypeScript Typecheck、ESLint、Backend Checks、Packaged CLI Smoke 与 Linux/macOS Release Artifact Smoke

## 升级

```bash
npm install --global farming-code@2.2.23 && farming daemon
```
