# Farming v2.2.43

[English](./v2.2.43.md)

里程碑代号：**TEN MINUTES**

本次发布删除实测确认的 CI 与打包浪费，同时保留完整的 Exact-SHA、平台、Runtime、Artifact 和发布门禁。

## 更快的完整验证发布

- Source CI 不再执行正式安装形态的 Postinstall，避免每个一次性 Job 都下载大型 Runtime Seed。
- Chromium 使用 12 个有界文件级 Shard；Browser Job 失败时保留 Playwright Trace、Screenshot 和 Report。
- Linux CLI、标准 App、Legacy App 并行构建；每个 macOS 架构的 CLI 与 App 也分别并行构建。
- App Bundle Smoke 直接测试精确保留的 Assembly Directory，不再立即解压刚生成的大型 Archive。
- GitHub Release Manifest 复用 Artifact Checksum，并且不再重新安装整棵仓库依赖。
- npm 使用明确相对路径发布已经 Smoke 的同一份 Tarball，并继续保持在 GitHub 资产验证之后最后公开。

## 升级

```bash
npm install --global farming-code@2.2.43 && farming daemon
```
