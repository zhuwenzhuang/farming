# Farming v2.2.97

[简体中文](./v2.2.97.zh_cn.md)

## Agent models and runtimes

- Expose per-model reasoning levels and descriptions from ACP session options so switching models in Chat or Side Chat immediately updates the available thinking controls without mutating the main session.
- Keep Composer caret movement and boundary deletion stable around file and resource chips, and size the mobile model picker to fit compact screens cleanly.
- Update the managed Codex runtime to 0.167.0, the Claude ACP adapter to 0.101.0, and the Claude Agent SDK to 0.3.318.

## Navigation and sidebar controls

- Move the sidebar pin control into the top navigation toolbar and unify resource and subagent visibility under a single sidebar toggle.
- Align touch interactions, active row highlights, and focus rings across sidebar trees, tabs, settings, and dialogs in Light, Dark, and Paper themes.

## Authentication and workspace continuity

- Retain authentication tokens across in-app navigation, startup redirects, and shared links so existing browser tabs stay signed in across reloads.
- Keep previous frontend script bundles available across rolling upgrades and preserve the active workspace when an editor module fails to load.
- Reduce interactive Terminal output latency, Chat composer typing-to-send overhead, and background workspace Git refreshes while handling literal special characters cleanly in workspace search.

## Installation

```bash
npm install -g farming-code@2.2.97 --registry=https://registry.npmjs.org
```
