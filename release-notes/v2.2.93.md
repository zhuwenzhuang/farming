# Farming v2.2.93

[简体中文](./v2.2.93.zh_cn.md)

## Chat composition and quoted questions

- Chat preserves structured input through paste, draft restoration, and submission, including on HTTP installations.
- Pasting a standalone code block into an existing draft keeps it as a code block, and long file paths wrap within narrow transcripts.
- Quoted questions appear as compact reference cards after sending, with a two-line summary and an expandable full reference. Agents still receive the full context, and older messages retain their original text.
- Asking in a child Agent opens the preparation panel immediately so you can start writing. The draft and cursor transfer when the child is ready; closing or navigating away prevents a late response from reopening the panel. Uncertain creation results recover the original request instead of creating another child.
- Parent and child Goals and current plans stay above their own input areas across desktop and narrow layouts in Light, Dark, and Paper.
- Chat activity and peer messages retain settled response state and the correct session identity.
- Exact structured user input survives provider history cleanup, including whitespace and literal context-like examples. Parent cleanup settles concurrent child deletion and records a bounded failure when child cleanup cannot be proven.
- Refreshing immediately after typing preserves the latest child preparation draft.
- Update request-body parsing and schema-validation dependencies to address published security advisories.
- Expanded mobile Chat editors use the full editing area and keep attachment layouts bounded.
