# Farming v2.2.101

[简体中文](./v2.2.101.zh_cn.md)

This release aligns the Review workspace with Gerrit conventions, improves Codex model handoff and session diagnostics, and refines Terminal composer and transcript copy behavior.

## Improvements

- Align the Review workspace with Gerrit: structured file list columns with header, totals, status pills, proportional change bars, auto-marking opened files as Reviewed, a single line-number gutter in unified diff view, Gerrit-style hunk context headers, and both inline copy buttons and native drag-select copying for file paths.
- Support model-advertised Ultrafast service in Codex Chat and Terminal, and carry the selected Chat model, reasoning effort, and speed profile when switching into Terminal.
- Keep the Terminal composer collapsed by default per view, open it automatically when pasting images into Terminal, float activity previews at the top right, and support rich HTML copying from Chat transcripts as well as clickable links in the Composer.

## Fixes

- Preserve question and answer history across sessions and deduplicate Codex answer receipts.
- Omit inline turn history when forking a Codex session so forked threads paginate cleanly without triggering deprecation warnings.
- Scope shared Codex app-server diagnostics to the session that triggered them, and include prepared adapter bundles in ACP runtime host identity checks.

## Managed runtimes

- Update Codex to 0.170.0, Claude ACP to 0.108.1, and the ACP SDK to 2.8.0. Codex ACP remains at 2.7.0, and the managed Claude runtime remains at 0.3.326.

## Installation

```bash
npm install -g farming-code@2.2.101 --registry=https://registry.npmjs.org
```
