# Farming v2.2.63

[简体中文](./v2.2.63.zh_cn.md)

Milestone codename: **UNISON**

Unison brings related Farming Code controls under one shared design contract,
with consistent behavior across Light, Dark, Paper, and compact layouts.

## Consistent controls

- Project, Agent, file, Review, Composer, Browser, and Computer menus share
  typography, spacing, corners, and interaction-state styling.
- File trees, Changes, and Open Editors use the same file-label density.
  Auxiliary Review links retain their intended text hierarchy, and more-action
  controls reuse the same icon.
- Open Editors keeps its seven-row cap at each density without an empty
  scrollbar gutter shifting its actions. Submenus fit their rendered height.
- Selectors, Review numeric fields, and dialog actions share their control
  specifications. Compact Review forms stay inside the dialog boundary.
- Shared design ownership checks and cross-theme browser scenarios help prevent
  page-local styling from reintroducing inconsistent controls.

## Navigation and supervision

- Reveal in Explorer in the file toolbar locates the current file in the left
  tree, including from Markdown preview, without reopening it or changing its
  unsaved contents. It also opens the mobile sidebar when needed.
- Virtual file trees use one native scroll surface, avoiding row drift caused
  by independently synchronized inner scrolling and transforms.
- Long Project names truncate before their persistent mobile actions.
- Narrow-screen file conflict actions wrap without reducing touch targets.
- File menus and their submenus remain visible and clickable beyond the mobile
  sidebar edge.
- Wide Markdown equations scroll within the reading column, with equation
  numbers kept clear of the formula instead of clipping or overlapping it.
- Closing New Agent cannot steal focus from a subsequent menu or dialog.
- Mobile Agent resource disclosure and resource actions remain accessible after
  initial load, reload, and viewport changes.
- Sidebar and Git history surfaces preserve coherent focus and selection;
  search distinguishes directories from files.
- Bounded interaction diagnostics correlate browser and server observations
  without retaining typed input, and remain restricted to instance owners.

## Runtime reliability

- Terminal model switching supports Codex's two-level model picker while
  preserving bounded cancellation and the existing picker behavior. Models
  outside a narrow Terminal's visible list remain reachable by keyboard navigation.
- Concurrent publication of the same Terminal socket no longer interrupts
  startup; a socket owned by a different listener is still rejected.
- Completed backend commands cannot recreate progress watchdogs from late
  buffered output.
- Cancelling a remote bootstrap download stops its exact downloader before
  waiting and cleaning temporary files, including unresponsive downloaders.

## Upgrade

```bash
npm install -g farming-code@2.2.63
```
