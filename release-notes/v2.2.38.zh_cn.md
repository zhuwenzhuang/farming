# Farming v2.2.38

[English](./v2.2.38.md)

里程碑代号：**MIDDLE**

本次发布引入两项初始能力：Farming 桌面应用和语言服务器状态界面。两者均为刻意早期发布，需要更多真实使用场景的打磨才能被视为成熟。我们现在发布它们，以便日常使用能够驱动后续改进。

## 桌面应用（初始）

- Farming Desktop 是一个 Electron 外壳，嵌入与浏览器体验相同的后端和前端，提供原生窗口管理和专属应用图标。
- 桌面应用拥有可取消的启动资源，在显示主窗口前验证后端协议就绪，并为远程连接围栏 SSH 隧道就绪状态。
- 环境切换是原子性的：桌面应用可以指向不同后端而不泄漏前一个会话的状态。
- 远程服务器引导下载有界限，中断的下载会被清理。
- 这是一项初始能力。窗口生命周期、更新流程和平台特定行为方面的粗糙边缘只会在持续日常使用中暴露。

## 语言服务器状态（初始）

- 专属语言服务器图标和状态界面显示 LSP 服务器是按需待机还是已活跃连接。
- 目标绑定生命周期管理协调多源注册，并权威地清理过期绑定。
- 停滞的桥接请求被围栏和规范化处理，挂起的语言服务器不会无限期阻塞编辑器。
- 诊断随服务器启停出现和消失；文件切换和重连路径已覆盖。
- 这是一项初始能力。大型工作区、多个并发服务器和非常规 Provider 配置的真实项目将推动下一轮加固。

## Codex 终端身份

- Codex 终端会话现在通过内部 `/status` 端点报告精确身份，而不再从终端文本模式推断。
- 历史身份扫描已移除。会话身份由 Provider 适配器权威提供，消除了一类过期身份不匹配问题。
- 终端和 ACP 运行时所有权分离：每种运行时独立解析其可执行文件。

## 历史与性能

- Agent 会话和工作区状态更新已精简，减少冗余状态转换和重渲染。
- 标题所有权元数据跨重启持久化，会话标题在恢复后无需重新派生。
- Provider 会话标题在重连时刷新，而非显示过期标签。

## 工作区与 Agent 行 UI

- Agent 行在快速状态更新期间不再闪烁或重排。
- 项目操作限定在标题悬停范围内，减少密集工作区列表的视觉噪音。
- 空的 Agent 资源被隐藏；Agent 发送的截图在对话中内联显示。
- 组合器附件和终端状态处理在分叉和恢复流程中已修正。
- 活跃 Agent 标题淡出和计划转录排版已优化。

## 语音实验已移除

- 实时语音实验已从主线回退。已发布的语音界面恢复到之前的稳定状态。

## 工程可靠性

- ACP 显示和悬停预览已优化；实时活动显示在引导对话下方。
- 插件库存断连显式呈现，而非静默降级。
- 键盘焦点在菜单、设置和侧边栏交互中得到保留。
- 桌面启动竞态由有界限的看门狗计时测试覆盖。
- 生成边界验证拒绝空白或仅含空白的可执行路径。

## 升级

```bash
npm install --global farming-code@2.2.38 && farming daemon
```
