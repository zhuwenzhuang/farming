[English](./v2.2.84.md)

里程碑代号：**BRIDGE**

## 旧版 Linux 兼容性

- 在旧版 Linux 上，Workspace 命令辅助进程使用 Farming 私有 Node.js 加载器和兼容库，避免缺少 GLIBC、GLIBCXX 的报错。
- 通过同一兼容运行时读取用户 Shell 环境，覆盖 Node.js 将加载器报告为自身可执行文件的情况。
- 安装目录支持相对路径，例如 `--dir ./farming`。

## 升级

```bash
npm install -g farming-code@2.2.84
```
