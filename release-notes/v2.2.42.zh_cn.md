# Farming v2.2.42

[English](./v2.2.42.md)

里程碑代号：**FAST**

本次发布在不减少 Package 与平台验证要求的前提下，让 Farming 的发布更快、更安全，也更容易定位失败。

## 发布可靠性

- CI Browser Check 改为使用独立 Frontend Artifact，不再等待完整仓库检查；Chromium 覆盖分配到更多 Shard，更早返回结果。
- Release Artifact Preparation 与 Exact-SHA CI Gate 并行运行，不再等 CI 完成后才开始构建。
- 同一 Revision 已经通过 CI 后，Linux 和 npm 发布 Job 不再重复普通仓库检查。
- npm Package Smoke 与正式发布使用同一份字节完全一致的 Tarball，并验证 SHA-256 Digest。
- npm 发布前先公开验证 GitHub Release、Tag、资产、Manifest 和 Checksum；npm 现在是最后一个公开发布步骤。
- Release Monitoring 直接生成有界 Failure Bundle，不再要求 Agent 反复轮询。

## 发布操作

- 仓库内新增 Farming Release Skill，覆盖无问题发布、简单问题快速修复，以及单个产品领域存在较大设计阻塞时的并行收敛。
- 发布时间统一包含调查、修复、重试、CI、Artifact Preparation 和正式发布，不再把失败尝试排除在统计之外。

## 升级

```bash
npm install --global farming-code@2.2.42 && farming daemon
```
