# Farming v2.2.44

[简体中文](./v2.2.44.zh_cn.md)

Milestone codename: **UNDER TEN**

This release fits verified delivery to the measured remote runner capacity and removes the remaining serialized publication work.

## Balanced CI and publication

- Chromium uses nine test-balanced shards with one worker each, avoiding both stateful in-job concurrency and runner queueing during a release.
- Release staging prepares verified checksums and metadata while exact-SHA CI finishes, then enforces the CI gate immediately before creating a tag or draft release.
- App artifacts carry their already verified release metadata, so staging no longer re-reads four large compressed archives.
- npm publication suppresses the large package-content notice listing and does not reinstall the npm CLI in the final publication job.

## Upgrade

```bash
npm install --global farming-code@2.2.44 && farming daemon
```
