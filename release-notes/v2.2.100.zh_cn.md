# Farming v2.2.100

[English](./v2.2.100.md)

此版本修复文件导航与对比显示，避免 Agent 活动遮挡对话和输入框，并改善运行中打开 Review 的安全性。

## 修复

- 对话中的目录链接可打开对应 Project，包括此前未挂载的工作树根目录。
- 文件 Diff 在切换可比较文件和刷新后保持开启，直到手动关闭。Diff 菜单统一选择上下或左右布局，窗口宽度变化不再自动切换；自动换行作用于两侧，并移除行号旁未使用的空白栏。
- Goal、计划和 Browser 活动显示在对话与输入框之间，不再遮挡内容。
- `farming review` 复用正在运行的 Server，保留其 Agent；端点参数冲突或进程身份不符时明确报错。
- 改善重复 ACP 答复、实时会话通知、终端路径导航和请求生命周期处理。
- 终端启动后正确显示 CRT 中的 Main Agent；终端未报告当前目录时仍可打开相对文件与目录链接；Blame 和变更列表分页失效时从头重建快照。
- 并发创建 Agent 时，避免将原生 PTY 锁的短暂空快照误判为损坏状态。

## 托管运行时

- Codex 更新至 0.169.0，Codex ACP 更新至 2.7.0，Claude ACP 更新至 0.108.0，ACP SDK 更新至 2.7.0；托管 Claude 运行时随适配器更新至 0.3.326。

## 安装

```bash
npm install -g farming-code@2.2.100 --registry=https://registry.npmjs.org
```
