# Farming v2.2.103

[English](./v2.2.103.md)

- 为项目文件和目录搜索引入常驻内存索引，支持任意长度模糊匹配、多词组合搜索、Smart Case 排序与最近访问加权。
- 新增基于 SQLite FTS5 的历史 Agent 会话全文检索（支持中文与跨轮次多词匹配），并在结果中展示高亮上下文摘要。
- 新增独立的项目代码内容搜索弹窗（`Shift+Cmd+F` / `Ctrl+Shift+F`），支持区分大小写、全词匹配、正则表达式、按文件折叠分组与精准跳行。
- 在每个 Agent 轮次前后自动记录隐藏 Git Ref 检查点，支持查看单轮精确变更 Diff 并一键安全回滚（恢复前自动创建安全备份）。
- 优化移动端 Composer 菜单、光标与对话内容的可见性，避免小屏视口裁切。
- 更新托管 Codex ACP 至 2.12.1、Claude ACP 至 0.113.0、Claude Agent SDK 至 0.3.331、ACP SDK 至 2.12.0。

## 安装

```bash
npm install -g farming-code@2.2.103 --registry=https://registry.npmjs.org
```
