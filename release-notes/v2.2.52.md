# Farming v2.2.52

[简体中文](./v2.2.52.zh_cn.md)

Milestone codename: **REACH**

This release makes the Farming Browser Connector consistently available on ordinary websites, restores Chrome pages that Memory Saver has discarded before an Agent attaches, updates the managed Codex and Claude ACP adapters, clarifies Agent selection while editing files, and publishes the Language Server guide with refreshed product screenshots.

## Use Agents on ordinary Chrome pages

- Farming Browser Connector now requests Chrome's all-sites host access, so Chrome shows it under **Full access** and Agents can read and operate any ordinary HTTP or HTTPS page without per-site approval after pairing.
- Pairing remains limited to an authenticated Farming page on localhost or `127.0.0.1`; `chrome://`, incognito, Chrome Web Store, and other browser-restricted pages remain unavailable.
- Connector startup now handles an unavailable Farming backend as a bounded reconnect state instead of leaving an extension error, while pairing always targets the explicit Farming tab instead of whichever tab happens to be active.
- When Chrome Memory Saver has discarded a selected page, Farming restores that exact tab, revalidates its URL and access, and then opens the debugger session. A unique URL match tolerates Chrome's transient empty title during restoration.

## Clearer workspace selection

- Opening a file clears the Agent row selection while the editor owns the main pane, avoiding two simultaneous active surfaces.
- Leaving the editor preserves the selected Agent in other Farming views, and returning from an external file link restores the source Agent predictably.

## Current managed Provider adapters

- The managed Codex ACP adapter is updated to 1.4.0 and the managed Claude ACP adapter to 0.69.0, retaining Farming's reviewed Codex integration patch and exact bundled-runtime hashes.
- Both upstream adapter releases add changed-file reporting to their AIR extension while preserving their existing ACP SDK and managed Claude SDK compatibility boundaries.

## Documentation

- The Language Server guide is now part of the main bilingual Code documentation, with setup, navigation, troubleshooting, and verified screenshots for settings and call hierarchy.
- Product screenshots across Farming Code, CRT, Browser, sharing, mobile, appearance, Pets, and usage views have been regenerated at higher resolution and are now checked by stronger asset validation.

## Upgrade

```bash
npm install --global farming-code@2.2.52 && farming daemon
```
