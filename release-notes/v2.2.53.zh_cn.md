# Farming v2.2.53

[English](./v2.2.53.md)

里程碑代号：**FLOW**

本次发布显著提升 Project Files 的速度与可预测性，加入 Agent 动态置顶，改善 Browser 恢复与 CRT Session 状态，并统一打磨 Farming Code 的视觉表现和只读分享体验。

## 更快、更稳定的 Project Files

- Workspace 文件控制现在复用主认证 WebSocket；请求所有权、取消、超时、重连和文件监听由同一条权威传输链路承载。
- 文件打开竞态按精确 Intent 隔离，过期的 Read 与 Language Server 响应会被取消；保留的 Editor Model 让重复切换 Tab 和文件无需再次读取即可立即显示。
- 大型展开树的选中反馈不再进入昂贵的整树渲染路径。持久化目录只在 Files 可见时 Hydrate，使用有界并发，并在 Workspace 切换时取消失效工作。
- 超大 Markdown Preview 会虚拟化屏幕外 Section；文件 Row 的鼠标、键盘、范围选择、紧凑目录、Header 和 Diff 交互均由 Production-shaped 压力场景覆盖。
- 渐进式 **显示更多** 在 Agent 或 Session 被选中、Reveal 和重新排序时保持稳定批量大小与键盘行为。

## 更好的 Agent 监督体验

- 动态置顶可以把活跃 Agent 保持在 Project 前部，同时保留显式持久顺序与恢复状态。
- Farming CRT 现在通过共享 Agent Protocol 同步 Pi Session 状态，生成的 Bridge Type 与 Backend State 保持一致。
- 当相关变更已经提交后，ACP Review Action 不再继续提供 Commit 操作。

## Browser、Appearance 与分享打磨

- Browser Connector 在 Farming Backend 短暂中断后可以自动重连，并提供明确的用户控制开关。
- Light、Dark 和 Paper Appearance 恢复了 Tab、文件图标、Transcript、Diff 与 Action Surface 的语义颜色。
- 只读分享提示会更清楚地区分复制、链接和访问失败；锚定的复制反馈会保持贴近触发它的操作。

## 升级

```bash
npm install --global farming-code@2.2.53 && farming daemon
```
