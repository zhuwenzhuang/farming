# Farming v2.2.82

[English](./v2.2.82.md)

里程碑代号：**SHRINK**

## Agent 通信

- 在 Agent 活动区展示 Codex 原生同伴消息，包括接收方、正文预览，以及发送中、完成、失败或取消状态。读取历史时也保留同样的展示。
- 正文相同的多次发送分别保留，发送状态变化时保持已展开的证据。
- 将 Farming CLI 查找 Agent 的调用显示为可检查的活动；查找命令完成不代表已经找到同伴。
- 按 Provider、Agent Home 和 Session 精确识别已有同伴，同步最新名称并打开正确的 Agent，不将同伴误认为子会话。

## 升级

npm install -g farming-code@2.2.82
