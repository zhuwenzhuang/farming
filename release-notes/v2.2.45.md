# Farming v2.2.45

[简体中文](./v2.2.45.zh_cn.md)

Milestone codename: **STRIPED**

This release distributes slow browser scenarios across the available runners while preserving one-worker isolation and the verified npm publication path.

## Duration-balanced verification

- CI discovers exact Playwright test locations and stripes adjacent location groups across nine Chromium jobs, preventing one product domain from owning a slow contiguous shard.
- Every Chromium job still uses one worker; generated tests sharing one source location remain an atomic group.
- npm publication keeps the current npm CLI required by OIDC Trusted Publishing while suppressing the large package-content notice listing.
- Release staging continues to overlap verified asset preparation with the tail of exact-SHA CI.

## Upgrade

```bash
npm install --global farming-code@2.2.45 && farming daemon
```
