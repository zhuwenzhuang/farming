# Farming v2.2.33

[简体中文](./v2.2.33.zh_cn.md)

This patch release tightens Farming Code's sidebar interactions and npm delivery path.

## Fixes

- Browser and Computer Resources now share the same sidebar section, row, hover, focus, active, action-reveal, and empty-state presentation while retaining their own icons and actions.
- Project Files rows, sticky context, editor tabs, and nested tree interactions use more consistent spacing, colors, focus, and reveal behavior.
- Agent Home ordering now uses one keyboard-operable drag handle, and opening an Agent Home configuration mounts and reveals it through the normal Project Files path.
- Current-page refreshes retain the existing presentation until the fresh authoritative result arrives, avoiding unnecessary blank states.

## Packaging

- The npm package bundles its production dependencies and reports bounded startup dependency-download progress, improving fresh installation and startup visibility.

## Upgrade

```bash
npm install --global farming-code@2.2.33 && farming daemon
```
