# Farming v2.2.83

[简体中文](./v2.2.83.zh_cn.md)

Milestone codename: **CHORUS**

## Clearer Agent conversations

- Show received Agent messages as ordinary Chat bubbles, with a separate avatar and smaller sender label. Preserve the name recorded when the message arrived.
- Group consecutive messages from the same Agent and show the group's recorded time. Replies, tool activity and sender changes keep conversations clearly separated.
- Recover supported incoming Codex and Claude messages from the recipient's own history. When Codex supplies an encrypted body without readable text, show a short explanation instead of ciphertext.

## Installation and startup

- Re-running the directory installer checks the requested version, updates when needed, and keeps configuration and history. An already current installation reports that no update is needed.
- Starting an already running instance explicitly stops that instance and its Agents, then starts it again. Installation output includes complete foreground, background and stop commands.
- Accept Node.js 23 alongside Node.js 22.13 and newer.

## Upgrade

```bash
npm install -g farming-code@2.2.83
```
