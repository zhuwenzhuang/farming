# Farming v2.2.90

[简体中文](./v2.2.90.zh_cn.md)

## Sidebar navigation

- Agent lists scroll immediately with the sidebar, including long lists expanded with Show more. Reaching another Agent no longer requires scrolling through the file tree first.
- A pin button above the Farming avatar keeps the compact Agent rail visible when a desktop window becomes narrow. The preference is remembered; touch devices retain their drawer navigation.
- File summary headers retain their sticky position without covering the last Agent's drag target.

## Desktop and Chat

- Narrow desktop windows retain keyboard and mouse editing, while touch devices keep their native input controls.
- Chat reading follows the user's position more consistently as replies stream, turns complete, and the input box grows or shrinks.
- Codex Terminal model changes recognize an idle composer even when the CLI displays a model name instead of its identifier.
- The black-hole rest effect fully covers text behind its center.
- ACP SDK 2.0 compatibility preserves existing Agent adapter protocol versions and session behavior.

## Installation

Installation commands use the public npm registry, and release mirror synchronization targets only the current release versions.

```bash
npm install -g farming-code@2.2.90 --registry=https://registry.npmjs.org
```
