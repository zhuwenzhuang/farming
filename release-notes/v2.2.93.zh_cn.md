# Farming v2.2.93

[English](./v2.2.93.md)

## Chat 输入与引用提问

- Chat 在粘贴、草稿恢复和提交时保留结构化输入，也支持通过 HTTP 访问的实例。
- 引用提问发送后显示紧凑引用卡片，提供两行摘要和全文展开。Agent 仍收到完整上下文，历史消息保留原文。
- 在子 Agent 中提问会立即打开准备面板，可先输入问题。子 Agent 就绪后保留草稿和光标；关闭或导航后，迟到的响应不会重新打开面板。创建结果不明时核对原请求，不会重复创建子 Agent。
- 父、子会话的 Goal 和当前计划分别位于自己的输入区上方，适用于桌面和窄屏的 Light、Dark、Paper 外观。
- Chat 活动与同伴消息保留已结束的响应状态和正确的会话身份。
- 输入后立即刷新也会保留最新的子 Agent 准备草稿。
- 更新请求体解析和结构校验依赖，修复已公布的安全公告问题。
- 移动端 Chat 展开编辑器使用完整编辑区域，附件布局保持在限定高度内。
