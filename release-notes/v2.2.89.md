# Farming v2.2.89

[简体中文](./v2.2.89.zh_cn.md)

## Faster interactions

- Sending Chat messages and marking Agents read no longer wait for routine state persistence. Background snapshots coalesce updates and reject stale writes while lifecycle operations retain their durability requirements.
- Agent startup collects the shell environment asynchronously, keeping other sessions responsive while login scripts run.
- Streaming replies no longer rerender completed turns unnecessarily; Fork continues to use the latest conversation revision.
- Routine recovery checkpoints retain lightweight metadata and use the Agent provider's native conversation history instead of duplicating the transcript.

## Clearer failures and reliable handoffs

- Chat failures show their cause and recovery guidance directly in the conversation and Agent preview, including usage-limit errors.
- Handoff remembers its own Chat or Terminal choice when reopened. Ordinary new-Agent creation continues to use Provider defaults, and the current mode remains consistent while switching providers within a dialog.
- Antigravity history replay preserves incoming Agent-message provenance without duplicating the message.

## Upgrade

```bash
npm install -g farming-code@2.2.89
```
