# Farming v2.2.86

[English](./v2.2.86.md)

## 原生文本编辑

- Chat、Terminal 和侧边会话统一使用原生纯文本编辑，覆盖紧凑和展开输入。Markdown 保持字面文本，不再改变输入字体和样式。
- 复制渲染后的回答时粘贴其纯文本，保留缩进、换行和原生撤销。长文本继续使用上下文卡片，并能将完整原文恢复到输入框。
- 移动端文件源码支持原生触摸选择和复制，桌面端保留现有编辑器。
- 文件行链接和搜索导航定位到可见的移动端源码，在切换布局后继续保持正确位置。

## 会话连续性

- 保持长 Chat 历史完整，在重新加载和后台更新后恢复阅读位置。
- 保留源码和头文件扩展名配对等文件引用简写。
- Terminal 会话交接自动提交上下文，并在打开下一个 Agent 时记住选择的启动模式。
- 从终端渲染状态确认 Codex Terminal 的 Fast 模式切换，避免切换成功后仍误报超时。

## 升级

```bash
npm install -g farming-code@2.2.86
```
