# Farming v2.2.58

[简体中文](./v2.2.58.zh_cn.md)

This patch release makes Agent list actions reliable and visually consistent, and restores complete keyboard editing in shared Browser control.

## Reliable Agent actions

- Archive now works for historical read-only Agent entries even when no live runtime currently owns the Session.
- Archiving shows a compact notice near the top of Farming with the affected Agent identity, plus working View, Undo, and failure feedback.
- Pin, notification, and archive controls now use consistent icon geometry and neutral state styling instead of introducing a separate blue selected state.

## Complete shared Browser keyboard editing

- Backspace and Delete are forwarded correctly through shared Browser control, so existing text can be removed as well as appended.
- Focused browser coverage verifies both editing keys without changing unrelated key handling.

## Consistent appearance acceptance

- Sidebar selection and scrollbar surfaces use the shared interaction-state language.
- Archive notice success, hover, keyboard focus, disabled, and error states are covered in Light, Dark, and Paper appearances.

## Upgrade

```bash
npm install --global farming-code@2.2.58 && farming daemon
```
