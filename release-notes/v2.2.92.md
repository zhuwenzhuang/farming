# Farming v2.2.92

[简体中文](./v2.2.92.zh_cn.md)

## Chat and mobile navigation

- Returning to a scrolled Terminal keeps unseen output unread until you jump to the latest output.
- Browser tabs reliably show the unread icon. Titles keep the instance name first and describe the unread count in the selected UI language.

- Inline Chat visualizations render correctly when Farming is opened through an HTTP address.
- Mobile unread navigation supports swiping to the next unread Agent while preserving drafts. Each navigation action refreshes its return window, and share-copy errors appear beside the selected link.
- Project actions share the focused row surface across Light, Dark, and Paper. Product documentation includes refreshed screenshots for these appearances.
- Chat file links remain stable during access checks, and symlinked Projects use one identity across Agents and history.
- Rejected Fork and read-only language requests settle explicitly instead of leaving operations pending.

## Runtime and recovery

- Terminal recovery releases abandoned rotation preparations. Generation allocation uses exact process ownership to prevent an older writer from overwriting newer state.
- A Desktop stop or deletion rejects Browser acquisitions that have not yet received a lease.
- Superseded update operations cannot roll back or restart an obsolete installation.
- Agent updates reject unsupported protocol fields. agy retains accurate response, tool-completion, and configuration state after interruption.
- Claude interactive resume preserves native session selection instead of injecting a new Session identity.

## Managed Agent maintenance

- Update managed Codex to 0.164.0, Claude ACP to 0.94.0, and the ACP SDK to 2.0.1. The Claude runtime follows its adapter-owned SDK version, 0.3.303.
