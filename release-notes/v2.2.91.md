# Farming v2.2.91

[简体中文](./v2.2.91.zh_cn.md)

## Attention and sharing

- Browser tabs show a blue unread dot and the number of unread conversations, using the same unread state as the Agent list. Dark browser chrome uses the CRT icon; light chrome uses the transparent farmer icon.
- Browser notification settings explain permission requirements and provide an explicit permission request.
- Read-only share links remain visible when clipboard access fails or times out, with retry and manual-copy controls.

## Chat and Agent defaults

- Outgoing Agent messages retain compact, collapsed previews with the target Agent's assigned icon, name and message summary.
- Chat file links are enabled after workspace access is verified, with clearer handling of unavailable targets.
- New Agents inherit the current global permission default; explicit launch choices take priority and existing Sessions retain their permissions.
- Agent instructions discourage unsolicited coordination with idle or completed peers.
- Startup verification uses one bounded readiness deadline.
- Concurrent Terminal launches wait for PTY controller registration before issuing operations, avoiding false ownership-conflict errors during connection setup.

## Installation

```bash
npm install -g farming-code@2.2.91 --registry=https://registry.npmjs.org
```
