# Farming v2.2.89

[English](./v2.2.89.md)

## 更快的交互

- 发送 Chat 消息和标记 Agent 已读不再等待常规状态持久化。后台快照合并更新并拒绝过期写入，生命周期操作继续保留原有持久化要求。
- Agent 启动改为异步采集 Shell 环境，登录脚本运行期间其他会话仍可响应。
- 流式回复不再使已完成轮次发生不必要的重新渲染；Fork 仍使用最新的会话版本。
- 常规恢复检查点保留轻量元数据，使用 Agent Provider 的原生会话历史，避免重复保存完整对话。

## 更清晰的失败提示与可靠交接

- Chat 失败原因和恢复建议直接显示在对话及 Agent 预览中，包括用量限制错误。
- 在新建 Agent 和交接对话框内切换 Provider 时，保留当前选择的 Chat 或 Terminal 模式；重新打开对话框时使用配置的默认值。
- Antigravity 历史回放保留收到的 Agent 消息来源，且不会重复显示消息。

## 升级

```bash
npm install -g farming-code@2.2.89
```
