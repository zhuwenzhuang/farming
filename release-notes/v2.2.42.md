# Farming v2.2.42

[简体中文](./v2.2.42.zh_cn.md)

Milestone codename: **FAST**

This release makes Farming releases faster, safer, and easier to diagnose without reducing package or platform verification.

## Release reliability

- CI browser checks start from a dedicated frontend artifact instead of waiting behind the complete repository check, and Chromium coverage is distributed across more shards for earlier feedback.
- Release artifact preparation now runs in parallel with the exact-SHA CI gate instead of waiting for CI before starting.
- Linux and npm publication jobs no longer repeat the ordinary repository check after the same revision has already passed CI.
- npm package smoke and publication use one byte-identical tarball with a verified SHA-256 digest.
- GitHub Release, tag, assets, manifest, and checksums are publicly verified before npm publication begins; npm is now the final public release step.
- Release monitoring produces a bounded failure bundle instead of requiring repeated Agent polling.

## Release operations

- The repository includes a Farming Release Skill covering normal releases, bounded quick fixes, and parallel convergence when one product domain has a larger design blocker.
- Release timing includes investigation, fixes, retries, CI, artifact preparation, and publication instead of excluding failed attempts from the result.

## Upgrade

```bash
npm install --global farming-code@2.2.42 && farming daemon
```
