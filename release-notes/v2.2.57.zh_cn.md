# Farming v2.2.57

[English](./v2.2.57.md)

本次补丁发布移除了 Project Files 中与滚动联动的显示效果，并收紧了多处恢复与活动状态边界。

## 稳定的 Project Files 导航

- Project Files 滚动时不再渲染 Sticky Ancestor Row，消除了拖动侧栏分隔条时 `workflow` 等目录行可能闪动的反馈链路。
- 深层文件树会限制视觉缩进并为名称保留最小宽度，确保实际文件名可见。聚焦 Browser Test 覆盖了反复双向拖动、滚动、搜索与重载。

## 真实的 Agent 活动状态

- ACP Turn 没有 Final Reply 时会被显式标记，不再显示为已正常完成；History Replay 与 Recovery 后也保持这一语义。
- 长时间运行的 Command Activity 使用最新权威事件时间，显示的活动时长不会偏离 Runtime Transcript。
- ACP Restart 与 Executable Fixture 不再继承无关测试环境，避免外部 Recovery 设置改变测试行为。

## 有界恢复与休息提醒

- 过期 Browser Resource 现在执行有界、校验 Owner 的恢复，并显式显示 Reconnecting 或 Failed，不再无限期停留在模糊状态。
- Rest Reminder 只有在显式有效启动后才进入 Resting，Timer 与 Recovery Event 不会再用休息遮罩盖住正在运行的 Agent。
- 受管 Agent 依赖更新至 ACP SDK 1.4.0 与 Codex Runtime 0.149.1，并由生成的 Runtime Manifest 固定所有受支持平台的 Artifact。

## 升级

```bash
npm install --global farming-code@2.2.57 && farming daemon
```
