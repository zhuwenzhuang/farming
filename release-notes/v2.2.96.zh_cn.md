# Farming v2.2.96

[English](./v2.2.96.md)

## Agent 连续性

- 交接继承来源 Agent 的名称，并使用与 fork 相同的编号规则。仍可指定名称，并发 fork 和交接会预留不同名称。
- 原生子会话显示在 Chat 协作面板中。Antigravity 子会话在没有可用状态时保持隐藏，收到权威状态后再显示；传输恢复后不再残留过期的失败状态。
- 验证修改一个 Codex Chat 的模型不会影响并发会话各自的选择，覆盖历史加载与重连。
- ACP SDK 更新至 2.4.0。

## 导航与富内容

- 分享链接重定向至标准 URL 时保留认证令牌，历史导航稳定落到所选会话。
- 文件链接按准确的工作区路径解析；Mermaid 在流式输出和拖动图表时保持稳定。
- 以只读方式打开外部文件，不再将文件系统根目录挂载成 Project，也不再请求无关的资源管理器目录树。
- 分享文件链接等待 Project 和 Agent 列表加载完成后再打开，避免启动时将项目文件误判为外部只读文件。

## Linux 稳定性

- 将旧 Linux 的兼容库替换为 Debian 修补版 glibc 2.28，修复可能导致 Farming 无响应的读写锁死锁。
- App bundle 和 npm image 使用同一份经过校验的运行库。升级安装到不可变的运行库目录，不覆盖使用中的库，也不会复用旧版本。

## 安装

```bash
npm install -g farming-code@2.2.96 --registry=https://registry.npmjs.org
```
