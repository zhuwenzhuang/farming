# Farming v2.2.66

[简体中文](./v2.2.66.zh_cn.md)

## Model controls

- The model matrix follows the runtime's advertised catalog across model
  generations, including Astra. The Ultra track, hit area, knob travel, and
  energy fill now adapt to the matrix height on desktop and mobile.

## Mobile editing and previews

- Expand Chat and Terminal input in place to edit long drafts while preserving
  text, selection, attachments, and native touch scrolling.
- Preserve Chinese input composition and transcript reading position as content
  updates. Render standard Markdown image sources through the workspace file
  API and preview authorized workspace HTML visualizations inline.

## Runtime maintenance

- Update managed Codex to 0.153.4, Codex ACP to 1.10.0, and Claude ACP to
  0.75.1, including Astra catalog visibility and Claude fork loading fixes.

## Upgrade

```bash
npm install -g farming-code@2.2.66
```
