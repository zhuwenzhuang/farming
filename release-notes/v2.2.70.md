# Farming v2.2.70

[简体中文](./v2.2.70.zh_cn.md)

Milestone codename: **WORKSHEET**

Worksheet adds spreadsheet inspection, Subagents, quoted follow-ups and inline
visualizations to the unified Project and Agent workspace.

## Subagents and quoted follow-ups

- Use the plus action on an Agent row to create or reopen a persistent Subagent.
  The parent Agent and Subagent initially share the workspace width equally and
  keep independent drafts and conversations.
- Type `/side` in a parent Chat to open the same Subagent without sending the
  command text to the Agent.
- Select text in an Agent answer to quote it into the current Chat or ask about
  it in the Subagent. Existing Agent-created child sessions continue to open in
  the same right-side detail area.

## Spreadsheet preview

- Open XLSX, CSV and TSV files directly in the File Viewer. Switch sheets, jump
  to a cell address, find text, copy a selection and quote it in Chat with its source.
- Show merged cells, column widths, hidden-content markers and formula cache
  warnings. Preserve identifiers and date-like text in CSV/TSV instead of
  silently coercing their values.
- Parse workbooks in a cancellable Worker with bounded loading and parsing.
  Reject invalid or oversized XLSX archives before preview and release preview
  resources when the file changes or closes.
- Support Light, Dark and Paper appearances with a lazily loaded, open-source
  SheetJS CE and VTable viewer. Preview is read-only and does not recalculate
  formulas or modify the original workbook.

## Inline visualizations and browser lifecycle

- Render Agent-created HTML visualizations directly in Chat with scoped local
  assets, adaptive sizing, fullscreen viewing and Light, Dark and Paper themes.
- Capture browser frames on demand and clean up Farming-owned Chrome processes
  when their sessions close.
- Bundle a pinned agent-browser repair that continuously drains Chrome's stderr,
  preventing long-running background browsers from blocking on a full pipe and
  triggering excessive CPU usage. Missing patched runtimes fail explicitly
  instead of falling back to the affected upstream binary.

## Upgrade

```bash
npm install -g farming-code@2.2.70
```
