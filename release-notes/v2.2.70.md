# Farming v2.2.70

[简体中文](./v2.2.70.zh_cn.md)

Milestone codename: **WORKSHEET**

Worksheet adds spreadsheet inspection to the same workspace that now supports
Side Chat and the unified Project and Agent information cards from v2.2.69.

## Spreadsheet preview

- Open XLSX, CSV and TSV files directly in the File Viewer. Switch sheets, jump
  to a cell address, find text, copy a selection and download the original file.
- Show merged cells, column widths, hidden-content markers and formula cache
  warnings. Preserve identifiers and date-like text in CSV/TSV instead of
  silently coercing their values.
- Parse workbooks in a cancellable Worker with bounded loading and parsing.
  Reject invalid or oversized XLSX archives before preview and release preview
  resources when the file changes or closes.
- Support Light, Dark and Paper appearances with a lazily loaded, open-source
  SheetJS CE and VTable viewer. Preview is read-only and does not recalculate
  formulas or modify the original workbook.

## Upgrade

```bash
npm install -g farming-code@2.2.70
```
