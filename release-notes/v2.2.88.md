# Farming v2.2.88

[简体中文](./v2.2.88.zh_cn.md)

Milestone codename: **ARGON**

## Antigravity and Argon

- Farming officially supports Antigravity across structured Chat, Terminal, and resumable History, with Gemini 4 Argon as its default model.
- Antigravity and Pi support steering a running Chat turn. When that turn has already ended, input starts a new turn instead.
- Antigravity recovers from retryable stream errors within the same turn, and Pi reports retry failures without leaving the turn stuck.

## Chat

- Sticky turn prompts keep the current question visible while scrolling and jump back to its start on click. Sending a new turn brings its prompt into focus; this behavior can be disabled in Settings → Interface.
- Native incoming messages and input echoes stay synchronized across Agent runtimes without duplicate text or messages.
- Incomplete streaming Markdown links and images wait for a complete destination before appearing, keeping partial URLs from stretching tables.

## Workspace and appearance

- Uninitialized Git submodules display a neutral status instead of a change error.
- The black-hole Pet has clearer accretion-disk rendering and improved Light and Paper appearance.

## Reliability

- Agent communication history stays within its persistence limit so it remains readable after a restart.

## Upgrade

```bash
npm install -g farming-code@2.2.88
```
