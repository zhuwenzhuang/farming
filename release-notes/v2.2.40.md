# Farming v2.2.40

[简体中文](./v2.2.40.zh_cn.md)

Milestone codename: **ANCHOR**

This release strengthens Chat continuity across background work, reconnects, and server restarts. It also preserves explicit ACP Session settings and makes Agent lifecycle operations safer and easier to supervise.

## Chat continuity

- Inactive Chat transcripts can be prepared before they are opened, reducing the wait when returning to completed Agent work.
- Restored transcripts now cross one checkpointed revision boundary, so cached and authoritative entries appear atomically without duplicate or partially replaced content.
- Reading position is retained while transcript snapshots are refreshed, including background completion and reconnect paths.
- ACP transcript presentation keeps provider ordering while grouping compact progress and tool summaries consistently.

## Session settings and recovery

- Explicit ACP Session configuration changes, including Codex Fast mode, persist across reconnect, server restart, permission restart, and Chat/Terminal switching.
- Sessions without an explicit override continue to inherit the selected Agent Home's provider defaults.
- Recoverable idle ACP Sessions retain exact checkpoint and process identity boundaries during lazy restoration.
- Provider fork behavior, worktree admission, and persisted recovery metadata now share one authoritative capability contract.

## Agent supervision

- Adaptive Agent titles are routed through the installed CLI, persisted across restart, and coalesced under frequent updates without overriding a user-specified title.
- Project and Agent ordering changes use persistent backend transactions, including Project drag ordering.
- Chat exposes an Agent review-and-commit action backed by the existing review and workspace ownership boundaries.

## Runtime safety

- Browser and Computer capabilities share authenticated HTTP MCP endpoints instead of launching redundant per-Agent MCP subprocesses.
- Browser runtime output retention is bounded while preserving the core recovery evidence needed by an active Agent.
- `farming stop` now attempts a bounded graceful shutdown before escalating to an identity-checked force kill.

## Upgrade

```bash
npm install --global farming-code@2.2.40 && farming daemon
```
