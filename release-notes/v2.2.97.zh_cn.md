# Farming v2.2.97

[English](./v2.2.97.md)

## Agent 模型与运行时

- 从 ACP 会话配置中提供按模型区分的推理档位与说明，在主会话或侧边会话中切换模型时立即更新可用的思考强度选项，且互不干扰。
- 保持输入框光标在文件与资源标签边界处的移动和删除行为稳定，并适配移动端紧凑屏幕下的模型选择器宽度。
- 内置 Codex 运行时更新至 0.167.0，Claude ACP 适配器更新至 0.101.0，Claude Agent SDK 更新至 0.3.318。

## 导航与侧边栏控制

- 将侧边栏固定按钮移至顶部导航工具栏，并将资源与子智能体的显隐控制统一为单个侧边栏开关。
- 统一浅色、深色与纸张主题下侧边栏目录树、标签页、设置面板及对话框的触控交互、选中高亮与焦点环样式。

## 认证与工作区连续性

- 在应用内导航、启动重定向与分享链接跳转过程中保留认证令牌，使已打开的浏览器标签页在刷新与升级后保持登录状态。
- 滚动升级期间保留上一版前端脚本资源，并在编辑器模块加载失败时保留当前工作区上下文。
- 降低交互式终端输出延迟、对话输入框打字到发送的链路开销及后台工作区 Git 状态刷新频率，并支持在工作区搜索中直接匹配包含特殊字符的字面量查询。

## 安装

```bash
npm install -g farming-code@2.2.97 --registry=https://registry.npmjs.org
```
