# Farming v2.2.47

[English](./v2.2.47.md)

里程碑代号：**WATCHTOWER**

本次发布让 Workspace 分享更安全，并在任何公开 Package 发布前明确展示 Release Readiness。

## 更安全的 Workspace 分享

- Owner 可以创建短时签名只读链接；Guest 在链接有效期内重连后，HTTP 与 WebSocket Access 仍保持只读。
- Read-only Guest 可以查看共享 Browser 输出，但输入、Resize、Computer Control 和其他 Mutation 都会被权威 Backend 拒绝。
- Share Menu 继续支持复制 Full-control Link，并改进状态反馈、响应式布局和 Dark Theme 表现。

## 可验证的正式发布

- Release Preparation 现在按 Exact Candidate Revision 强制执行 Focused Automation、真实 Provider 和 Computer Use Acceptance。
- Candidate Push 触发的每个 Workflow 都进入监控，包括相关改动触发的 Documentation 与 GitHub Pages。
- GitHub Release Asset 先公开并完成验证，随后才发布通过 Smoke 的同一份 npm Tarball。

## 升级

```bash
npm install --global farming-code@2.2.47 && farming daemon
```
