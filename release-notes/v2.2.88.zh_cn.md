# Farming v2.2.88

[English](./v2.2.88.md)

里程碑代号：**ARGON**

## Antigravity 与 Argon

- Farming 正式支持 Antigravity，提供结构化 Chat、Terminal 与可恢复的 History，并以 Gemini 4 Argon 作为默认模型。
- Antigravity 和 Pi 支持在 Chat 运行期间追加引导；若当前轮次已结束，则以新轮次接收输入。
- Antigravity 可在同一轮次内恢复可重试的流式错误，Pi 会明确报告重试失败，避免轮次持续卡住。

## Chat

- 轮次问题吸顶后，滚动时仍可看到当前问题，点击即可返回问题起点。发送新一轮消息时自动聚焦其问题；可在 Settings → Interface 中关闭此行为。
- 原生传入消息与输入回显在各 Agent 运行时之间保持同步，避免重复文本或消息。
- 流式 Markdown 中尚未完整的链接和图片会等待目标地址完整后再显示，避免部分 URL 撑宽表格。

## 工作区与外观

- 未初始化的 Git 子模块显示中性状态，不再显示为变更错误。
- 黑洞 Pet 的吸积盘渲染更清晰，并改进了 Light 和 Paper 外观。

## 可靠性

- Agent 通信历史遵循持久化容量上限，确保重启后仍可读取。

## 升级

```bash
npm install -g farming-code@2.2.88
```
