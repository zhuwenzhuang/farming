## Conversation handoff

- Hand off a coding conversation from the Agent row menu to a new Agent, choosing its provider and Home while retaining the source conversation and working directory.
- The destination reads the source history, uses the original user's language, explains its understanding, and waits for instructions. Expand **Handoff context** to inspect the source reference and prompt.

## Chat and workspace improvements

- Keep peer messages readable as conversation bubbles, preserve bounded child history, and make recovery controls usable in compact views.
- Record model changes as durable conversation boundaries and restore the **Steer** label across languages.
- Apply reversible sidebar edits immediately while persistence completes, and preserve inline paste boundaries and subsequent typing.
- Preserve whitespace in formatted clipboard content and keep text pasted inside an existing code block literal.
- Keep ordinary Farming list queries in the regular tool display.
