# Farming v2.2.68

[English](./v2.2.68.md)

## 工作区与导航

- 统一 Project 和 Agent 信息卡，完善长标题、键盘访问、指针交互和视口定位，覆盖 Light、Dark、Paper 三种外观。
- 重命名时保留完整 Agent 标题，统一侧栏排序、选中和共享交互行为。
- 自动发现 Agent Home，按 Provider 分组，并分别记住各 Home 的模型和 Fast 默认设置。
- 某个监听文件缺失或无效时，其他文件继续自动刷新；保留草稿，监听失败的内容须重新读取后才能复用。
- 对齐已失效的文件条目；收起目录保持本地操作，不再发起多余的文件系统请求。
- 根据可用工作区宽度调整 Agent 面板。

## 运行时与恢复

- 恢复受阻的历史归档，将会话恢复限定在所属 Home。
- ACP 运行时绑定就绪前，启动读取保持等待状态。
- 托管 Codex ACP 更新至 1.12.0，Claude ACP 更新至 0.78.0。

## 升级

```bash
npm install -g farming-code@2.2.68
```
