# Farming v2.2.63

[English](./v2.2.63.md)

里程碑代号：**UNISON**

Unison（同调）让 Farming Code 的同类控件遵循同一份设计协议，在 Light、Dark、Paper
及紧凑布局下保持一致。

## 控件一致性

- Project、Agent、文件、Review、Composer、Browser 和 Computer 菜单共享字体、间距、
  圆角及交互状态样式。
- 文件树、Changes 与 Open Editors 使用相同的文件标签密度；辅助 Review 链接恢复
  正确文字层级，更多操作入口复用同一个图标。
- Open Editors 按实际行高保持七行上限，不再因空滚动条槽错开操作按钮；子菜单按实际高度适配视口。
- 选择器、Review 数字输入及弹窗操作共享控件规范；紧凑布局下 Review 表单不再超出弹窗。
- 新增样式归属检查和跨主题浏览器场景，防止页面局部样式再次引入同类控件差异。

## 导航与监督

- 文件工具栏新增文件树定位按钮，Markdown 预览中也能定位左侧对应文件；不重新打开文件、
  不改变未保存内容，需要时自动展开手机侧栏。
- 虚拟文件树只使用一个原生滚动面，消除内部滚动与位移分别同步造成的行位置漂移。
- 手机上的长 Project 名称在常显操作之前省略，不再与按钮重叠。
- 窄屏文件冲突操作自动换行，保持完整触控区域。
- Markdown 长公式在阅读列内独立横向滚动，公式编号预留空间，不再裁切或遮挡公式。
- 关闭新建 Agent 后，迟到的焦点恢复不会抢走后续菜单或弹窗的焦点。
- 手机 Agent 资源展开入口及资源操作在首次加载、重载和切换视口后仍可访问。
- 侧栏与 Git 历史保持一致的焦点和选中样式；搜索区分文件与目录。
- 有界交互诊断关联浏览器与服务端观测，不记录输入正文，并仅允许实例所有者访问。

## 运行可靠性

- 同一 Terminal socket 的并发发布不再打断启动，仍明确拒绝其他监听器占用的 socket。
- 后端命令完成后，迟到的缓冲输出不会重新创建进度计时器。
- 取消远程启动下载时，先停止精确的下载进程再等待和清理临时文件，不再被不响应退出的
  下载进程卡住。

## 升级

```bash
npm install -g farming-code@2.2.63
```
