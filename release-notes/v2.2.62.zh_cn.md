# Farming v2.2.62

[English](./v2.2.62.md)

本次补丁进一步收紧 Farming Code 中的生命周期所有权、恢复语义、发布完整性与视觉监督契约。

## Lifecycle 与恢复正确性

- Terminal Input 遇到结果不确定的 Transport Failure 后，会一直隔离到权威 Checkpoint 完成
  所有权对账；Stop 现在会覆盖完整的 Farming-owned Process Group。
- ACP Reconnect Failure 在所属 Binding Boundary 关闭；Transcript Correction 按 Projection
  Identity 隔离，已替换 Session 不会再接收陈旧更新。
- Computer Open 与 Stop 超时后，会按精确的权威 Container State 对账，不会重放结果不确定的
  Mutation。
- Browser 与 Computer Capability 采用新鲜且有界的读取；仍被 Live Session 引用的 Browser
  Resource 会保持可见并受到 Retention 保护。

## 更新、认证与发布完整性

- 托管 Codex Runtime 已在全部受支持的平台包中更新至 0.151.0。
- npm 托管更新使用唯一排他的 State Lock 与原子化 Ownership Commit；超时后脱离的工作不能再
  修改状态。
- Session Token 启动流程会保留可操作的失败原因，并确定性地修复精确文件权限。
- 由 JavaScript 加载的 CSS 与 Chunk 现在会跟随 Live Server Base Path，打包产物在
  Instance 使用不同路径运行时仍能正常显示。
- 发布流程会按 Tarball Digest 对账已存在的 npm 版本，并在允许 npm 发布前，逐一校验所有公开
  平台制品与发布 Checksum。

## 界面与验收

- Project、Agent、File 与 Resource Surface 统一使用共享交互状态层级；空白侧栏获得焦点时
  保持透明，Paper 外观保留清晰的键盘焦点。
- 紧凑导航作为一个隔离 Drawer 关闭，Files 在触屏下保持唯一 Scroll Surface，保留的 Browser
  Resource 仍可发现，移动端 Share QR Renderer 可从延迟加载中恢复。
- 聚焦的 Light、Dark 与 Paper 检查现在覆盖修正后的 Sidebar、Resource、Files、Settings、
  Archive 与 Mobile Navigation Surface。

## 升级

```bash
npm install --global farming-code@2.2.62 && farming daemon
```
