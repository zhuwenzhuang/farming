# Farming v2.2.36

[English](./v2.2.36.md)

这个版本让 Farming 的公开发布门禁对 CI 失败严格关闭，并修复了发布候选版本在真实使用中发现的多处交互与导航问题。

## 发布安全

- Release Workflow 现在要求候选版本的精确 Revision 必须存在由 Push 触发且成功完成的 `CI` Run，随后才允许任何构建或发布 Job 继续。CI 缺失、运行中、取消或失败都会阻止发布。
- 预发布指南现在明确要求解决每一个失败的 CI Check，并把生产依赖审计加入快速源码门禁。
- 内置 `tar` 依赖升级到 `7.5.22`。

## Code 与 CRT 交互

- 触摸屏 Viewport 上的 Agent Row 不再启用 HTML Drag-and-Drop，点击 Agent 可以稳定完成选择并关闭移动端侧栏。
- CRT 不再把 Main Agent 引导弹窗重新覆盖到已经存活的 Agent 上，包括权威状态晚于初始空状态到达的情况。
- 打开 Agent Home 配置时会保留真实 Provider Home 身份，并直接在编辑器中打开文件，不再借用无关 Project 身份重建路径。
- File Tree 的定位与焦点恢复现在可以容忍延迟布局和虚拟化；内联重命名会在 Tree Renderer 更新后重新取得焦点，避免点击被粘性目录或 Editor Layer 拦截。
- File Editor Tab 会预留实测的 Action Bar 宽度，窄布局下 Tab 内容不再被操作按钮覆盖。

## Terminal Link 与发布验证

- Terminal Path 处理现在会考虑互相重叠的候选路径、排除显式 HTTP(S) URL 的 Workspace Path 解析，并依次尝试可用目标，全部失败后再恢复 Terminal 焦点。
- Chromium 与 iPhone WebKit 的发布浏览器检查已改为确定性验证，覆盖 Terminal Output、触摸导航、文件操作、Plugins、CRT 引导与 Farming Pet 黑洞生命周期。

## 升级

```bash
npm install --global farming-code@2.2.36 && farming daemon
```
