# Farming v2.2.59

[简体中文](./v2.2.59.zh_cn.md)

This release adds one shared configuration for newly started Agents and makes navigation focus surfaces more consistent.

## Shared Agent configuration

- The built-in Shared configuration plugin can append common system instructions and environment variables to every new or restarted Agent.
- Environment variables can come from a strict `.env` file or an explicitly trusted Shell file such as `~/zzbashrc`.
- Configuration files remain ordinary editable files: changes apply automatically to the next Agent launch, while running Agents keep their original launch snapshot.
- Missing or invalid files block only affected new launches with a clear error and recover automatically after the file is fixed.
- Farming-owned credentials, provider Homes, and runtime-loader variables remain protected, and environment values are never returned by the configuration API.

## Consistent focus surfaces

- Project, navigation, file, tab, and Agent focus states now share one coherent surface treatment.
- Focus appearance is covered in Light, Dark, and Paper themes without adding competing row-selection markers.

## Managed Agent runtime

- The Farming-managed Codex runtime is updated to 0.150.1 across every supported platform package.

## Upgrade

```bash
npm install --global farming-code@2.2.59 && farming daemon
```
