# Farming v2.2.44

[English](./v2.2.44.md)

里程碑代号：**UNDER TEN**

本次发布按实测远端 Runner 容量配平完整验证链路，并删除剩余的串行发布浪费。

## 均衡 CI 与发布

- Chromium 使用 9 个测试均衡 Shard，每个仍为单 Worker，发布时既不引入有状态 Job 内并发，也不再制造 Runner 排队。
- Release Stage 在 Exact-SHA CI 尾段同时准备已验证 Checksum 和 Metadata，并在创建 Tag 或 Draft Release 前执行 CI Gate。
- App Artifact 携带已经验证的 Release Metadata，Stage 不再重新读取四个大型压缩 Archive。
- npm Publish 关闭大型 Package Content Notice 清单，最后发布 Job 也不再重新安装 npm CLI。

## 升级

```bash
npm install --global farming-code@2.2.44 && farming daemon
```
