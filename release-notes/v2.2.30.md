# Farming v2.2.30

[简体中文](./v2.2.30.zh_cn.md)

This maintenance release focuses on setup clarity and fixes several regressions in everyday Farming workflows.

## Browser setup

- **Plugins → Browser** can now install the version-matched managed Chromium explicitly when no suitable local browser is available. Chromium remains opt-in and is never downloaded during normal Farming installation, update, or startup.
- Managed Chromium installation uses isolated staging, cross-process coordination, executable verification, and atomic activation. Failed or interrupted installs do not become selectable Browser sources, and an older valid managed version is reported as updateable instead of being silently reused.

## History and collaboration

- History now treats each provider's root Session identity as authoritative. Child-Agent transcripts stay nested under their root instead of appearing as duplicate top-level History rows, and the UI distinguishes the loaded page count from the provider's total Session count.
- Provider History search can reach older Sessions without loading the full archive. Resume IDs remain visible and searchable, row actions restore the exact Session, and empty workspaces explain how to continue from History.
- ACP History preserves supported images and other media. Codex collaboration events retain their reviewed hierarchy and status, stay attached to the conversation turn that created them, and focus the matching process evidence without presenting child activity as an independent writable Agent. Folded child Agents now use compact inline buttons and expand in place only when selected.
- History rows once again use each Agent's themed icon assets.

## Reliability fixes

- Deep Project Files trees keep their real hierarchy while scrolling. The sticky ancestor stack now accounts for its own height, stays bounded, and leaves normal file rows visible instead of covering intermediate directories.
- Dark mode is applied before the application bundle starts, preventing a light first frame during reload and restoring clear visual separation between the sidebar and main workspace. The project-list scrollbar now stays hidden while idle and appears when the pointer moves over the list.
- HTTP and HTTPS links now open in the external browser on a normal click. Their context menu offers **Open in Farming browser** only when Browser capability is available; otherwise that row is omitted.
- In-app self-update is now limited to npm installations. Source checkouts, standalone executables, and app bundles keep their explicit manual deployment path and no longer treat GitHub Releases as an in-app update source.
- Obsolete fallback history readers and the legacy `farming memory report` command have been removed; supported History and resume paths now use the authoritative provider adapters.
- Public documentation has a shorter task-oriented entry path, with a dedicated documentation hub and concise product landing pages.

## Upgrade

```bash
npm install --global farming-code@2.2.30 && farming daemon
```
