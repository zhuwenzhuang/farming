# Farming v2.2.6

[English](https://github.com/zhuwenzhuang/farming/blob/main/release-notes/v2.2.6.md)

里程碑代号：**CRT**

本版本新增 Farming CRT、扩展 Farming Code 的 Review 与文件工作流和 Coding Agent Runtime 支持，并修改 Session 恢复、更新、打包和发布验证。

## Highlights

- **两套实时 UI，共用一套 runtime**：Farming Code 仍是 `/code/` 默认界面，`/crt/` 提供键盘优先的多终端视图；两者观察和控制相同的后端 Agent，不重复启动进程。
- **Farming CRT 功能**：包含实时终端缩略图、xterm session、New Agent、近期工作区、History、键盘导航、未读状态、终端字号、CRT 效果，以及返回 Farming Code 的入口。
- **Project Files 与 Review 工作流**：Project Files 提供 Changes、Open Editors、搜索、预览、diff 和 blame；独立 `/review` 路由提供不可变 comparison、行内评论、reviewed 状态、偏好、patchset 和 ACP 历史变更捕获。
- **Provider-aware Agent Runtime**：Codex、Claude Code、OpenCode、Qoder、Qwen Code、Aider、GitHub Copilot CLI、Amazon Q、bash 和 zsh 按各自能力使用 Provider 启动参数、环境隔离和持久元数据。
- **Codex Runtime 路径**：正常 CLI 仍是默认路径；实验性 App Server 为每个 Agent Home 隔离 Runtime，并覆盖 Transcript、请求、权限和恢复验证。
- **结构化 Chat 切换到 ACP**：Codex、Claude Code、OpenCode 和 Qoder 可以在保留 provider session 的情况下切换 Chat / Terminal，并支持原生权限、session 控件、图片 prompt、后续消息排队、内嵌交互终端和可独立控制的子 session。
- **前端或服务重启后的 Session 恢复**：Native PTY Host、Farming Session ID、Provider Session 关联、终端屏幕恢复和重连共同保留运行中 Session。
- **按安装类型区分更新路径**：npm 安装可使用应用内更新；源码 Checkout 继续走 Git；独立 CLI / App Bundle 包含 Checksum 和 Manifest。
- **移动端与终端交互变更**：包括工作区布局、Composer、终端尺寸与输入、中文输入法、链接、分享二维码，以及窄屏文件 / Review 流程。

## Farming CRT

- 新增独立 CRT 入口，采用参考复古终端的单色绿色视觉、中英文可读终端字体、轻量扫描效果和 GPU 友好的静态纹理层。
- 新增键盘优先的主页、New Agent、Settings 和 History；主页与 New Agent 选择器支持边界循环。
- 后端确认创建成功后，新 Agent 会自动成为当前键盘选择。
- 新增 History 自适应分页、provider 名称、受支持 Coding Agent 过滤、restore/resume/open 操作和稳定反色选择。
- 新增 10–20 px 的打开终端字号调节，拖动即时生效并自动持久化。
- 新增带 ANSI 颜色的终端缩略图、working 闪烁、未读外框、固定卡片尺寸、可选 Dynamic Heat，以及项目 / 任务标题。
- 打开 session 默认统一使用 xterm.js；Ghostty Web 仅保留为显式调试开关。
- UI Theme 中新增 Farming Code 入口，可以在不改变后端 Session 的情况下返回 Farming Code。
- 新增 ACP Chat 控件、后续消息排队、原生图片 prompt、`Alt+M` runtime 切换，以及中止后的 Composer 焦点恢复。
- Billing 扩展为 token telemetry 而非金额账单：对数 120 天图表与 52 周活跃条带区分 cache / non-cache 用量；选中某天后可查看小时分布和 provider 归因，且不会为每次点击重新扫描 provider 历史。
- 主页 Agent 网格使用预留的 `2 x 2`、`3 x 2` 和 `3 x 3` 机位；打开 New Agent 时会刷新可用 Agent 并显示终端关闭快捷键，同时新增 Farming CRT 浏览器图标。

## Farming Code、Review 与 Files

- 扩展项目级 Files：搜索、Changes、Open Editors、文本编辑、Markdown 预览、diff、blame、创建 / 重命名 / 删除 / 移动和有界文件监听。
- 独立 `/review` 路由支持不可变 Revision、文件列表、Patchset、行内评论、Reviewed 状态、偏好、Snapshot 与隔离的按需样式加载。Review Diff 支持字符级范围、文件末尾缺少换行提示、向上/向下/完整展开间隔的渐进式上下文，以及精确的 ACP 历史 Patch 捕获。
- 更新 Workspace 导航、近期工作区、路径建议、项目命名、文件 Reveal、Sticky Context 和移动端侧边栏。延迟 Reveal / Focus 会保留用户刚刚关闭的目录状态，也不会从文件右键菜单抢回焦点。
- 更新 Agent Hover 详情、启动图标、深浅色图标变体、Provider 分组、Shell 标签和 Runtime/Profile 控件。
- 更新 Codex Transcript 清理、App Server 消息处理、Goal 控制、权限切换和 Terminal/Chat Fallback。ACP Chat 改为读取基于 Revision 的 Transcript 增量，以紧凑时间线展示进度更新和分组操作，通过内嵌 xterm 展示 Client Terminal，支持子 Session 预览/停止及子 Session Elicitation，大型 Tool 详情按需加载，并保留明确的中止状态。
- 新增基于 Cursor 的 Agent Session 分页、后端 Provider 历史标题 / 项目搜索、History 页面内筛选、共用的 15 秒搜索超时；文件行内重命名保留焦点与文件名主体选区。

## Runtime 与可靠性

- 交互 Agent 默认由独立 native PTY host 持有，支持服务重启恢复和无会话时的空闲清理。
- 新增稳定的 `fsess_*` Farming session id，并把 runtime id 与 provider 关联字段分开。
- 更新 Shell 环境解析、Login Shell Profile、Prompt 归属、OSC Busy/Cwd 标记、终端状态、Resize、屏幕重放、光标隔离和链接处理。New Agent 的发现与启动会读取最新 Login Shell `PATH`，终端重放也会保留 TUI 使用的隐藏光标状态。
- 运行 History 只接收 Farming 明确支持的 Coding Agent；bash、zsh 和未知命令不会进入归档。
- 新增 Agent Home 元数据和 Codex App Server 的逐 Agent runtime 隔离。
- Agent turn 执行中会拒绝 runtime 切换；若目标 runtime 启动失败，Farming 会先恢复原 runtime 和 provider session，再明确报告失败。
- 增加更新回滚处理、安装类型识别、Release Manifest、Checksum、包校验和 Linux 兼容打包。

## 发布与兼容性说明

- package、lockfile、release notes 和 Git tag 必须保持 `2.2.6` / `v2.2.6` 一致。
- 现有 `~/.farming/.session-token`、settings、sessions 和 history 会继续复用并自动规范化，无需手动迁移。
- 标准 App Bundle 使用目标系统的 Node.js 和 native runtime。独立的 Linux x64 legacy 包包含固定的 glibc 2.28 runtime，仅在宿主 glibc 低于 2.28 时启用；目标机仍需 Node.js 22。
- macOS CLI 产物采用 ad-hoc 签名，不是 Developer ID 签名，也未 notarize；部分系统首次运行可能需要手动允许一次。
- 本版本 GitHub Release 正文来自英文 release note 文件。

## 安装 / 升级

通过 npm 安装：

```bash
npm install -g farming-code@2.2.6
farming
```

也可以在 GitHub Release 下载对应产物：

| 平台 | CLI | App bundle |
| --- | --- | --- |
| macOS Apple Silicon | `farming_2.2.6_darwin_arm64` | `farming-2.2.6-darwin-arm64.tar.gz` |
| macOS Intel | `farming_2.2.6_darwin_amd64` | `farming-2.2.6-darwin-x64.tar.gz` |
| Linux x64 | `farming_2.2.6_linux_amd64` | `farming-2.2.6-linux-x64.tar.gz` |
| 老 Linux x64（glibc < 2.28） | — | `farming-2.2.6-linux-x64-legacy-glibc228.tar.gz` |
| Linux ARM64 | `farming_2.2.6_linux_arm64` | — |

使用 `farming_2.2.6_checksums.txt` 和 `manifest.json` 校验下载产物。
