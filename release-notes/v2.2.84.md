# Farming v2.2.84

[简体中文](./v2.2.84.zh_cn.md)

Milestone codename: **BRIDGE**

## Legacy Linux compatibility

- Start Workspace command helpers with Farming's private Node.js loader and libraries on older Linux systems, avoiding missing GLIBC and GLIBCXX errors.
- Read the user's Shell environment through the same compatible runtime, including systems where Node.js reports the loader as its executable.
- Accept relative installation directories such as `--dir ./farming`.

## Upgrade

```bash
npm install -g farming-code@2.2.84
```
