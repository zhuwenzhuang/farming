# Farming v2.2.61

[English](./v2.2.61.md)

本次补丁继续收口 2.2.60 移动端监督版本中剩余的恢复与窄屏布局问题。

## Chat 历史恢复

- 预期存在 Chat 历史时，有界读取失败现在会进入显式且适合触控的“重试”状态，不再永久
  Loading。
- “重试”只重新读取完整的只读 Checkpoint，绝不会重放 Prompt 或其他 Mutation。
- Session 或 Runtime Epoch 替换后，旧身份的缓存历史会立即隔离。空响应、过期 Checkpoint
  与 Revision Gap 均采用有界重试，既不会泄露旧历史，也不会形成请求循环。

## 移动连接与交互加固

- 手机页面从挂起状态恢复时，如果 Browser 已把保留的 WebSocket 标为 Closing 或 Closed，
  即使原生 Close Event 丢失，也会有界替换连接；草稿保持不变，结果不确定的输入不会重放。
- 紧凑 Approval Menu 与 Composer 保持稳定间距；320 px 下的文件冲突操作保持可见、满足触控
  尺寸且可正常点击。
- Language Server 详情在窄屏下改为可读的堆叠字段，同时在宽屏继续保留语义化桌面表格。
- Restart Recovery 在 Docker 确认精确 Computer Container 已不存在后，会清除对应的陈旧引用，
  避免外部清理遗留反复的 Lifecycle Failure 或幽灵 Resource。

## 升级

```bash
npm install --global farming-code@2.2.61 && farming daemon
```
