# Farming v2.2.19

[简体中文](https://github.com/zhuwenzhuang/farming/blob/main/release-notes/v2.2.19.zh_cn.md)

Milestone codename: **THE WORKSPACE**

This release adds actions to the Farming Code empty workspace, persists Project membership, and fixes Agent resume and bundle updates.

## Changed

- Adds History, New Agent, Search, sharing, focus mode, and sidebar actions to the Farming Code empty workspace. Compact layouts show two primary actions.
- Adds a mobile Usage activity view with a 52-week overview, day selection, and a 24-hour histogram.
- Makes History rows perform their open, continue, or resume action while preserving separate alternate controls.
- Keeps mobile drawers opaque so terminal content does not bleed through navigation.
- Aligns the CRT empty state with its command style by displaying the `[N]` and `[H]` shortcuts consistently, and labels token charts from their actual reported time window.

## Fixed

- Persists renamed Agent titles, Project workspace identity, ordering, pinning, and recovery metadata across resume and restart boundaries.
- Makes Project membership backend-authoritative across Agent creation, History resume, Files, restored Project sessions, and Git worktrees. Failed admission now rolls back the exact runtime and durable membership without creating archive history.
- Keeps Project Files bound to the workspace root while Agents are reordered, removed, or resumed.
- Moves app-bundle installation into an input-validated detached helper so the running server can finish a replacement before restart.

## Upgrade

```bash
npm install --global farming-code@2.2.19 && farming daemon
```
