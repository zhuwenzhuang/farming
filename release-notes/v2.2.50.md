# Farming v2.2.50

[简体中文](./v2.2.50.zh_cn.md)

Milestone codename: **PAPER**

This release strengthens Agent continuity across restarts and runtime switches, adds precise read-only links for Chat and Files, and introduces the Paper appearance as part of a more consistent workspace experience across themes, providers, and live resources.

## Reliable Agent continuity

- Full restarts now reconcile exact Farming-owned processes and recover persisted Chat and Terminal Sessions without leaving missing, zombie, or indefinitely pending Agent rows.
- ACP cold recovery uses bounded parallel preparation, while History and Session inventory remain responsive with larger Agent collections.
- Usage history cache rebuilds now yield quickly to foreground reads and continue in bounded background batches, so daily and hourly activity remain usable while large local histories synchronize.
- Terminal-to-Chat replacement and ACP Host recovery are fenced to the exact Provider Session, preventing stale asynchronous results from replacing the current conversation.

## Context-preserving sharing and navigation

- Chat answers and the File Viewer can copy direct read-only links that preserve the selected Turn or the current file, view, line, and column, with bounded fallbacks when the original location has moved.
- Mobile Project and Agent navigation now behaves as a real modal, including keyboard focus containment, Escape handling, and protection from accidental background actions.
- External images referenced by structured Chat transcripts can now be previewed directly in the conversation.

## A more cohesive workspace

- The Paper appearance now distinguishes input surfaces from their surroundings by color, and Review follows the complete Light, Dark, and Paper appearance registry instead of falling back to a fixed light presentation.
- Deep and compact Files trees keep stable icon, label, and status columns, preserve real ancestor context, continue bounded single-child expansion, and avoid scroll jumps during direct expansion.
- Provider-native Plugins load production raster icons, keep source navigation atomic, and expose their slash commands consistently.
- Managed clangd and JDTLS installations can update from verified stable upstream releases while retaining a cached runtime when update checks fail; slow incidental Hover requests no longer leave empty or loading popovers.

## Consistent providers and live resources

- Provider capabilities, history behavior, Composer choices, Terminal controls, and Session identity now follow one adapter-owned definition, improving consistency across Codex, Claude, OpenCode, Qoder, and Qwen.
- New Chat Sessions use the Farming-managed ACP runtime. Existing legacy Sessions retain their exact persisted runtime identity for recovery, while native Terminal executable selection remains independent.
- Browser and Computer Resources are reconciled and cleaned up by exact owner identity. Browser launches use the canonical workspace, and stale rows, profiles, or Desktop containers no longer survive a missing or archived Agent.
- Update checks retry against the authoritative npm registry when an intermediary registry is stale.

## Upgrade

```bash
npm install --global farming-code@2.2.50 && farming daemon
```
