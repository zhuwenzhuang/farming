# Farming v2.2.61

[简体中文](./v2.2.61.zh_cn.md)

This patch closes the remaining mobile recovery and narrow-layout gaps from the
2.2.60 mobile supervision release.

## Chat history recovery

- Expected Chat history now ends bounded read failures in an explicit,
  touch-sized Retry state instead of an indefinite loading surface.
- Retry performs a fresh read-only checkpoint and never replays a Prompt or
  another mutation.
- A replacement Session or Runtime epoch immediately quarantines cached history
  from the previous identity. Empty responses, stale checkpoints, and revision
  gaps use bounded retries and cannot expose old history or create a request
  loop.

## Mobile connection and interaction hardening

- Returning to a suspended phone page now replaces a retained WebSocket that
  the browser marked closing or closed even when its native close event was
  lost. Drafts remain intact and uncertain input is not replayed.
- Compact approval menus keep a stable gap above the Composer, and 320 px file
  conflict actions remain visible, touch-sized, and usable.
- Language Server details become readable stacked fields on narrow screens
  while retaining the semantic desktop table at wider widths.

## Upgrade

```bash
npm install --global farming-code@2.2.61 && farming daemon
```
