# Farming v2.2.61

[简体中文](./v2.2.61.zh_cn.md)

This patch closes the remaining mobile recovery and narrow-layout gaps from the
2.2.60 mobile supervision release.

## Chat history recovery

- Expected Chat history now ends bounded read failures in an explicit,
  touch-sized Retry state instead of an indefinite loading surface.
- Retry performs a fresh read-only checkpoint and never replays a Prompt or
  another mutation.
- A replacement Session or Runtime epoch immediately quarantines cached history
  from the previous identity. Empty responses, stale checkpoints, and revision
  gaps use bounded retries and cannot expose old history or create a request
  loop.

## Mobile connection and interaction hardening

- Returning to a suspended phone page now replaces a retained WebSocket that
  the browser marked closing or closed even when its native close event was
  lost. Drafts remain intact and uncertain input is not replayed.
- Compact approval menus keep a stable gap above the Composer, and 320 px file
  conflict actions remain visible, touch-sized, and usable.
- The compact sidebar uses an accessible icon-only New Agent action, preventing
  its label from wrapping and distorting the navigation row on narrow phones.
- Language Server details become readable stacked fields on narrow screens
  while retaining the semantic desktop table at wider widths.
- Restart recovery now discards an exact Computer container reference after
  Docker confirms that container no longer exists, so stale external cleanup
  cannot leave repeated lifecycle failures or a ghost Resource.
- Mobile release screenshots now prove the scenario, visible controls, drawer
  state, viewport, scroll, and declared stable geometry both before and after
  capture. A changed or partially settled surface is discarded instead of
  entering the release evidence manifest.

## Global file path search

- Global Search now finds files by name, relative path, or a mounted Project's
  absolute path. Results show the complete path and Project, and click or Enter
  opens and reveals the exact file, including optional line and column targets.
- File queries are bounded, cancellable, path-only, and protected from
  out-of-Project symbolic-link traversal. Same-name Projects remain visibly
  distinguishable, timeouts are explicitly retryable, and a file that moves
  after search produces an error in Search instead of opening a substitute.

## Upgrade

```bash
npm install --global farming-code@2.2.61 && farming daemon
```
