# Farming v2.2.81

[English](./v2.2.81.md)

里程碑代号：**SHRINK**

## 更小的安装包

- agent-browser、ripgrep 和原生 PTY 通过精确版本的平台 npm 包交付；仅 Linux x64 下载旧 glibc 兼容库。
- 从运行时包中移除重复的前端依赖目录、未使用依赖、设计母版、历史素材、调试符号和 SDK 开发文件，保留应用功能与许可证。
- 禁用 npm 生命周期脚本也能安装预构建运行时，不依赖 postinstall 下载。
- 展示简洁的安装阶段和下载进度，并行下载独立运行时归档；支持 `--mirror cn`，由官方确定版本、校验完整性，并在镜像失败时回退到官方同版本。

## 首次使用

- 缺少可选浏览器时静默探测，让启动访问令牌更容易找到；普通安装输出不再展示临时目录路径。
- 中文时区的新 Config 默认使用中文，并保留用户显式选择的语言。
- Docker 浏览器镜像缺失显示为可安装状态；Agent Home 配置在加载期间发生变化时，提供简洁提示和刷新入口。

## Agent 监督

- 保留粘贴文本的格式，并高亮可编辑的输入草稿。
- 立即暂存 Chat 发送请求，保持有序接收和安全恢复。
- 支持原生 ACP 子任务更新，并改善配额失败诊断。

## 升级

```bash
npm install -g farming-code@2.2.81
```
