# Farming v2.2.62

[简体中文](./v2.2.62.zh_cn.md)

This patch tightens lifecycle ownership, recovery, release integrity, and the
visual supervision contract across Farming Code.

## Lifecycle and recovery correctness

- Terminal input that ends with an uncertain transport result is fenced until
  an authoritative checkpoint reconciles ownership, while Stop now targets the
  complete Farming-owned process group.
- ACP reconnect failures close at the owning binding boundary, and transcript
  corrections are quarantined by projection identity so replaced Sessions
  cannot accept stale updates.
- Timed-out Computer open and stop operations reconcile against the exact
  authoritative container state instead of replaying an uncertain mutation.
- Browser and Computer capability reads are fresh and bounded, and retained
  Browser resources stay visible and protected while a live Session references
  them.

## Update, authentication, and release integrity

- The managed Codex runtime is updated to 0.151.0 across every supported
  platform package.
- npm-managed updates use one exclusive state lock and atomic ownership commits;
  detached work cannot mutate state after its timeout.
- Session token startup preserves actionable failure causes and repairs exact
  file modes deterministically.
- JavaScript-loaded CSS and chunks now follow the live Server base path, so a
  packaged build remains usable when an instance runs below a different path.
- Release publication reconciles an existing npm version by tarball digest and
  verifies every public platform asset against its published checksum before
  npm is allowed to publish.

## Interface and validation

- Project, Agent, file, and Resource surfaces use the shared interaction-state
  hierarchy; blank sidebar focus remains transparent and Paper keeps visible
  keyboard focus.
- Compact navigation closes as one isolated drawer, Files keep one touch scroll
  surface, retained Browser resources remain discoverable, and the mobile share
  QR renderer recovers from delayed loading.
- Focused Light, Dark, and Paper checks now cover the corrected sidebar,
  resource, Files, Settings, archive, and mobile navigation surfaces.

## Upgrade

```bash
npm install --global farming-code@2.2.62 && farming daemon
```
