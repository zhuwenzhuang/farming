# Farming v2.2.95

[English](./v2.2.95.md)

## Agent 权限默认值

- 新建 ACP Chat 会话会遵循 Farming 的绕过权限设置，覆盖 Qoder、Claude、Qwen 和 Antigravity。权限模式经 Agent 确认后，在 Chat 中一致显示。
- 会话切回受限模式时恢复权限请求。修改默认值不会覆盖已有会话各自的选择。
- 新增覆盖全部七种 ACP Provider、Chat 与 Terminal 启动默认值，以及 Light、Dark、Paper 外观的回归测试。

## 相关会话与移动端菜单

- Antigravity 支持发现原生子会话，并在只读面板中打开相关历史。
- Codex Chat 分叉会话在释放原会话写入者后，使用新 Agent 的身份和环境。
- 移动端更多菜单补齐 Agent 操作，并在小屏幕内保持可用边界。Paper 菜单使用与侧边栏区分的背景。

## 托管 Agent 维护

- Codex ACP 更新至 2.5.0，Codex 更新至 0.166.0，Claude ACP 更新至 0.99.1，ACP SDK 更新至 2.2.0。Claude 运行时跟随其适配器指定的 SDK 版本 0.3.312。

## 安装

```bash
npm install -g farming-code@2.2.95 --registry=https://registry.npmjs.org
```
