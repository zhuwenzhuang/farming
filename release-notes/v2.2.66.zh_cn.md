# Farming v2.2.66

[English](./v2.2.66.md)

## 模型控件

- 模型矩阵按运行时公布的目录跨代际展示模型，包括 Astra。Ultra 轨道、点击区域、
  滑块行程和能量填充现在随矩阵高度自适应，兼容桌面和移动端。

## 移动端编辑与预览

- Chat 与 Terminal 输入框支持原地展开编辑长草稿，保留文本、选区、附件及原生触摸滚动。
- 内容更新时保留中文输入组合与对话阅读位置。标准 Markdown 图片通过工作区文件 API
  渲染，并支持内联预览已授权的工作区 HTML 可视化。

## 运行时维护

- 托管 Codex 更新至 0.153.4，Codex ACP 更新至 1.10.0，Claude ACP 更新至 0.75.1，
  包含 Astra 目录可见性及 Claude 分叉加载修复。
