# Farming v2.2.58

[English](./v2.2.58.md)

本次补丁发布让 Agent 列表操作更可靠、视觉语义更统一，并恢复了共享 Browser 控制中的完整键盘编辑能力。

## 可靠的 Agent 操作

- 即使当前没有运行中的 Runtime 认领 Session，历史只读 Agent 条目也能正常 Archive。
- Archive 后会在 Farming 界面顶部附近显示紧凑提示，包含被操作的 Agent 身份，并提供可用的 View、Undo 与失败反馈。
- Pin、通知与 Archive 控件统一了图标尺寸、线条和中性状态样式，不再额外使用蓝色表示选中。

## 完整的共享 Browser 键盘编辑

- Backspace 与 Delete 现在会通过共享 Browser 控制正确转发，输入框不仅能追加文本，也能删除已有内容。
- 聚焦 Browser 测试覆盖了这两个编辑按键，未改变无关按键处理。

## 一致的外观验收

- 侧栏选择与滚动条 Surface 使用统一的交互状态语义。
- Archive 提示的成功、Hover、键盘 Focus、Disabled 与 Error 状态均已覆盖 Light、Dark、Paper 三种外观。

## 升级

```bash
npm install --global farming-code@2.2.58 && farming daemon
```
