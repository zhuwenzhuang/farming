# Farming v2.2.46

[English](./v2.2.46.md)

里程碑代号：**WEIGHTED**

本次发布消除最后一段可避免的发布尾部，并按实测耗时而不是测试数量均衡 Browser Verification。

## 更快的验证发布

- 9 个隔离的 Chromium Job 按实测耗时分配原子 Test Location，在不增加 Worker 和日常 CI 工作量的前提下分散已知慢场景。
- GitHub 发布、公开资产验证和 npm 发布在同一个连续 Job 内完成，删除重复 Runner 调度和 Setup。
- npm 仍然是最后一个公开 Mutation；只有匹配的 GitHub Release、Tag、Manifest、Checksum 和必需资产全部公开验证后才会发布。
- Release Snapshot 与 Workflow Watcher 脚本替代反复手工查询，并直接生成有边界的失败证据。

## 升级

```bash
npm install --global farming-code@2.2.46 && farming daemon
```
