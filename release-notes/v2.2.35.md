# Farming v2.2.35

[简体中文](./v2.2.35.zh_cn.md)

This release strengthens Farming's self-hosted lifecycle, makes completed Agent work easier to notice, and tightens several high-frequency Code interactions.

## Installation, update, and instance isolation

- Each Farming Server now owns one canonical configuration directory and rejects conflicting ownership, so separate installations can safely isolate authentication, sessions, runtime state, and update metadata while still using shared external workspaces and Provider Homes.
- npm installations now update through an isolated package-version lifecycle. Candidate packages are staged and verified before activation, exact process identity and port release are proven before mutation, and stale updater metadata is reconciled without treating source or standalone installations as npm-managed deployments.
- The npm package carries its reviewed production dependency set, allowing fresh installations and updates to use the exact packaged dependency graph rather than relying on unrelated global state.

## Agent completion notifications

- Farming can notify the user when an Agent finishes while the page is hidden. ACP Chat follows the authoritative Prompt `stopReason`; Terminal sessions consume standard BEL and OSC notification protocols, with OpenCode using its supported OSC 99 integration.
- Notifications use the Agent's latest visible answer or terminal-provided message instead of generic completion copy. Clicking a notification returns to the exact Agent and closes competing overlays.
- Notification permission is an explicit Agent setting. Background tabs coordinate delivery so one completed Turn produces one notification instead of duplicates.

## Chat, Plan, and sidebar interactions

- The floating ACP Plan is now a live-Turn surface. It appears only while the latest Turn is running and the Plan is incomplete; Prompt completion, failure, cancellation, process loss, and the start of a later Prompt clear stale Plan state.
- History now shows complete Resume IDs, marks exact sessions already represented on the main page, and opens the matching Agent instead of leaving History visible. Escape from the History search field returns to the workspace.
- ACP Composer menus close with Escape and restore input focus. The expanded Usage panel follows the same keyboard convention and collapses with Escape.
- New Codex Chat Agents now receive a first-task title while their initial Turn is still running instead of remaining generically labeled `Codex` until completion.
- Invalid empty-workspace starts remain immediately editable, and Project pagination buttons no longer let Arrow keys switch the active Agent. Agent and session pagination controls also expose distinct names and hidden counts to assistive technology.
- Closing Settings or an Extension detail returns keyboard focus to the control that opened it.
- Project and Agent hover details pause while the Project options menu is open. Pointer-opened Project menus no longer preselect the first action, while keyboard navigation remains available from the first item.
- Git branch rows no longer highlight the parent Project title on hover, and Agent provider icons use a lighter size aligned to the label baseline.
- Provider-specific controls remain capability-driven, preventing unsupported session modes or actions from appearing merely because of the Provider name.

## Browser and rest experience

- Browser Viewer input and JPEG frame backlogs are bounded so rapid pointer, viewport, and stream activity cannot accumulate unbounded stale work.
- Farming Pet's black-hole rest scene now has a more continuous attraction, lensing, disk, radiation, and evaporation sequence, with smoother final-minute convergence.

## Upgrade

```bash
npm install --global farming-code@2.2.35 && farming daemon
```
