# Farming v2.2.39

[English](./v2.2.39.md)

里程碑代号：**SIGNAL**

本次发布让结构化 Chat 更早进入可用状态，并更清楚地呈现 Agent 正在进行的工作。同时新增 Codex 内联可视化，并在权威终端回放中保留鼠标输入协议。

## 更快的 Chat 启动

- 新启动的 ACP Chat 会在 Agent 仍处于连接阶段时打开，不再让启动对话框持续遮挡工作区。
- 工作区选择和最近工作区持久化不再阻塞 Agent 启动。持久化失败会通过权威 Settings 状态进行协调，不会重放启动操作。
- Transcript 会区分 Agent 初始启动和历史同步，使可见状态与实际 Runtime 所有者保持一致。

## ACP 实时活动

- 进行中的 Turn 会为受支持的 ACP Provider 显示一行紧凑实时状态，覆盖思考、读取、搜索、编辑、规划、获取、终端和工具操作。
- 类型化活动图标只在工作进行时显示；已完成的 Transcript 条目保持原有紧凑呈现。
- 当 Thought 标题或 Plan 标签最能描述当前工作时，会继续使用这些信息作为实时状态。

## Codex 内联可视化

- Codex Host 指令提供的 HTML 可视化资源可以直接在 Chat Transcript 中渲染。
- 可视化文档运行在沙箱 iframe 中，只能进行有界的工作区资源访问。表单、对象嵌入、父页面导航和任意网络连接仍被阻止。
- Preview 资源随 Transcript 组件生命周期创建和清理，包括取消与失败路径。

## 终端回放

- 权威终端 Checkpoint 除 mouse tracking protocol 外，现在也会保留活跃的 xterm mouse encoding。
- 使用 SGR 鼠标上报的全屏 TUI（包括 Qwen Code）在重连或 Native PTY Host 轮换后仍可使用滚轮和指针输入。
- 新增 Round-trip 回归测试，覆盖 Alternate Screen 下的 Drag Tracking、SGR Encoding 以及向新终端恢复的过程。
- Codex Terminal 现在可以识别带边框的新版 `/status` 面板，使新会话能够物化可恢复身份，并在切换到 ACP Chat 时保持连续性。

## 工作区布局

- Project Files 工作区 Pane 不再显示调整大小光标或拖拽入口；在监督 Agent 和文件时宽度保持稳定。

## 升级

```bash
npm install --global farming-code@2.2.39 && farming daemon
```
