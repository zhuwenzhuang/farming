# Farming v2.2.85

[English](./v2.2.85.md)

## 会话交接

- 从 Agent 行菜单交接编程会话，选择新 Agent 的类型和 Home，保留来源会话并沿用工作目录。
- 新 Agent 先读取原会话，沿用原用户语言，说明理解后等待指示。展开「交接上下文」可查看来源引用和提示词。

## Chat 与工作区改进

- 将 Agent 间消息显示为易读的对话气泡，保留有界子会话历史，并改善紧凑视图中的恢复控件。
- 将模型切换记录为持久的会话分界，并恢复各语言中的 **Steer** 标签。
- 可撤销的侧栏编辑即时显示，随后完成保存；保留行内粘贴边界和后续输入位置。
- 保留格式化粘贴内容的空白，在已有代码块内粘贴时保持原文。
- 普通 Farming 列表查询保留在常规工具展示中。

## 升级

npm install -g farming-code@2.2.85
