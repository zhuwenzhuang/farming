# Farming v2.2.51

[简体中文](./v2.2.51.zh_cn.md)

Milestone codename: **BRIDGE**

This release lets Agents use pages and signed-in state from an existing Chrome, adds Pi as a first-class coding Agent, restores more workspace context across navigation and restarts, and strengthens file, terminal, provider, security, and interaction behavior throughout Farming Code.

## Use your existing Chrome

- The optional Farming Browser Connector lets Browser Agents discover and manage eligible pages already open in the user's Chrome, reusing the current signed-in state without replacing the independent Farming Browser.
- Connector setup is now a short, explicit flow in Plugins. Farming prepares a visible extension folder only on request, reports its path, size, integrity, and live availability, and keeps installation and removal instructions separate.
- The Connector reconnects automatically, manages ordinary existing tabs without per-tab approval, authenticates the local Farming side panel, and uses a separate identity, protocol, key, storage, and tab group so it can coexist with OpenClaw.
- Browser sources remain composable: a new browser, the user's Chrome, and Browser in Docker can be available at the same time, while unsupported External CDP configuration has been removed.

## Pi and stronger Provider continuity

- Pi is now a first-class Chat and Terminal Provider with managed ACP packaging, history, activity detection, icons, capability discovery, CLI smoke coverage, and release integrity checks.
- Codex and Claude ACP adapters are updated to their current managed releases. Farming retains its reviewed Codex integration patch and verifies exact upstream and bundled hashes before packaging.
- ACP streaming now preserves split UTF-8 characters across both Host and Provider socket boundaries, renders progressive answers and reasoning markup, and reconciles Provider history before rejecting duplicate Session starts.
- Provider-owned terminal viewports no longer receive Farming reading-anchor restoration, while hard stop now removes the complete Farming-owned native terminal process set.

## Continue from the same workspace

- Farming restores stable workspace choices such as the last valid Agent, open file, Plugins location, Project expansion, side-panel visibility and width, and falls back to the most recently updated Agent when a remembered Agent no longer exists.
- Worktree controls can safely switch the clean main worktree to an existing local branch after checking live Agent ownership, branch occupancy, expected HEAD, failure, and uncertain outcomes.
- Chat and Terminal file links can mount the nearest Git worktree, preserve an explicitly selected subdirectory Project, return to a source Agent across Projects, and decode structured paths exactly once.
- Files can open larger text documents safely, page oversized Markdown previews, keep Language Server results current, and preserve focus through save, Review, transcript, sharing, and other modal flows.

## Clearer and more resilient interaction

- Sidebar rows, tabs, lists, mobile navigation, Plugins, Review, and related controls now share one coherent hover, selection, focus, radius, and light-theme surface language without stacked or leaking selection cues.
- Agent side panels remain stable during activity, remember the user's width and visibility choice, and use a wider default for Browser and Computer Resources.
- Editor and rich-preview runtimes load only when needed, Browser navigation reuses authoritative metadata, and state-based test fences replace timing guesses in changed interaction paths.
- Credential-bearing share links are bound to a trusted origin, ZIP extraction rejects unsafe archives through one reviewed boundary, desktop source checkouts prepare required runtimes, and Pet rest transitions retain their intended duration and close reliably at zero.

## Documentation

- The Browser guide now has a dedicated, bilingual existing-Chrome setup and removal path with verified high-resolution screenshots and clear separation from the Browser capability itself.
- Provider, Files, ACP, terminal, Browser, Computer Use, appearance, extension, security, and runtime contracts are updated alongside the shipped behavior. Light documentation pages again use Farming's neutral white palette.

## Upgrade

```bash
npm install --global farming-code@2.2.51 && farming daemon
```
