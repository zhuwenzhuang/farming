# Farming v2.2.96

[简体中文](./v2.2.96.zh_cn.md)

## Agent continuity

- Handoffs inherit the source Agent's name, using the same numbered naming rules as forks. Explicit names remain available, and concurrent forks and handoffs reserve distinct names.
- Native child sessions appear in Chat collaboration. Antigravity children with no usable status stay hidden until authoritative state arrives, and recovered transport failures no longer leave stale failure state.
- Verify that changing one Codex Chat model preserves the selections of concurrent sessions through history loading and reconnect.
- Update the ACP SDK to 2.4.0.

## Navigation and rich content

- Preserve authentication tokens when shared links redirect to the canonical URL, and settle history navigation on the selected session.
- Resolve file links against their exact workspace paths and keep Mermaid previews stable while content streams or diagrams are dragged.
- Wait for Project and Agent inventories before opening shared file links, so a project file is not mistaken for an external read-only file during startup.

## Linux reliability

- Replace the legacy Linux compatibility library with the patched Debian glibc 2.28 build, fixing a reader/writer-lock deadlock that could leave Farming unresponsive.
- Use the same verified runtime in app bundles and npm images. Upgrades install immutable runtime directories without overwriting libraries in use or reusing an older runtime.

## Installation

```bash
npm install -g farming-code@2.2.96 --registry=https://registry.npmjs.org
```
