# Farming v2.2.94

[English](./v2.2.94.md)

## 访问验证、Chat 与运行时启动

- 未认证的浏览器访问和过期会话会打开点选拼词口令验证页，不再返回原始 JSON 错误。诗句与短语口令会预填每句开头提示，并在 Light、Dark、Paper 外观下提供打乱的候选词库，也支持切换为直接输入完整口令。
- 运行时依赖准备支持并发下载缺失的托管运行时，并在交互式终端中分行显示各组件进度。
- Chat 在中途补充指令（Steering）后保留流式 Markdown 段落结构，并对齐 Antigravity 历史错误步骤状态，避免与输入区反馈重叠。
- 富文本 Chat 输入区在原生输入法（IME）组合输入与引用提问流程中保持焦点稳定，并新增宽屏阅读切换，切换时保持当前阅读位置。
- CRT Token 计量在扫描大规模本地 Codex 历史会话时避免分叉会话基线阻塞，明确展示同步中或历史不完整状态；CRT 总览网格仅展示运行中的实时 Agent，已停止或退出的终端会话以只读方式收敛展示，不再触发检查点重试报错。

## 托管 Agent 维护

- Codex ACP 更新至 2.3.0，Codex 更新至 0.165.0，Claude ACP 更新至 0.98.0。Claude 运行时跟随其适配器指定的 SDK 版本 0.3.310。

```bash
npm install -g farming-code@2.2.94 --registry=https://registry.npmjs.org
```
