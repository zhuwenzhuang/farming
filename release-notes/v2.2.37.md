# Farming v2.2.37

[简体中文](./v2.2.37.zh_cn.md)

This patch release hardens Farming's publication process so a version cannot proceed while its exact release commit has missing, pending, cancelled, or failed CI.

## Release safety

- A fully successful `CI` workflow for the exact release commit is now documented as the first non-negotiable publication gate. Any failure requires a fix and a new candidate revision before qualification restarts.
- The Release workflow waits for the push-triggered CI run bound to the exact candidate SHA and fails closed unless that run succeeds.
- npm source verification now tolerates the registry's short metadata-propagation window with a bounded retry, while immediately rejecting a version that belongs to a different Git revision.
- The black-hole lifecycle browser gate no longer requests redundant software-WebGL frames after the renderer has already produced its bounded E2E timing state, preventing slow CI runners from timing out while preserving the full lifecycle assertions.
- The real Codex release gate now waits for the target model action to become enabled before issuing its keyboard selection, so an in-flight profile update cannot silently discard the verification action.

## Codex Terminal

- Model controls now follow the backend provider adapter's exact Terminal-profile capability instead of disappearing when a transient terminal-screen observation falls back to a generic process while Codex redraws its composer.

## Upgrade

```bash
npm install --global farming-code@2.2.37 && farming daemon
```
