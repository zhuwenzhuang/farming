# Farming v2.2.59

[English](./v2.2.59.md)

本次发布增加了面向新启动 Agent 的统一共享配置，并让导航 Focus Surface 更加一致。

## Agent 共享配置

- 内置 Shared configuration 插件可以为每个新建或重新启动的 Agent 追加公共系统提示词和环境变量。
- 环境变量既可以来自严格解析的 `.env` 文件，也可以来自显式信任的 Shell 文件，例如 `~/zzbashrc`。
- 配置文件仍是普通、可直接编辑的文件：修改会自动作用于下一个 Agent 启动，运行中的 Agent 保持原有启动快照。
- 文件缺失或内容无效时，只阻止受影响的新启动并展示明确错误；修好文件后自动恢复。
- Farming 自有凭证、Provider Home 与 Runtime Loader 变量仍受保护，配置 API 也不会返回环境变量值。

## 一致的 Focus Surface

- Project、导航、文件、Tab 与 Agent 的 Focus 状态统一使用一致的 Surface 表达。
- Light、Dark、Paper 三种主题均覆盖 Focus 外观，同时不会增加相互竞争的行选中标记。

## 托管 Agent Runtime

- Farming 托管的 Codex Runtime 已在全部受支持平台包上更新至 0.150.1。
- 经过审查的 Codex ACP Adapter 已更新至 1.7.0：保留 Farming 的环境变量、Steering、Goal、Fork 与 Subagent 集成，同时纳入上游新增的权限生命周期能力。

## 升级

```bash
npm install --global farming-code@2.2.59 && farming daemon
```
