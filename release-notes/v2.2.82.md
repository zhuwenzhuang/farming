# Farming v2.2.82

[简体中文](./v2.2.82.zh_cn.md)

Milestone codename: **SHRINK**

## Agent communication

- Show native Codex peer messages in the Agent activity feed, including recipient, message preview and sending, completed, failed or cancelled state. Restore the same presentation when reading saved history.
- Keep separate sends visible even when their text matches, and preserve expanded evidence as a send changes state.
- Show Farming CLI Agent lookup calls as inspectable activities. A completed lookup does not imply that a peer was found.
- Resolve existing peers by provider, Agent Home and Session identity. Follow current Agent names and open the correct Agent without treating a peer as a child session.

## Upgrade

```bash
npm install -g farming-code@2.2.82
```
