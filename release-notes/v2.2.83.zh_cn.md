# Farming v2.2.83

[English](./v2.2.83.md)

里程碑代号：**CHORUS**

## 更清晰的 Agent 对话

- 收到其他 Agent 的消息时，使用普通 Chat 气泡，头像和较小的发送者署名单独显示。保留消息接收时记录的名称。
- 同一 Agent 的连续消息合组展示，默认显示组尾记录时间；回复、工具活动和发送者变化会明确分开。
- 从接收方自身历史恢复受支持的 Codex、Claude 来信。Codex 只提供加密正文时显示简短说明，不展示密文。

## 安装与启动

- 重复执行目录安装脚本时检查目标版本，按需更新并保留配置和历史；已经是目标版本时明确提示无需更新。
- 对已经运行的实例再次执行启动时，明确停止该实例及其 Agent，然后重新启动。安装完成后给出完整的前台、后台和停止命令。
- 支持 Node.js 23，版本要求统一为 Node.js 22.13 及以上。

## 升级

```bash
npm install -g farming-code@2.2.83
```
