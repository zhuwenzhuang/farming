# Farming v2.2.54

[English](./v2.2.54.md)

里程碑代号：**STEADY**

本次补丁发布消除了大文件树冷打开卡顿，并加强了 Project Files 发布门禁。

## 更快的冷文件打开

- 文件打开的加载反馈现在只更新受影响的新旧 Row，不再通过整个文件树重新发布状态。
- 同一 Workspace 资源的手动重新加载与文件监听刷新现在共享一个在途读取，不再重复发起读取。
- 大型展开树滚动时，Sticky Context 改为从预计算 Row Projection 定位，不再逐帧扫描全部 Tree Node 并测量每个已挂载文件 Row。
- 2,000 文件性能场景现在同时约束两次冷打开、热切换最坏延迟与 Row 渲染数，避免尾部卡顿被仅看百分位的结果掩盖。

## 更强的 Project Files 验收

- 发布门禁现在覆盖超大 Markdown 与文本、大型展开树、图片和 PDF 原始加载，以及有界的二进制文件查看。
- 空 Workspace 与 Changes 视觉测试改为观察权威 WebSocket Workspace 协议，不再监听已经移除的 HTTP 控制路由。
- Claude ACP 只在受管 Codex ACP 或 Codex Runtime 同时需要更新时才更新。Bundle 预审 SHA 校验继续保留：实测成本不到一秒，同时能阻止未经审查的 Runtime 字节进入发布包。
- Settings 与对话框现在只阻止休息提醒进入，不再暂停工作截止时间，消除了依赖时序的提醒状态。

## 升级

```bash
npm install --global farming-code@2.2.54 && farming daemon
```
