# Farming v2.2.95

[简体中文](./v2.2.95.zh_cn.md)

## Agent permission defaults

- New ACP Chat sessions honor Farming's bypass-permissions preference, including Qoder, Claude, Qwen, and Antigravity. The selected permission mode is confirmed by the Agent and shown consistently in Chat.
- Changing a session back to a restricted mode also restores permission requests. Existing sessions retain their own selection when the default changes.
- Add regression coverage across all seven ACP providers, Chat and Terminal launch defaults, and Light, Dark, and Paper appearances.

## Related sessions and mobile menus

- Antigravity discovers native child sessions and opens their related history in read-only panels.
- Forked Codex Chat sessions use the new Agent's identity and environment after releasing the original session writer.
- Mobile overflow menus include Agent actions and keep their bounds on small screens. Paper menus have a distinct surface from the sidebar.

## Managed Agent maintenance

- Update Codex ACP to 2.5.0, Codex to 0.166.0, Claude ACP to 0.99.1, and the ACP SDK to 2.2.0. The Claude runtime follows its adapter-owned SDK version, 0.3.312.

## Installation

```bash
npm install -g farming-code@2.2.95 --registry=https://registry.npmjs.org
```
