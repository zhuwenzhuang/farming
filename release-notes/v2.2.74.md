# Farming v2.2.74

[简体中文](./v2.2.74.zh_cn.md)

## Projects and files

- Name permanent Worktrees before creating them, with collision checks, visible creation progress, and a minimized status control that preserves the operation across reloads, including trusted HTTP connections.
- Keep editor changes pending until they can be applied safely, and improve quoted context without losing the current draft.

## Chat and usage

- Unify pasted documents, mixed text and files, image previews, HEIC conversion, optional image optimization, and attachment-aware draft and history recovery. Long pasted text becomes a restorable reference card.
- Keep the return-to-latest control hidden at the live bottom, and recover failed Mermaid component loads with a page reload.
- Read Codex account quotas independently of the inference provider, isolate account identities, and reconcile token usage snapshots across Code and CRT.
- Preserve model versions in the model matrix so different generations remain distinguishable.

## Installation and runtimes

- Improve public installer compatibility and simplify the website installation commands.
- Update the managed Codex runtime to 0.159.2, Codex ACP to 2.0.1, and Claude ACP to 0.84.0.

## Upgrade

```bash
npm install -g farming-code@2.2.74
```
