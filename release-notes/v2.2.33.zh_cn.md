# Farming v2.2.33

[English](./v2.2.33.md)

这个修复版本收敛了 Farming Code 的侧栏交互与 npm 交付路径。

## 修复

- Browser 与 Computer Resource 现在共享统一的侧栏 Section、Row、Hover、Focus、Active、Action 浮现和 Empty State 样式，同时保留各自的 Icon 与 Action 语义。
- Project Files 的 Row、Sticky Context、Editor Tab 与嵌套文件树交互使用更一致的间距、颜色、Focus 与 Reveal 行为。
- Agent Home 排序统一使用支持键盘操作的拖拽把手；打开 Agent Home 配置时会通过普通 Project Files 路径挂载并定位文件。
- 当前页面刷新会保留现有展示，直到新的权威结果返回，避免不必要的空白状态。

## 打包

- npm 包现在携带生产依赖，并在启动依赖下载时展示有界进度，改善全新安装和首次启动的可见性。

## 升级

```bash
npm install --global farming-code@2.2.33 && farming daemon
```
