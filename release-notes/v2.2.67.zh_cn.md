# Farming v2.2.67

[English](./v2.2.67.md)

## Chat 与恢复

- Chat 消息被接受后自动回到最新消息，普通更新仍保留正在阅读的位置。
- 模型发现失败时保留已选模型，在可能使用非预期模型发送消息前提示恢复操作。
- 硬重启后移除无法恢复的 Shell，避免已替换的 Main 终端累积为多余的 bash 行。
- 修复 macOS 上旧进程尚在完成退出时，Terminal 切换到 Chat 可能失败的问题。

## 文件与富内容

- 稳定流式 Markdown、公式与图表展示，图表首次打开即适配视口，并共用全屏查看控件。
- 将 blame 注释限制在编辑器视口内，并避开异步出现的顶部固定代码行；切换文件或视图时关闭失效菜单。
- 剪切时若写入剪贴板失败，保留选中文本并显示错误提示。
- 在中等宽度窗口中保留桌面导航和编辑控件。

## Browser 与运行时

- 改进远程 Browser 的键盘、指针、焦点和剪贴板操作。
- 隔离 Browser 保持自动化连接时，Viewer 输入也能正常工作。
- 最后一个 Browser 标签页消失时释放隔离 Desktop 租用，确保对应 Computer 可以删除。
- 托管 Codex 更新至 0.154.0，Codex ACP 更新至 1.11.0，Claude ACP 更新至 0.76.0。

## 升级

```bash
npm install -g farming-code@2.2.67
```
