# Farming v2.2.28

[简体中文](./v2.2.28.zh_cn.md)

Milestone codename: **POMODORO**

This release adds two new ways to stay inside the Farming workspace: Farming Pet provides an opt-in Pomodoro-style break experience, while Browser Resources let people and Agents view and operate the same web page through a system Chromium browser.

## Highlights

- Farming Pet starts a work cycle from real Farming clicks or input, resets after five idle minutes, survives reloads in the current tab, and never treats Agent output as human activity. Work intervals include common Pomodoro presets and a custom duration; a due reminder provides a quiet countdown, one postponement, dismissal, and a five-minute break.
- Pet appearance follows the active theme until the user makes an explicit choice. Soft glow provides a calm modal rest scene. Black hole provides a WebGL rest scene with local page refraction, a readable undistorted control, continuous lensing, background-safe timing, and a full Hawking-radiation evaporation sequence.
- Each Project can own multiple persistent, named Browser Resources. Farming discovers a compatible Chromium-based browser already installed on macOS, Linux, or Windows, launches it headlessly with an isolated profile, and streams the exact page into the workspace. Farming does not download Chromium or add Playwright to the product runtime.
- The person and Agent share the same Browser Resource and CDP session. The Viewer supports navigation, pointer input, text input, keyboard input, scrolling, lifecycle state, reconnects, and bounded recursive-view feedback.
- Browser capability is opt-in. When enabled, ACP Agents can receive the project-scoped `farming-browser` MCP server; Terminal and other Agents can discover and operate the same resources through `farming browser` or the `farming-browser` alias. Tools list resources first and require an explicit Browser id for later operations.
- HTML files can now open in a sandboxed preview with source/preview switching, unsaved content, relative resources, bounded navigation, expiry recovery, and desktop/mobile coverage. This remains a static HTML surface rather than a general JavaScript browser.

## Browser boundary

Browser Resources are intended for web viewing and straightforward Agent interaction. They do not replace a full browser window, DevTools, downloads UI, extensions, arbitrary desktop interaction, or future Computer Use. Only compatible Chromium-based system browsers are supported by this release.

## Reliability and interaction

- Browser processes, rows, isolated profiles, screencast frames, CDP requests, and Viewer connections have explicit lifecycle ownership and bounded failure states.
- Recursive Browser viewing is bounded so a Browser can inspect a page containing Farming without creating unbounded video feedback.
- Composer drafts now stay with the correct restart lineage.

## Upgrade

```bash
npm install --global farming-code@2.2.28 && farming daemon
```
