# Farming v2.2.54

[简体中文](./v2.2.54.zh_cn.md)

Milestone codename: **STEADY**

This patch release removes a large-tree cold file-open stall and strengthens the Project Files release gate.

## Faster cold file opening

- File-open loading feedback now updates only the affected old and new rows instead of republishing state through the entire file tree.
- Explicit reloads and file-watch refreshes now share one in-flight read for the same workspace resource instead of issuing duplicate reads.
- Scrolling a large expanded tree now resolves sticky context from its precomputed row projection instead of scanning every tree node and measuring every mounted file row on each frame.
- A 2,000-file performance case now bounds both cold-open samples, worst-case warm switching latency, and row render counts so tail regressions cannot hide behind percentile-only results.

## Stronger Project Files acceptance

- The release gate now covers oversized Markdown and text, large expanded trees, image and PDF raw loading, and bounded binary-file viewing.
- Empty-workspace and Changes visual tests now observe the authoritative WebSocket workspace protocol instead of removed HTTP control routes.
- Codex Runtime 0.148.0 and Claude ACP 0.70.0 are updated together after all six Codex platform packages became available. Reviewed bundle SHA verification remains enabled because its measured cost is below one second and it prevents unreviewed runtime bytes from entering a release.
- Settings and dialogs now suppress break-reminder entry without pausing its work deadline, eliminating a timing-dependent reminder state.

## Upgrade

```bash
npm install --global farming-code@2.2.54 && farming daemon
```
