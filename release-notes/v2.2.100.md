# Farming v2.2.100

[简体中文](./v2.2.100.zh_cn.md)

This release fixes file navigation and comparison, keeps Agent activity clear of Chat and the composer, and makes Review opening safer for a running Server.

## Fixes

- Open directory links from Chat into the exact Project, including worktree roots that were not mounted before.
- Keep File Diff enabled across eligible files and reloads until it is closed. Choose inline or side-by-side layout from the Diff menu; resizing does not switch layouts. Word wrap applies to both sides, and the unused line-number gutter is removed.
- Keep Goal, plan and Browser activity between the transcript and composer without covering either surface.
- Reuse an already-running Server when opening `farming review`, preserving its Agents. Reject conflicting endpoint settings and stale process identity.
- Improve repeated ACP replies, live session notices, Terminal path navigation and request lifecycle handling.
- Keep the Main Agent visible in CRT after its terminal starts, open relative Terminal file and directory links without a reported cwd, and restart expired Blame and Changes page snapshots.
- Avoid misclassifying a transient native PTY lock snapshot during concurrent Agent creation.

## Managed runtimes

- Update Codex to 0.169.0, Codex ACP to 2.7.0, Claude ACP to 0.108.0, and the ACP SDK to 2.7.0. The managed Claude runtime follows the adapter at 0.3.326.

## Installation

```bash
npm install -g farming-code@2.2.100 --registry=https://registry.npmjs.org
```
