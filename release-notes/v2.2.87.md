# Farming v2.2.87

[简体中文](./v2.2.87.zh_cn.md)

## Chat first

- Antigravity is supported across structured Chat, Terminal, and resumable History.
- New sessions and launch controls prefer Chat when the selected Agent supports it, while saved Terminal preferences and existing session modes are kept.
- Submitted user messages render as Markdown in Chat.
- Expanding a collapsed disclosure keeps the current reading position.
- Collapsed handoff context stays intact across forks and history replay.
- Native child Agents keep their identity, history and readable progress across resumed turns.

## Terminal

- The desktop Terminal Composer starts collapsed by default.

## Language Server

- Slow, stalled or cancelled Language Server work no longer blocks browsing files or returning to Chat.
- Hover and navigation keep an interactive slot while diagnostics, semantic tokens and other background analysis run separately.
- Cancelled requests are forwarded to the Language Server, and a broken server connection stays contained to that server.

## Private deployment

- When a Config's running Server comes from a package other than the selected install (for example a manual npm install), a failed deployment now restarts that exact running package instead of downgrading to the selected image. An unidentifiable running package is refused before it is stopped.

## First use and feedback

- Chat keeps the first-session sign-in card visible and preserves launch configuration after authentication.
- Stop recognizes terminated zombie Servers while still checking owned child processes. Missing host tools and occupied ports now report actionable errors; startup links exclude old log entries.
- The directory installer reports elapsed dependency-installation time. `farming --version` shows the selected package and `farming url` recovers its authenticated address.
- Closing mobile navigation restores interaction with the main workspace. Large file trees keep visible rows mounted during fast scrolling.
- Empty workspace submissions explain what is missing. Spreadsheet input focus, plugin errors, compact navigation buttons, and the Paper Model Matrix follow the shared appearance rules.

## Agent communication

- Agent messages show their sender in Chat and preserve attribution across history replay.
- External applications can connect through the optional A2A plugin. Enable it in Plugins, create a scoped credential, and revoke access when no longer needed. It is disabled by default.
- Managed runtimes update to Codex 0.163.0, Claude ACP 0.93.0 and ACP SDK 1.9.0.

## Upgrade

```bash
npm install -g farming-code@2.2.87
```
