# Farming v2.2.71

[English](./v2.2.71.md)

## Chat 与关联 Session

- 在文件导航期间保持未完成的 Composer 提交归属原 Agent；移动端提交被接受后收起输入区，避免控件重叠。
- 使用共享 Chat 渲染与安全的分页关联会话读取展示原生子 Agent 详情；关闭已归档面板，并在继承对话后保留分叉边界。
- 持续展示轮次失败标记，新进度消息淡入且不重复播放，并保持键盘选中的命令可见。
- 提交确认晚于回复完成时保持轮次空闲，并恢复悬停与键盘聚焦时的展开箭头。
- 恢复大型 Codex 对话时不截断历史，并在重新打开 Session 前核对恢复失败后的实际状态。
- 父轮次结束后仍可发现原生子 Agent，返回父 Agent 时保留子 Agent 详情，并提供统一的可见性开关。

## 连接与生命周期

- 恢复超大目录时保持文件浏览响应：限制目录枚举与元数据读取的处理量，响应取消，并明确提示大小限制，不返回不完整列表。
- 大量展开目录恢复时先排队再发送读取请求，后台文件装饰加载期间仍为目录导航保留处理能力。
- 已跟踪文件的 Review 不再被无关的未跟踪文件阻塞；编辑器菜单明确显示 Blame 可用性检查状态和检查失败后的重试入口。
- 大量未跟踪文件不再阻塞 Review 来源选择；子模块提交差异无需在父仓库中读取子模块对象即可展示。
- Agent 或文件在后台恢复完成时，保持用户刚打开的移动端侧栏展开。
- 恢复停滞连接，让 Project 路径操作感知连接状态，并支持配置只读分享链接有效期与清晰的说明。
- 仅强制停止已核验的 Farming 所属进程快照，保留已验证的运行时缓存，并为源码安装准备修补后的 Browser 运行时。
- 改进私有发布工具链兼容性，并在部署冒烟验收前验证生命周期恢复。
- 将共享 ACP SDK 升级至 1.5.0，同时保留适配器拥有的运行时固定版本。
- 将托管 Codex 更新至 0.156.1、Codex ACP 更新至 1.13.0，Claude ACP 更新至 0.81.0 及其 SDK 0.3.280，并保留 Farming 已审阅的历史记录与生命周期集成。
- 支持独立目录安装并显式准备私有运行时；安装镜像不再重复包含仅供浏览器构建使用的依赖，同时保留对应许可证声明。

## 升级

```bash
npm install -g farming-code@2.2.71
```
