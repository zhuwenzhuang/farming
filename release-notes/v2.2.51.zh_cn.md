# Farming v2.2.51

[English](./v2.2.51.md)

里程碑代号：**BRIDGE**

本次发布让 Agent 可以直接使用用户现有 Chrome 中的页面与登录状态，将 Pi 纳入一等 Coding Agent，并在导航和重启后恢复更多工作区上下文，同时全面增强 Farming Code 的文件、终端、Provider、安全与交互体验。

## 直接使用现有 Chrome

- 可选的 Farming Browser Connector 让 Browser Agent 发现并管理用户 Chrome 中已经打开且允许访问的普通页面，直接复用当前登录状态，同时不影响独立的 Farming Browser。
- Connector 安装流程在插件页中被简化为明确步骤。Farming 只在用户请求后准备可见的扩展目录，并显示目录位置、大小、完整性和实时可用状态；安装与删除说明保持独立。
- Connector 会自动重连，无需逐个标签页授权即可管理现有普通页面；本地 Farming 侧栏会完成认证。独立的扩展身份、协议、密钥、存储和标签组确保它可与 OpenClaw 共存。
- 多种 Browser 来源可以同时启用：新浏览器、用户的 Chrome 与 Docker 中的浏览器可按任务组合使用；不再支持且容易混淆的 External CDP 配置已移除。

## Pi 与更可靠的 Provider 连续性

- Pi 现在是一等 Chat 与 Terminal Provider，具备托管 ACP 打包、History、Activity Detection、图标、Capability Discovery、CLI Smoke 与发布完整性校验。
- Codex 与 Claude ACP Adapter 已升级到当前托管版本。Farming 保留经过审查的 Codex 集成补丁，并在打包前校验精确的上游与 Bundle 哈希。
- ACP Streaming 现在会在 Host 与 Provider Socket 边界正确保留被拆分的 UTF-8 字符，渐进显示 Answer 与 Reasoning Markup，并在拒绝重复 Session Start 前先对账 Provider History。
- Provider 自己管理的 Terminal Viewport 不再被 Farming 恢复 Reading Anchor；Hard Stop 会移除完整的 Farming-owned Native Terminal Process 集合。

## 回到同一个工作区

- Farming 会恢复上次有效 Agent、打开文件、插件位置、Project 展开状态、侧栏可见性与宽度等稳定选择；记住的 Agent 已不存在时，会回到最近更新的 Agent。
- Worktree 控件可以在验证 Main Worktree 干净、目标 Branch 未被占用、没有 Live Agent 持有 Workspace、HEAD 一致并正确处理失败或不确定结果后，安全切换到已有本地分支。
- Chat 与 Terminal 文件链接可以挂载最近的 Git Worktree，保留用户明确选择的子目录 Project，跨 Project 返回来源 Agent，并确保结构化路径只解码一次。
- Files 可以安全打开更大的文本文件，对超大 Markdown Preview 分页，保持 Language Server 结果最新，并在保存、Review、Transcript、分享等 Modal Flow 中正确管理焦点。

## 更清晰、更稳定的交互

- Sidebar Row、Tab、List、移动导航、Plugins、Review 与相关控件现在共享一致的 Hover、Selection、Focus、圆角和浅色 Surface 语义，不再叠加或泄漏多个选中提示。
- Agent 侧栏在活动过程中保持稳定，记住用户选择的宽度与显示状态，并为 Browser 与 Computer Resource 提供更合适的默认宽度。
- Editor 与 Rich Preview Runtime 按需加载，Browser Navigation 直接复用权威 Metadata；修改过的交互路径使用状态 Fence 代替时间猜测。
- 带 Credential 的分享链接被限制在可信 Origin；ZIP 解压通过统一且经过审查的边界拒绝不安全 Archive；Desktop Source Checkout 会准备所需 Runtime；Pet 休息流程会保留完整时长并在归零时可靠结束。

## 文档

- Browser 指南新增独立的中英文“使用现有 Chrome”安装与删除流程，配套经过校验的高清截图，并清楚区分 Connector 与 Browser 能力本身。
- Provider、Files、ACP、Terminal、Browser、Computer Use、Appearance、Extension、安全与 Runtime Contract 均随实际行为同步更新；浅色文档页面恢复 Farming 的中性白色体系。

## 升级

```bash
npm install --global farming-code@2.2.51 && farming daemon
```
