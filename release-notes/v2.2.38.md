# Farming v2.2.38

[简体中文](./v2.2.38.zh_cn.md)

Milestone codename: **MIDDLE**

This release introduces two new capabilities in their initial form: the Farming Desktop app and the Language Server status UI. Both are deliberately early-stage; they require more real-world refinement before they can be considered mature. We are shipping them now so that daily use can inform that refinement.

## Desktop app (initial)

- Farming Desktop is an Electron shell that embeds the same backend and frontend as the browser experience, with native window management and a dedicated application icon.
- The desktop app owns cancellable startup resources, verifies backend protocol readiness before showing the main window, and fences SSH tunnel readiness for remote connections.
- Environment switching is atomic: the desktop app can point at a different backend without leaking the previous session's state.
- Remote server bootstrap downloads are bounded and interrupted downloads are cleaned up.
- This is an initial capability. Expect rough edges around window lifecycle, update flows, and platform-specific behavior that only surface with sustained daily use.

## Language Server status (initial)

- A dedicated Language Server icon and status surface shows whether an LSP server is on-demand standby or actively connected.
- Target binding lifecycle management reconciles multi-source registrations and cleans up stale bindings authoritatively.
- Stalled bridge requests are fenced and normalized so a hung language server cannot block the editor indefinitely.
- Diagnostics appear and clear as servers start and stop; file switching and reconnect paths are covered.
- This is an initial capability. Real-world projects with large workspaces, multiple concurrent servers, and unusual provider configurations will drive the next round of hardening.

## Codex Terminal identity

- Codex Terminal sessions now report exact identity through the internal `/status` endpoint instead of inferring it from terminal text patterns.
- History identity scanning has been removed. Session identity is authoritative from the provider adapter, eliminating a class of stale-identity mismatches.
- Terminal and ACP runtime ownership is separated: each runtime resolves its executable independently.

## History and performance

- Agent session and workspace status updates are streamlined, reducing redundant state transitions and re-renders.
- Title ownership metadata persists across restarts, so session titles survive recovery without re-derivation.
- Provider session titles refresh on reconnect instead of showing stale labels.

## Workspace and Agent-row UI

- Agent rows no longer flash or reorder during rapid status updates.
- Project actions scope to title hover, reducing visual noise in dense workspace lists.
- Empty agent resources are hidden; agent-sent screenshots display inline in Chat.
- Composer attachments and terminal state handling are corrected for fork and recovery flows.
- The active agent title fade and plan transcript typography are refined.

## Voice experiment removed

- The realtime voice experiment has been reverted from mainline. The released voice surface is restored to its prior stable state.

## Upgrade

```bash
npm install --global farming-code@2.2.38 && farming daemon
```
