# Farming v2.2.87

[English](./v2.2.87.md)

## Chat 优先

- 新增 Antigravity 支持，提供结构化 Chat、Terminal 与可恢复的 History。
- 所选 Agent 支持时，新会话和启动控件默认使用 Chat；已保存的 Terminal 偏好和已有会话模式保持不变。
- Chat 中已提交的用户消息按 Markdown 渲染。
- 展开折叠内容时保持当前阅读位置。
- 折叠的交接上下文在分叉和历史回放后保持完整。
- 原生子 Agent 在恢复后的轮次中保持身份、历史和可读进展。

## Terminal

- 桌面端 Terminal 输入区默认折叠。

## Language Server

- 缓慢、卡住或已取消的 Language Server 工作不再阻塞文件浏览或返回 Chat。
- 悬停和跳转保留独立的交互通道，诊断、语义高亮等后台分析单独排队。
- 取消请求会转发给 Language Server，服务连接断开只影响该服务本身。

## 私有部署

- 当 Config 中正在运行的 Server 来自所选安装之外的包（例如手动 npm 安装）时，部署失败会重新启动该正在运行的包，而不是降级到所选镜像；无法识别的运行包会在停止前被拒绝。

## 首次使用与反馈

- Chat 首次创建会话需要登录时保留登录卡片，并在认证后保留启动配置。
- Stop 正确识别已终止的僵尸 Server，同时继续检查所属子进程。缺少主机工具和端口占用会给出可操作错误，启动链接不再混入旧日志地址。
- 目录安装器在依赖安装期间显示已用时间；`farming --version` 显示当前选定版本，`farming url` 可找回带认证信息的地址。
- 提交空工作区会明确提示。表格输入框焦点、插件错误、紧凑导航按钮与 Paper Model Matrix 遵循共享外观规则。

## Agent 通信

- Chat 中的 Agent 消息显示发送方，并在历史回放中保留来源。
- 外部应用可通过可选的 A2A 插件接入。在 Plugins 中启用、创建限定权限的凭证，并在不再需要时撤销访问；插件默认关闭。
- 托管运行时升级至 Codex 0.163.0、Claude ACP 0.93.0 和 ACP SDK 1.9.0。

## 升级

```bash
npm install -g farming-code@2.2.87
```
