# Farming v2.2.36

[简体中文](./v2.2.36.zh_cn.md)

This release makes Farming's public release gate fail closed on CI and fixes several interaction and navigation issues found while dogfooding the release candidate.

## Release safety

- The Release workflow now requires a successful push-triggered `CI` run for the exact candidate revision before any build or publish job can proceed. Missing, pending, cancelled, or failed CI blocks the release.
- The pre-release guide now explicitly requires resolving every failed CI check and includes the production dependency audit in the fast source gate.
- The bundled `tar` dependency is updated to `7.5.22`.

## Code and CRT interactions

- Agent rows no longer enable HTML drag-and-drop on touch viewports, so tapping an Agent reliably selects it and closes the mobile sidebar.
- CRT no longer reopens Main Agent onboarding over an existing live Agent, including when authoritative state arrives after the initial empty render.
- Opening an Agent Home configuration now preserves its actual Provider Home identity and opens the file directly in the editor instead of reconstructing it through an unrelated Project identity.
- File-tree reveal and focus recovery now tolerate delayed layout and virtualization. Inline rename reclaims focus after the tree renderer updates, avoiding clicks intercepted by sticky directory or editor layers.
- File editor tabs reserve the measured width of their action bar, preventing narrow layouts from placing tab content underneath controls.

## Terminal links and release verification

- Terminal path handling now considers overlapping path candidates, excludes explicit HTTP(S) URLs from workspace-path resolution, and falls back through viable targets before restoring terminal focus.
- Browser release checks are deterministic across Chromium and iPhone WebKit for terminal output, touch navigation, file operations, Plugins, CRT onboarding, and Farming Pet's black-hole lifecycle.

## Upgrade

```bash
npm install --global farming-code@2.2.36 && farming daemon
```
