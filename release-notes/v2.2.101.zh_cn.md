# Farming v2.2.101

[English](./v2.2.101.md)

此版本使 Review 工作区在布局、Diff 展示与路径复制体验上对齐 Gerrit，改进 Codex 模型配置在 Chat 与 Terminal 间的衔接及诊断隔离，并优化终端输入框与对话复制行为。

## 改进

- Review 工作区对齐 Gerrit 体验：新增文件列表表头、总计行、状态标签与变更比例条；打开文件自动标记为 Reviewed；Unified Diff 合并为单列行号并采用 Gerrit 风格 Hunk 展开条；文件路径同时支持行内复制按钮与原生拖选复制。
- 在 Codex Chat 与 Terminal 中支持模型声明的 Ultrafast 服务，并在从 Chat 切换到 Terminal 时延续当前选中的模型、推理强度与速度配置。
- Terminal 输入框按视图默认收起，向终端粘贴图片时自动展开；活动预览浮动展示在右上角；支持从 Chat 对话复制富文本 HTML 格式，并支持在输入框中点击打开链接。

## 修复

- 跨会话保留问答历史并去重 Codex 问答回执。
- Fork Codex 会话时省略内联历史轮次，避免触发分页线程的废弃警告。
- 将共享 Codex app-server 的诊断通知限定在触发它的会话内，并将已准备好的适配器产物纳入 ACP 运行时宿主身份校验。

## 托管运行时

- Codex 更新至 0.170.0，Claude ACP 更新至 0.108.1，ACP SDK 更新至 2.8.0；Codex ACP 保持 2.7.0，托管 Claude 运行时保持 0.3.326。

## 安装

```bash
npm install -g farming-code@2.2.101 --registry=https://registry.npmjs.org
```
