# Farming v2.2.55

[简体中文](./v2.2.55.zh_cn.md)

Milestone codename: **STAY**

This patch release keeps the active workspace stable across Agent switches, Chat recovery, shared links, and Browser reuse.

## Chat and Agent continuity

- Structured ACP transcripts and Session configuration now remain attached to their exact Agent while users switch among live work, including progressive updates that arrive in the background.
- A newly connecting Chat stays visibly pending until its authoritative Provider Session identity exists, and loading older history preserves the reader's current position.
- Bounded Chat-history recovery now ends in an explicit transport or response error when no authoritative transcript is available, then reconnects without discarding retained history.
- Codex Session discovery is reused through a bounded cache without making cached state authoritative; stale or mismatched Session state fails closed and refreshes from the Provider boundary.
- Selecting an Agent no longer changes its activity time, and a currently visible Agent remains anchored while Project ordering updates arrive.

## Reusable Browser sessions

- Every Agent and Project now has a reusable `default` Browser Session. `farming browser open` creates it only when absent, starts it when stopped, and otherwise reuses the same Resource and profile.
- Independent Browser work can use stable named Sessions, while explicit Resource IDs remain available for compatibility and administration.
- Project launch shortcuts remain explicit: the Provider row starts Terminal and the adjacent shortcut starts Chat, regardless of the saved new-Agent runtime default.

## More predictable workspace behavior

- Farming Code and CRT now use the supported xterm.js WebGL Terminal path exclusively, removing the retired Ghostty renderer and its bundled runtime.
- Owner app URLs retain their authentication token across reloads, copies, and installed-app handoff, while contextual Chat and File locations are consumed only on the first page load.
- Horizontal workspace resizing stops cleanly after pointer release, and native, Monaco, and Terminal scrollbars now share appearance-aware geometry and interaction colors.
- The packaged Codex ACP runtime integrity check is aligned with the reviewed adapter bundle used by this release.

## Upgrade

```bash
npm install --global farming-code@2.2.55 && farming daemon
```
