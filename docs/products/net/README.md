# Farming Net

> Chinese version: [README.zh_cn.md](./README.zh_cn.md)

Farming Net provides one private directory for opening several Farming
deployments. It is separate from Farming Code and Farming CRT.

Use it when you already run Farming on more than one trusted host and want one
place to find those instances.

See the [Farming Net guide](guide.md) for setup, enrollment, and security
requirements.
