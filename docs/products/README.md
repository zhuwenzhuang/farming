# Farming Products

> Chinese version: [README.zh_cn.md](./README.zh_cn.md)

Farming provides several interfaces for the same underlying Agents and Sessions.
Choose the interface that fits the task.

- [Farming Code](code/README.md) — focused work, files, review, and intervention.
- [Farming CRT](crt/README.md) — keyboard-first monitoring and control.

Switching between Code and CRT does not create a second Agent.

Return to the [documentation home](../README.md) for setup and operations.
