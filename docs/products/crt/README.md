# Farming CRT

> Chinese version: [README.zh_cn.md](./README.zh_cn.md)

The maintained user guide, screenshots, common keys, and Token interface are on
the [Farming CRT documentation page](https://zhuwenzhuang.github.io/farming/en/crt/overview).

Farming CRT is a keyboard-first second interface over the same backend Agents
and Sessions as Farming Code. Switching interfaces does not duplicate an Agent.

Maintainers should use [Farming CRT base layout](base_layout.md) for the durable
layout, interaction, and visual contract. Historical cleanup notes remain in
[Agent cleanup history](agent-cleanup-history.md).
