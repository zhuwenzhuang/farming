# Composer 输入

> English version: [composer-input.md](composer-input.md)

Chat 和 Terminal 输入共享一套编辑约定。草稿、附件和提交状态仍由现有 Agent Composer
管理。展开编辑只改变本地展示状态，不创建另一份草稿或提交路径。

Chat 发送时立即把文字、媒体和上下文的完整快照移入所属 Agent 的待发送列表，释放输入框供继续编辑。本地入队不代表后台已接受。主会话和侧会话共用状态所有者与待发送行样式，每个 Composer 最多保留 32 条待确认消息，达到上限时保留草稿。Terminal 保持原有确认与草稿处理。

待发送消息依次经历排队、投递中、已接受／明确失败／结果不明。只有队首可以投递；结果不明或失败的队首阻止后续消息。Prompt 还需等待当前 Turn 结束。每次尝试固定保留请求 ID、内容与投递模式。明确无副作用的失败重试使用新 ID，避免旧回执影响新尝试；结果不明时必须沿用原 ID。确认后只移除对应项并记录输入历史；明确失败仅在没有后续排队项且输入框没有新文字、媒体、引用或模式时回弹完整快照，否则保留失败行供重试或显式丢弃。超时、断线保留结果待确认项，不能回弹成可能重复发送的新草稿。

刷新后所有恢复项都需显式核对，包括原先显示排队的项，因为检查点可能早于实际投递。核对只查询原请求 ID：已接受请求返回保存的结果；持久化意图、结果不明和缺失记录均保持待确认，绝不重放。已完成准入记录的保留数量有限，因此缺失记录不能证明没有副作用。恢复的后续消息队列遵循同样的保守规则。迟到的明确回执仅处理对应项，不修改新草稿。运行时变化、主侧会话和队列刷新都不能绕过同一 Composer 的在途互斥。

后台继续在投递前持久化意图，在确认前持久化接受结果。界面即时反馈不削弱这两道持久化约束。

显式发送 Chat 消息后立即跟随对话最新位置，包括等待确认期间。只有读者向上滚动离开最新内容时才显示“跳到最新”按钮；紧凑布局下按钮贴近对话视口底部。

Chat 和 Terminal 工具栏标签使用共同的文本行框，必须完整展示字形及下伸部。横向省略不能裁剪文字上下边缘或改变外层按钮高度；此规则适用于常规与紧凑布局中的模型、推理强度和审批标签。

## 引用对话文字

选区工具条使用有对比度的底色，在滚动或布局变化时跟随会话可视区域内的文字。
上方空间不足时移到选区下方，锚点被裁切时隐藏。清除选区、离开会话或关闭
工具条后结束展示；引用本身不发送消息。

引用文字作为所属 Composer 的上下文快照，与用户编辑的问题分开保存。紧凑引用块
默认显示两行摘要，可展开完整原文，也可移除而不修改草稿。复用现有上下文持久化
和发送流程，在恢复草稿或发送失败时保留引用，发送时随问题一起提交。主会话和侧会话
使用同一展示方式，各自保留独立草稿。

## 长文本粘贴

一次纯文本粘贴超过 1,000 个 Unicode 字符时，会成为同一 Agent 草稿中的文本引用。
短文本保留原生编辑行为，媒体粘贴沿用附件流程。Chat、Terminal 输入框和侧聊遵守
同一规则。卡片复用引用内容的共享样式，显示摘要，支持全文预览、删除和“在输入框中显示”；
后者将完整内容移到当前草稿末尾，不重复保留引用。

输入框状态同时拥有草稿和文本快照。粘贴以原子操作将选中范围替换为引用，每次粘贴
具有独立标识。预览只改变展示；删除只移除该引用。移回输入框时，原子地删除引用并
追加完整文本，重复操作不会重复插入。粘贴和移回均不发送消息，也不需要网络请求。
超过 250,000 个 UTF-16 码元的粘贴会被明确拒绝并提示拆分，草稿保持不变；
快照沿用现有有界检查点。提交将完整快照作为引用材料，
与用户请求分开。队列编辑、发送失败或结果不确定时保留快照；提交成功不能清除更新的
草稿或引用。切换 Agent 保持各自归属，不依赖特定提供方的文件路径或上传。

粘贴预览和引用摘要支持原生鼠标框选与复制，只有展开标签切换折叠状态。剪贴板 HTML
为卡片提供有界且经过校验的格式区间，颜色随外观适配；来源 HTML 与可执行内容不会挂载。

所有 Composer 均采用原生纯文本编辑。短文本在当前选区粘贴剪贴板纯文本，保留缩进、
换行和原生撤销/重做。剪贴板 HTML 不得向草稿添加 Markdown 标记、代码围栏或链接地址。
主动输入或复制的 Markdown 源码按字面保留。长文本卡片保存同一原文；“在输入框中显示”
原子恢复原文并仅删除一次卡片。已有持久化卡片若包含可编辑 Markdown 表示，继续保留该表示，
兼容恢复与提交。Shift＋Cmd/Ctrl＋V 绕过当次粘贴折叠。

Agent 草稿字符串是唯一编辑与提交状态。可见文字、光标、选区、IME、滚动和撤销均由同一个
原生 textarea 负责；禁止透明文字与语法叠加层替代原生显示。Markdown 样式的内容不能改变
输入字体、行高或颜色。主 Chat、侧边 Chat、Terminal 和展开编辑在所有外观下共用此规则。
HTML 派生样式仅用于不可编辑的上下文卡片预览，不进入输入框。

输入、选择、撤销、历史、队列编辑、刷新和 Agent 切换沿用既有草稿转换。组合输入期间
Enter/Escape 归 IME；编辑与展示变化不会发送。切换 Agent 保持草稿独立，显式发送通过既有
提交归属捕获当前草稿。卡片删除、恢复、提交确认和更新草稿隔离沿用既有归属与失败语义。

## 附件接收与恢复

粘贴、文件选择和拖放共用同一条附件处理路径，并始终归属于操作开始时的 Agent 草稿，侧聊也遵循这一规则。剪贴板同时包含文字和文件时保留两者。工作区文件树拖放保留根目录与相对路径身份；系统文件上传到当前实例，不把本机路径当成远程后端路径。全局文件粘贴交给最后聚焦且仍可见的输入框，并让其他文本编辑器、终端、菜单及对话框优先处理。Desktop 仅在显式粘贴没有浏览器文本或文件时读取原生剪贴板图片。

接收时先保留附件身份和顺序，再异步处理。附件由处理中进入就绪或明确错误，处理有截止时间；处理中及失败的附件阻止发送。移除附件取消未完成工作，迟到结果不能恢复已删除附件。刷新后未完成的附件保留为错误卡片，切换 Agent 不转移处理结果；不自动重放不确定的上传。

后端在实例附件目录保留原文件，并在隔离工作线程中提取有界正文。单文件限制为 20 MB，组合文档正文限制为 250,000 字符，超限明确报错而不截断。支持 UTF-8／UTF-16 文本、PDF、DOCX、PPTX 和 XLSX／XLS；保留 PDF 页、幻灯片及工作表边界。预览是提取正文，不包含图片、原始排版或 OCR。空扫描件、加密文件、不支持的二进制、超限压缩包及处理超时明确失败。原文件可下载；所有 Provider 都通过现有上下文提交接收标明用途的正文快照和原文件位置。

图片在 MIME 缺失时根据已知扩展名识别。HEIC 转为 PNG。PNG、JPEG 和 WebP 最长边超过 2048 像素时自动缩小并保留透明度；其他图片仅在 WebP 转换减小体积时使用转换结果，否则保留原始字节。大图预览复用共享查看器，支持键盘关闭与焦点返回。长文本折叠和图片处理是所有输入框共享的系统默认行为，菜单不再提供开关，也不读取旧浏览器偏好；Shift＋Cmd/Ctrl＋V 临时绕过折叠。

历史记录同时恢复文字、上下文快照和就绪的媒体附件；浏览历史期间保留尚未发送的附件草稿，退出历史后恢复。持久历史有容量限制，不存储临时对象 URL，媒体预览通过当前实例的认证附件接口读取。排队消息、失败发送及新草稿保护沿用既有快照归属。

## 紧凑与展开编辑

紧凑布局中，文本框随内容增高至有界上限（约六行，可见视口较矮时进一步缩小），超过后
使用原生滚动。文本框内开始的纵向手势由文本框处理，到达边界也不会带动背后的对话。
保留原生选字、输入法组字和双指缩放。

无论输入框是否聚焦，对话区域始终按 Composer 实测高度预留空间。清空或缩短草稿时，
输入框按内容高度收缩，不能因网格拉伸而保留之前的较大高度。

始终可见的展开按钮打开原位编辑页面，占用当前可见视口。文本框保持挂载，草稿、选区和
滚动位置保持连续，收起也不丢失这些状态。Light、Dark、Paper 均复用共享的 Composer
表面、控件、附件和提交行为。暂时隐藏对话但保留阅读位置；桌面端保持原有布局和键盘行为。

| 触发 | 效果 |
| --- | --- |
| 展开 / 收起 | 只改变展示，保持文本框挂载并保留选区 |
| 输入、粘贴、组字或删除 | 更新同一 Agent 草稿，尺寸变化或展开不会发送 |
| 紧凑布局 Enter | 插入换行，发送仍通过显式控件完成 |
| Escape | 共享交互层先关闭最上层菜单，再收起展开页；输入法取消优先 |
| 键盘 / 视口尺寸变化 | 在可见视口内重算有界尺寸，保持发送可达 |
| Agent 切换、桌面布局、权限/错误请求或听写 | 退出展开状态，保持草稿归属并展示需处理的界面 |
| Chat 本地入队或 Terminal 接受 | 所属状态管理器接管提交快照后收起当前展开页；保留更新的草稿和后来重新展开的编辑会话 |
| 提交被拒绝、结果不确定或中断 | 保留后续编辑状态；明确 Chat 失败仅回弹至空输入框，结果不明保留待确认项；展示层不重试操作 |

展开是完整编辑页面，不是可点击外部关闭的模态框。编辑时隐藏背景内容和紧凑导航；外部
点击不会丢弃或收起草稿。可通过按钮显式收起，提交被接受后也自动返回对话；不增加与滚动、选字冲突的下拉手势。
紧凑输入行必须为展开按钮保留完整的 44px 点击区域，与下方发送／中断行分离；空草稿和键盘占用后的短视口同样适用。

## 命令导航

Chat 和 Terminal 命令菜单使用共享菜单选中背景，确保键盘选中项清晰可见。
所有外观下，悬停与选中使用相同填充色。命令名占主行，说明位于下一行并在来源标签前
截断；长名称优先使用主行可用宽度。方向键在筛选后的命令中循环，
Home 和 End 选择首尾项。打开菜单或改变选中命令时，将该行滚入菜单可见区域，
焦点仍留在输入框。筛选后重置到第一项；关闭菜单结束导航，不提交消息。

## 验证

Chat 和 Terminal 均须覆盖中英文长文本、原生滚动、选区、输入法、附件、菜单、权限请求、
较矮视口和 Agent/布局切换。验证展开前后是同一个 DOM 文本框，且 Enter 不发送。在
Light、Dark、Paper 下捕获紧凑和展开状态。浏览器模拟视口只验证布局，不代表已验收
实体手机的键盘、听写或候选词界面。

纯文本验收覆盖从已渲染 Chat 回答原生复制，粘贴到主 Chat、Terminal 和侧边 Chat，正文中间
替换、中文组合输入 Enter 仲裁、撤销/重做、换行滚动、Agent 切换、刷新以及精确发送内容。
检查 Markdown 字面量、代码缩进、表格分隔符和长文本卡片恢复。在桌面 Chromium 和紧凑/展开
WebKit 中对比 Light、Dark、Paper 截图。浏览器组合输入事件仅验证应用事件仲裁，不代表
实体操作系统候选窗口验收。

`npm run release:fast-screen:mobile` 在完整移动端矩阵前检查草稿收缩、失焦空间预留和
图片预览点击区域。

## 上下文与命令

Chat 与 Terminal 共用 `@` 文件／目录查找、编辑器选区快照、分类 `/` 命令和 `$` 技能选择。
引用保存在现有草稿中，沿用已有提交路径。文件引用不会添加工作区根目录或授予文件系统访问权限。

### 入口语义

| 入口 | 含义 | 选中候选项后 |
| --- | --- | --- |
| `@` | 引用当前已授权工作区的上下文 | 向草稿添加类型化引用，不发送 |
| `/` | 查找 Farming 动作、Agent 命令与技能 | 打开本地操作界面，或暂存命令／技能，等待显式发送 |
| `$` | 直接查找技能 | 与 `/` 中对应技能使用同一身份和草稿表示 |
| 文件编辑器“引用选区” | 添加带来源的选中代码 | 保存文本、路径和范围的快照，不发送 |

`@`、`$` 在文本开头或空白／左括号等起始标点后，按光标位置触发。邮箱、URL 内部以及
`$HOME` 等已知环境变量不能被转换为引用。粘贴标记不会创建类型化引用或选中技能。
没有选择候选项时保持普通文字可编辑。`/` 在行首命令位置、参数之前触发，不能在文件
路径中触发。支持 Unicode 查询，只替换当前查询片段，保留光标之后的文字。

Escape 关闭后，在该处查询变化或输入新触发符之前抑制重新弹出；普通重新渲染不能重开菜单。

#### 上下文引用

选中 `@src/auth.ts` 后，将查询替换为可读的相对路径 `src/auth.ts`，同时在现有附件区
添加可移除的引用标签。这样保留原生文本框及其撤销、选字、输入法和展开行为。插入路径是
普通正文，标签才是附件的权威表示：编辑／删除正文路径不改变附件，移除标签也不改写正文。
手打或粘贴路径不会自动附加内容。可见标签用于查看和管理引用，不推断隐藏的文字绑定关系。

引用携带精确的工作区／根目录身份、类型和规范化相对路径。选区额外保存选中文字、原始
范围及可获得的来源版本。完全相同的引用共用一个标签；同文件的不同选区保持独立。
同名文件展示父级路径。点击标签打开预览，展示路径、范围及移除操作。

文件和目录引用表示“让 Agent 查看这个位置”，不递归内联文件内容。选区引用发送捕获的
原文并标注原始来源，即使文件后来发生变化。预览明确区分实时位置和选区快照。
保留已有非代码引用及媒体附件流程。

后端按已有工作区授权检查根目录、路径和符号链接。引用沿用带来源的路径／选区文本表示。
技能通过读取准确 SKILL.md 路径的明确指令投递。目录不意味着无限枚举。无法投递时必须在
发送前明确展示；前端不能悄悄丢弃上下文或自行拼接提供方语法。Terminal 同样由适配器
提供受支持的表示，不额外执行文件系统或 Shell 命令。

#### 命令与技能

`/` 菜单分为 Farming 动作、Agent 命令、Skills 三组。每行展示名称、简短说明、来源／
作用域，以及来源提供的参数提示。身份包含来源和作用域，同名但不同来源的条目仍可区分，
不能只按显示名称去重。

选择打开模型设置等本地展示动作时，打开已有控件，只消耗触发文字，保留其他正文和附件。
实际选择设置沿用该控件的应用行为。发送任务、切换会话或破坏性动作不能仅因选中补全项
就立即执行。

Agent 命令连同参数暂存到草稿，由用户显式发送。通过 `/` 或 `$` 选择技能时，使用同一
身份和可见技能标签，消耗查询文字，保留周围普通正文。重复选择同一技能不重复添加。
目录同时携带技能精确路径、提供方命令名及作用域；发送时重新校验这三个字段，不按显示名称解析。
选择技能不启用集成、不改变权限，也不创建 Agent。

Agent 命令来自当前会话权威发布的命令目录。技能必须有明确目录身份／元数据，不能猜测
任意斜杠命令就是技能。没有技能目录的提供方仍展示其命令；`$` 明确说明技能不可用。
能力丢失后，已选条目保留并显示可处理的不可用状态。提交准入时重新核验能力，不得替换成
另一来源的同名命令。

### 搜索、键盘与样式

空 `@` 查询展示授权工作区根目录下的真实条目，排除空根路径；输入后搜索授权范围内的文件和目录。依次按
精确匹配、名称前缀、路径／词前缀、模糊匹配排序，同分保持稳定。命令和技能在各分组内
使用相同文字匹配规则。读取和渲染结果有界，存在更多匹配时提示缩小查询范围。
加载中、无结果和读取失败分别展示；失败不能伪装成权威空列表。

键盘优先级为输入法、当前补全、已有编辑／历史快捷键、已有发送行为。组字期间 Enter 和
Escape 归输入法。菜单中方向键导航，Home／End 选首尾，Enter／Tab 接受可选候选项，
Escape 关闭但不改草稿。菜单处于加载／空／错误状态时，消耗 Enter／Tab，不能穿透发送。
点击外部关闭时保留草稿并让目标点击正常生效。没有菜单时保留桌面、紧凑布局、排队与
steer 的既有快捷键，不新增全局 Tab 排队语义。输入焦点不离开文本框，选中行始终可见。

复用共享补全 listbox 与可关闭界面的交互所有者。向辅助技术暴露当前候选项、加载／错误
状态；本地动作的效果在行说明中写清楚。不增加组件私有的全局键盘或外部点击监听器。

菜单锚定 Composer，受可见视口约束，内部独立滚动。复用共享菜单行的字号、图标、几何和
间距。悬停与选中使用同一填充色，不添加左侧标记。引用和技能共用紧凑附件栏；默认一行，
溢出以数量入口展开，不能变成不断增高的卡片堆。Paper 复用共享色块，Light／Dark 沿用
各自表面／边框规则，所有外观都应能辨认输入区边界。紧凑与展开编辑保留同一个文本框，
软件键盘出现后发送控件仍可达。

### 所有权与状态转换

草稿、排队消息和失败提交都保存有界的类型化引用；仅含引用的草稿在刷新或 Agent 替换后仍然保留。
主聊天与关联 Agent 侧栏使用完整的同一份草稿快照。实际发送（包括队列出队）前，通过工作区授权重新检查文件和目录，
并重新读取技能目录，核对技能命令、来源和准确的 SKILL.md 路径。技能通过“读取并遵循此准确路径”的明确指令传递，
不将这种表示声称为原生斜杠命令调用。选区保留捕获的文本，不受源文件后续变化影响。
异步校验占用现有的每 Agent 提交所有权，读取期限为八秒；失败保留完整草稿并明确报错。
空 `@` 展示当前工作区根目录内可选择的文件与目录，不把空路径根节点作为候选。

Agent Composer 所有者将正文、引用、技能和附件作为同一个草稿版本管理。菜单只拥有
展示／查询状态。后端拥有授权、能力和提交准入，提供方适配器拥有传输编码。复用既有
持久化边界，不再建一份草稿存储、重试循环或提交队列。

| 状态／触发 | 守卫与效果 | 失败、取消与恢复 |
| --- | --- | --- |
| 关闭 → 查询 | 捕获 Agent、工作区、运行时／目录代次、查询和光标范围 | 组字中或触发边界不合法时不打开 |
| 查询 → 加载 → 就绪／空／错误 | 只有匹配代次的结果可以发布；使用既有有界读取期限 | 新查询尽可能取消旧读取，迟到结果丢弃；超时可见，可显式重试 |
| 接受候选项 | 核验当前片段、候选身份和所有者，再更新一个草稿版本 | 过期或禁用候选不能修改另一份草稿；关闭菜单不发送 |
| 添加／预览引用 | 后端验证精确范围；验证中可见并阻止发送该条目 | 丢失／不可访问／不支持的条目可重试或移除；移除取消读取并拒收迟到结果 |
| 编辑／切换 Agent／展开 | 保持草稿归属；展开只改展示 | Agent／运行时变化关闭补全并使异步工作失效；引用不能迁移到另一个 Agent |
| 恢复草稿／重连 | 恢复类型化身份，重新验证当前位置访问和能力 | 丢失条目保留为无效状态；旧文字／媒体草稿不凭空生成引用；不自动重开菜单 |
| 显式发送／排队／steer | 用已有请求身份，一起快照正文、引用、选区、技能和附件 | 未解析／无效条目阻止提交；准备好的请求不可变；编辑排队项按已有规则形成替代草稿版本 |
| 提交被接受 | 只清除该次提交版本及其拥有的条目 | 迟到确认不能删除更新后的正文或附件 |
| 提交被拒绝／结果不确定 | 保留完整提交快照和已有核对状态 | 由当前所有者核对，不能自动重放或换通道重试 |

排队的位置引用仍表示实时位置，选区文字仍是快照。除排队准入外，实际投递前也核验授权和
当前能力。失败时明确阻塞该条目，不能只发送正文。关闭预览／搜索取消读取，不取消 Agent。
