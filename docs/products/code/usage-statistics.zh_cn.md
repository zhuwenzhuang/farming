# 用量统计

> English version: [usage-statistics.md](usage-statistics.md)

后端拥有用量快照。本地 Token 活动和账户额度是两类指标：日志描述已配置 Agent Home
内的工作量（包含缓存 Token），不能证明账户剩余额度或账单。

## 状态与归属

一次摘要读取固定 Home 配置和采样时间，采集同一份本地历史，再派生速率、曲线和每日
总量。缓存身份包含 Home 和后端本地日期。扫描未完成及 Provider 读取失败必须明确
展示；缺失数据不是零用量。每日图与小时明细使用后端时区；1d 活动曲线表示滚动
24 小时，并非今天的自然日总量。
解析后的源记录缓存独立于观察时间；每次读取按当时的时间窗口筛选，避免时钟偏差
导致用量记录被永久丢弃。

账户读取归属于 Provider 与确切 Home。支持的适配器读取登录账户的权威额度，自定义
推理路由和会话内限额事件不能替代。每个 Home 保留独立结果、来源和观察时间，禁止
跨账户累加百分比。不支持、未登录、数据无效及超时均显示不可用。Codex 调用
account/rateLimits/read，由额度接口自行验证保存的账户，优先选择 rateLimitsByLimitId
中的 codex 额度。推理 Provider 是否显示账户不能阻止这次读取；不启动对话轮次，
也不消耗重置次数。

读取从等待进入有界成功或明确失败；并发摘要请求复用实例缓存。Home 变化及失效操作
阻止旧结果覆盖新状态。临时额度进程限制输出及执行时间，所有终态均清理进程。失败
不能恢复旧额度，也不重试写操作。打开的今日明细周期刷新；导航取消旧请求，迟到
响应不能覆盖新日期。错误及未完成历史保持可见，来源恢复后可重新读取。

## 验证

覆盖代理日志与账户额度不一致、多 Home 隔离、缺失与零值、超时和进程清理、扫描
失败及恢复、读取中缓存失效、本地跨日、今日刷新、分叉／副本去重，以及摘要、每日
明细和各 Provider 总量一致。使用确定性 Provider 验证 Light、Dark、Paper 的组合界面。
