## 插件与实验性功能

- [插件概览](./cn/plugins/overview)：统一管理 Farming 内置能力、Agent Homes 与 Agent 扩展。
- [Agent Homes](./cn/plugins/agent-homes)：为同一种 Coding Agent 配置多套 Home，更方便地切换账号与配置。
- [Farming Browser](./cn/browser/overview)：需要 Agent 操作网页时再启用。
- [Language Server](./cn/code/language-server)：在 Files 中提供代码跳转、引用、调用层次和诊断。
- [Computer Use（实验性）](./cn/experimental/computer-use)：让 Agent 操作隔离的图形桌面。
- [Farming Desktop（实验性）](./cn/experimental/desktop)：在桌面应用中连接并切换多个 Farming 后端。

实验性功能仍可能变化，建议先用于可恢复、非关键的任务。
