# Token 使用

Farming Code 的 Usage 面板汇总本机能够读取到的 Provider Token 活动。它适合观察当前使用速度、每日趋势和异常峰值，不用于替代 Provider 自己的账单页面。

## 查看当前活动

打开侧栏顶部的 Usage 区域，可以查看当前窗口内的 Token 速度和各 Provider 状态。某个 Provider 无法提供完整数据时，界面会保留其他可用信息，并明确标出缺失原因。

## 查看历史

年度热力图用于发现活跃日期和使用变化。选择某一天后，可以继续查看小时分布，以及 Farming 能够关联到的 Provider 和 Agent。

这些数字来自本机可用的 Session 或 Provider 数据源。不同 Provider 的覆盖范围可能不同，因此跨 Provider 比较时应先看页面显示的数据来源和可用状态。

Farming CRT 也提供键盘优先的 Token 界面，见 [Farming CRT](../crt/overview#token-使用)。
