# Computer Use

<Badge type="warning" text="实验性功能" />

::: warning 实验性功能
Computer Use 已有实现和自动化验证，但目前缺少足够的真实使用案例。它不是 Farming 的默认工作流，能力、依赖和交互仍可能调整。
:::

Computer Use 让 Agent 操作完整图形环境，包括应用、系统对话框、鼠标、键盘、Screenshot 与可访问性信息。结构化网页任务仍优先使用 [Farming Browser](../browser/overview)。

## 当前目标

Farming 可以为 Agent 提供隔离的 Linux 图形环境。你可以在 Farming 中查看画面，并在需要时接管控制。

如果容器或运行依赖还没有准备好，页面会说明缺少什么，不会悄悄换成另一种操作方式。

## 控制权

同一时刻只有一个控制者：

- Agent 控制时，用户可以观察；
- 用户选择接管后，Agent 操作会停止；
- 用户交还控制后，Agent 必须先重新观察最新画面，再继续操作。

操作超时代表结果可能不确定。涉及提交、发送、删除等动作时，不应自动重放。

## 隔离边界

每个 Computer 环境属于一个 Agent 和 Project。不同 Agent 不会自动共享图形 Session、Profile、登录信息或可变文件系统。

隔离环境不能访问其他 Agent 的私有状态，也不会获得 Host 的容器管理权限。

## 启用前建议

- 先从无敏感账号、可恢复的任务开始；
- 明确准备并验证所需运行依赖；
- 保留人工接管路径；
- 不把实验性结果当成发布或生产操作的唯一证据；
- 发现真实使用问题时附上环境、步骤和可见错误。
